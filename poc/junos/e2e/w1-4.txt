JUN02 set policy-options policy-statement TO-ISP term REST then reject
JUN02 set policy-options policy-statement TO-ISP term SUMMARY from protocol aggregate
JUN02 set policy-options policy-statement TO-ISP term SUMMARY from route-filter 172.16.0.0/16 exact
JUN02 set policy-options policy-statement TO-ISP term SUMMARY then as-path-prepend "65000 65000"
JUN02 set policy-options policy-statement TO-ISP term SUMMARY then accept
