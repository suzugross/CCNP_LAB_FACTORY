# 学習モードの模範解 j1t1(learn.yml の solution から機械的に起こした)
JUN01 configure
JUN01 set policy-options policy-statement SERVERS-TO-OSPF term LAN from protocol direct
JUN01 set policy-options policy-statement SERVERS-TO-OSPF term LAN from route-filter 172.16.10.0/24 exact
JUN01 set policy-options policy-statement SERVERS-TO-OSPF term LAN then accept
JUN01 set policy-options policy-statement SERVERS-TO-OSPF term SRV from protocol static
JUN01 set policy-options policy-statement SERVERS-TO-OSPF term SRV from route-filter 172.16.20.0/24 exact
JUN01 set policy-options policy-statement SERVERS-TO-OSPF term SRV then metric 20
JUN01 set policy-options policy-statement SERVERS-TO-OSPF term SRV then accept
JUN01 set protocols ospf export SERVERS-TO-OSPF
JUN01 commit and-quit
