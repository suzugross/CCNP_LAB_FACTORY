# J1-5 誤答 a: 印を付けるポリシーを連鎖の後ろに置く(ISP-IN の accept で止まり届かない)
JUN02 configure
JUN02 set policy-options community FROM-ISP members 65000:100
JUN02 set policy-options policy-statement MARK term t from route-filter 203.0.113.0/24 exact
JUN02 set policy-options policy-statement MARK term t then community add FROM-ISP
JUN02 set policy-options policy-statement MARK term t then local-preference 200
JUN02 set protocols bgp group ISP import MARK
JUN02 show protocols bgp group ISP
JUN02 commit and-quit
