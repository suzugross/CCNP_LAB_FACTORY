# 学習モードの模範解 j1t3(learn.yml の solution から機械的に起こした)
JUN02 configure
JUN02 set policy-options policy-statement ISP-IN term DEFAULT from route-filter 0.0.0.0/0 exact
JUN02 set policy-options policy-statement ISP-IN term DEFAULT then accept
JUN02 set policy-options policy-statement ISP-IN term BOGONS from route-filter 10.0.0.0/8 orlonger
JUN02 set policy-options policy-statement ISP-IN term BOGONS from route-filter 172.16.0.0/12 orlonger
JUN02 set policy-options policy-statement ISP-IN term BOGONS from route-filter 192.168.0.0/16 orlonger
JUN02 set policy-options policy-statement ISP-IN term BOGONS from route-filter 100.64.0.0/10 orlonger
JUN02 set policy-options policy-statement ISP-IN term BOGONS from route-filter 198.18.0.0/15 orlonger
JUN02 set policy-options policy-statement ISP-IN term BOGONS then reject
JUN02 set policy-options policy-statement ISP-IN term PUBLIC from route-filter 0.0.0.0/0 prefix-length-range /8-/24
JUN02 set policy-options policy-statement ISP-IN term PUBLIC then accept
JUN02 set policy-options policy-statement ISP-IN term REST then reject
JUN02 set protocols bgp group ISP import ISP-IN
JUN02 commit and-quit
