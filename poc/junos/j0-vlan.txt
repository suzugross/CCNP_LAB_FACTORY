# J0 PoC 7: 1 つの物理 IF に VLAN の論理ユニットを 2 つ・同じユニットに IPv4 と IPv6(使っていない et-0/0/2 で)
JUN01 configure
JUN01 edit interfaces et-0/0/2
JUN01 set vlan-tagging
JUN01 set unit 10 vlan-id 10 family inet address 10.0.110.1/24
JUN01 set unit 10 family inet6 address 2001:db8:110::1/64
JUN01 set unit 20 vlan-id 20 family inet address 10.0.120.1/24
JUN01 show
JUN01 top
JUN01 commit check
JUN01 commit
JUN01 run show interfaces terse et-0/0/2
JUN01 show interfaces et-0/0/2 | display set
JUN01 set interfaces et-0/0/2 unit 0 family inet address 10.0.130.1/24
JUN01 commit check
JUN01 delete interfaces et-0/0/2
JUN01 commit and-quit
