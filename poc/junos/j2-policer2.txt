# PoC J2-6(BL-275): j2-policer.txt の続き。input-list は終端の動作(accept)で止まる(文書 Table 86)→ 1 本目の term OTHER accept を外す。
# カウンタは合成されたフィルタ名(et-0/0/1.0-inet-i)の下に出る(文書「Interface-Specific Names for Filter Lists」)
JUN02 show firewall filter et-0/0/1.0-inet-i | no-more
JUN02 configure
JUN02 delete firewall family inet filter NO-BOGONS term OTHER
JUN02 commit and-quit
JUN02 clear firewall all
FRR1:sh ping -c 3 -W 1 -I 10.200.0.1 172.16.10.10
FRR1:sh ping -q -c 200 -i 0.01 -s 1000 172.16.10.10
!sleep 5
JUN02 show firewall filter et-0/0/1.0-inet-i | no-more
JUN02 show firewall filter LIMIT-ICMP | no-more
JUN02 show bgp summary | match "10.0.23" | no-more
# 遅い ping は落ちない
JUN02 clear firewall all
FRR1:sh ping -q -c 20 -i 0.2 172.16.10.10
!sleep 5
JUN02 show firewall filter et-0/0/1.0-inet-i | no-more
# 単独のフィルタ(並びにしない)で policer の量: 64k・burst 15k で 1000 バイトを 100 個/秒 × 2 秒
JUN02 configure
JUN02 delete interfaces et-0/0/1 unit 0 family inet filter input-list
JUN02 set interfaces et-0/0/1 unit 0 family inet filter input LIMIT-ICMP
JUN02 commit and-quit
JUN02 clear firewall all
FRR1:sh ping -q -c 200 -i 0.01 -s 1000 172.16.10.10
!sleep 5
JUN02 show firewall filter LIMIT-ICMP | no-more
JUN02 clear firewall all
FRR1:sh ping -q -c 300 -i 0.01 -s 1000 172.16.10.10
!sleep 5
JUN02 show firewall filter LIMIT-ICMP | no-more
