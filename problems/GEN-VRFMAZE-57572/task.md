# 問題 GEN-VRFMAZE-57572 : VRF 迷路 — サブインターフェイス折り返しチェーン（おまけ・難易度2）

## 状況

これは、通常の演習の合間の、1つの「おまけ」の問題です。

あなたのラボには、**RT01** と **RT02** という2つのルータが、**1本の物理リンク**
(`Ethernet0/0`) だけで、接続されています。この1本のリンクの上に、
dot1q サブインターフェイスによって、**6 本の「廊下」**が、構成されています。

RT01 は、**迷路の本体**です。4 個の VRF（以下「部屋」）を持ち、パケットは、
START の部屋から、廊下を渡って RT02 で折り返し、**そのたびに 1 つ先の部屋へ**
入り直しながら、GOAL の部屋を目指すことが、意図されています。RT02 は、
**折り返しの役**です。廊下のペアごとに 1 つの VRF（TURN）で、パケットを
折り返します。各 VRF の中の経路は、スタティック・ルートによって、縫われています。

しかしながら、直近の巡回検証において、この迷路は、**下記の設計仕様書の
とおりには動作していない**ことが、報告されています。あなたのタスクは、
原因を特定し、迷路が設計仕様書のとおりに動作することを、確実にすることです。

```
        ┌──────────── 廊下1 (VLAN 210) ───────────┐
 RT01   ├──────────── 廊下2 (VLAN 570) ───────────┤   RT02
(迷路)  ├──────────── ...  計6本 すべて Et0/0 上 ──────┤ (折り返し)
        └──────────── 廊下6 (VLAN 734) ──────┘
```

## 設計仕様書（正典）

### 部屋（RT01 の VRF）

| # | VRF | rd | Loopback |
|---|-----|----|----------|
| 1 | ROOM-IVORY | 65000:101 | Loopback11 = 172.24.223.1/32 (START) |
| 2 | ROOM-OLIVE | 65000:102 | - |
| 3 | ROOM-GREEN | 65000:103 | - |
| 4 | ROOM-RUBY | 65000:104 | Loopback99 = 172.24.220.1/32 (GOAL) |

### 廊下（サブインターフェイス。サブIF番号 = VLAN ID・/30 の RT01 側 = .1 / RT02 側 = .2）

| 歩 | VLAN | 中継サブネット | RT01 側 VRF | RT02 側 VRF | 進行方向 |
|----|------|----------------|-------------|-------------|----------|
| 1 | 210 | 10.74.1.0/30 | ROOM-IVORY | TURN1 | RT01 → RT02 |
| 2 | 570 | 10.74.2.0/30 | ROOM-OLIVE | TURN1 | RT02 → RT01 |
| 3 | 818 | 10.74.3.0/30 | ROOM-OLIVE | TURN2 | RT01 → RT02 |
| 4 | 145 | 10.74.4.0/30 | ROOM-GREEN | TURN2 | RT02 → RT01 |
| 5 | 724 | 10.74.5.0/30 | ROOM-GREEN | TURN3 | RT01 → RT02 |
| 6 | 734 | 10.74.6.0/30 | ROOM-RUBY | TURN3 | RT02 → RT01 |

### 経路の縫い方

- 各 VRF は、**GOAL (172.24.220.1/32) 宛の順路**と、**START (172.24.223.1/32) 宛の帰路**の、
  スタティック・ルートを、上表の歩順のとおりに持つ（出口サブIF＋対向 IP 指定）。
- START の部屋には帰路は不要であり、GOAL の部屋には順路は不要です。

## 要求される最終状態

1. `ping vrf ROOM-IVORY 172.24.220.1 source 172.24.223.1` が、成功すること。
2. `ping vrf ROOM-RUBY 172.24.223.1 source 172.24.220.1` （帰路）も、成功すること。
3. `traceroute vrf ROOM-IVORY 172.24.220.1 source 172.24.223.1` が、**ちょうど 6 歩**で、
   上表の順路のとおりの中継 IP を示すこと（近道も、遠回りも、あってはなりません）。

## 遵守事項

- RT01 / RT02 の**どちらにも**原因がある可能性があります（原因の種類・数は伏せる）。
- 追加の VRF・リンク・ルーティング・プロトコルを、導入してはなりません。
  スタティック・ルートは、設計仕様書の縫い順のもの**のみ**が、許可されます。
- 迷路を短絡させる直接経路（部屋を飛ばすルート・リーク等）は、禁止です。
