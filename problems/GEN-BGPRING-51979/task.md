# 障害対応 GEN-BGPRING-51979 : トランジット トラフィックの排除（難易度4）

## 状況

あなたの会社のルータ(RT02)は、2つの通信事業者(RT03 および RT01)に、eBGP によって、接続されています。回線の使用率の監視において、あなたの会社のものではないところのトラフィックが、あなたの回線を通過している、ということが、検出されました。これは、意図された動作ではありません。

## トポロジ（物理）

```
  RT01 ──── RT02
   │          │
  RT04 ──── RT03
```
リンク一覧(接続・アドレス):
```
  RT01:E0/0(.1) ── RT02:E0/0(.2)   10.109.137.0/30
  RT02:E0/1(.1) ── RT03:E0/0(.2)   10.214.74.0/30
  RT03:E0/1(.1) ── RT04:E0/0(.2)   10.8.228.0/30
  RT04:E0/1(.1) ── RT01:E0/1(.2)   10.43.214.0/30
```

各ルータの Loopback1 が、拠点のネットワーク(/24)です。論理構成(AS 番号・ピアリングの詳細)は、示されていません。機器において、確認してください。

## 要件

1. 他の組織の間のトラフィックが、あなたの会社のAS(RT02)を、経由してはなりません。
2. あなたの会社のネットワーク(`172.16.180.0/24`)の、両事業者への広告は、維持されていること。
3. この制御は、route-map によって、実装されること。フィルタ・リスト(as-path filter-list)の使用は、承認されていません。
4. すべてのネットワークへの到達性が、維持されていること。

## 遵守事項

1. 構成の変更は、あなたの会社の管理下にあるところのデバイスにおいてのみ、許可されています。
2. BGP セッションの削除、および、スタティック・ルートの追加は、許可されていません。

## アクセス・採点

SSH で各機にログイン（`SUZUKI / CCNP`・mgmt IP は出題時に提示）。

```
ansible-playbook playbooks/grade.yml -e problem=GEN-BGPRING-51979 --vault-password-file <(printf 'CCNP\n')
```
