# 障害対応 GEN-STP-88339 : MST リージョンと旧機の境界が設計書と一致しない

## 状況
分配層 2 台(SW01・SW02)とアクセス層 2 台(SW03・SW04)のキャンパス L2 です。SW01〜SW03 は MST、SW04 は MST 非対応の旧機(Rapid PVST+)で、リージョンの境界になっています。
定期点検の結果、スパニングツリーの状態が設計書と一致しないことが判明しました。運用から次の申告も上がっています。

> - アクセススイッチ 1 台が、リージョンの外にいるように見える。
> - 特定 VLAN だけ、アクセススイッチ SW03 から他のスイッチへ疎通しない(STP の状態は正常に見える)。
> - 特定インスタンスの通信が、アクセス層から見て遠回りの経路を通っている。

設計書どおりの状態に復旧してください。**原因は 1 か所とは限りません。**

## 設計書(抜粋)

| 項目 | 設計 |
|---|---|
| MST リージョン | SW01・SW02・SW03。名前 `BLDG-A`・リビジョン 7。インスタンス1= VLAN131・VLAN219、インスタンス2= VLAN139(それ以外の VLAN は IST) |
| SW04 | MST 非対応の旧機。Rapid PVST+ のまま運用する(リージョン外)。パスコスト方式は long |
| CIST・インスタンス1 | root= SW01(priority 24576)・予備 root= SW02(priority 28672) |
| インスタンス2 | root= SW02(priority 24576)・予備 root= SW01(priority 28672) |
| アクセス層(SW03・SW04)の priority | 既定のまま(どの VLAN・インスタンスでも root にならない) |
| DS 間 2 本の使い分け | 正常時、インスタンス1 はリンク1(Et0/0 同士)、インスタンス2 はリンク2(Et0/1 同士)で転送する。ポート単位・インスタンス単位のパスコスト変更は使用しない |
| DS 間ポート | BPDU が途絶えても転送状態へ移行させない(両端) |
| DS のアクセス向きポート(Et0/2・Et0/3) | アクセス側から優位な BPDU を受けても root の座を明け渡さない |
| アクセスのエッジ(Et1/0〜Et1/3) | 端末の接続時は待たずに転送を始める。BPDU を受けたら直ちに遮断する |
| trunk | 802.1Q・許可 VLAN は 131,139,219 のみ(全 trunk 共通) |

## 構成台帳

| 機器 | 役割 | 配線 |
|---|---|---|
| SW01 | 分配 DS1(MST) | Et0/0・Et0/1→SW02 / Et0/2→SW03 / Et0/3→SW04 |
| SW02 | 分配 DS2(MST) | Et0/0・Et0/1→SW01 / Et0/2→SW03 / Et0/3→SW04 |
| SW03 | アクセス AS1(MST) | Et0/0→SW01 / Et0/1→SW02 / Et1/0〜Et1/3= エッジ |
| SW04 | アクセス AS2(旧機・Rapid PVST+) | Et0/0→SW01 / Et0/1→SW02 / Et1/0〜Et1/3= エッジ |

SVI(疎通確認用): VLAN131= 10.188.131.<SW 番号>/24 / VLAN139= 10.188.139.<SW 番号>/24 / VLAN219= 10.188.219.<SW 番号>/24

## 注意
- 管理 VLAN(999)・各機の Ethernet3/3 には触れないこと。
- SW04 のスパニングツリーのモードは変更しないこと。
