# JNT-01 — J0: IOS・IOS XR から Junos へ

## 進め方の約束

- JUN01 と JUN02 は、管理用の接続のほかに何も設定されていません。両方ともあなたが設定します。
- FRR1 は設定済みです。変更しないでください。コンソールから見る(`show` コマンド)ことはできます。
- **Topology** タブで機器をクリックすると、その機器のコンソールが開きます。Junos のルータには `admin` でログインしています。
- 各課題には、成り立つべきことを書いています。使うコマンドは書いていません。**確認**ボタンは機器の状態を見ます。
- 課題は順番に進めてください。後の課題は前の課題の結果を使います。

## トポロジ

```
JUN01 et-0/0/0 ──── et-0/0/0 JUN02 et-0/0/1 ──── eth1 FRR1
         10.0.12.0/30                 10.0.23.0/30
```

| 機器 | インターフェース | アドレス |
|---|---|---|
| JUN01 | et-0/0/0.0 | 10.0.12.1/30 |
| JUN01 | lo0.0 | 192.168.0.1/32 |
| JUN02 | et-0/0/0.0 | 10.0.12.2/30 |
| JUN02 | et-0/0/1.0 | 10.0.23.1/30 |
| JUN02 | lo0.0 | 192.168.0.2/32 |
| FRR1 | eth1 | 10.0.23.2/30 |
| FRR1 | lo | 192.168.0.3/32 |
| FRR1 | lo(サーバの網) | 198.51.100.1/24 |

FRR1 は eth1 で OSPF を area 0 で動かし、192.168.0.3/32 を広告しています。サーバの網 198.51.100.0/24 は広告していません。

## J0 IOS・IOS XR から Junos へ

単元 J0 に沿った課題です。IOS で身につけたこと(アドレス・OSPF・静的経路)を使い、Junos の作法で組んでください。

### 課題 J0-1  2 台の Junos ルータにアドレスを付ける

表のアドレスを JUN01 と JUN02 のリンクと lo0 に設定し、有効にしてください。
各ルータは、すべてのリンクで隣の機器からの ping に応答すること。

### 課題 J0-2  3 台で OSPF を動かす

JUN01 と JUN02 で、3 台の間のリンクとループバックに OSPF を area 0 で動かしてください。
ループバックでは隣接を作らないこと。
FRR1 は JUN01 と JUN02 のループバックを OSPF で学ぶこと。JUN01 のループバックから FRR1 のループバック(192.168.0.3)へ届くこと。

### 課題 J0-3  自分で元に戻る形で、危ない変更を試す

同僚から、ジャンボ フレームのために、JUN02 の FRR1 向けのインターフェースの MTU を 9000 バイトに上げてほしいと頼まれました。FRR1 は今日は変更できません。

数分以内(時間はあなたが決める)に確定しなければ JUN02 が自分で以前の設定に戻る形で、この変更を入れてください。
JUN02 と FRR1 の間の OSPF がどうなるかを見てください。変更で OSPF が壊れたら、変更を確定しないでください。
JUN02 に自分で戻させてください。

最後に、JUN02 と FRR1 の隣接が Full に戻り、そのインターフェースの MTU が 9000 でないこと。

### 課題 J0-4  FRR1 のループバックを経由してサーバの網へ届く

198.51.100.0/24 のサーバは FRR1 の後ろにあり、FRR1 はこの網を OSPF で広告していません。

JUN02 に、198.51.100.0/24 への静的経路を追加してください。次ホップは、リンクのアドレスではなく FRR1 のループバック
(192.168.0.3)とします。FRR1 とのリンクのアドレスを付け直しても、経路を書き換えずに済むようにするためです。
FRR1 が将来この網を OSPF に外部経路として広告し始めたら、JUN02 は静的経路でなく OSPF の経路を使うこと。

JUN02 のループバックから 198.51.100.1 へ届くこと。OSPF の設定は変更しないでください。
