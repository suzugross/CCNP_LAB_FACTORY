# 障害対応 GEN-BGPRING-48328 : 拠点間の経路交換の回復（難易度4）

## 状況

あなたの会社は、2つの拠点(RT02 および RT04)を、運用しています。それぞれの拠点は、2つの通信事業者(RT03 および RT01)のそれぞれと、eBGP によって、接続されています。拠点のネットワークは、対向の拠点へ、事業者の網を経由して、広告されることが、意図されています。
現在、拠点の間の通信が、確立できない、ということが、報告されています。

## トポロジ（物理）

```
  RT01 ──── RT02
   │          │
  RT04 ──── RT03
```
リンク一覧(接続・アドレス):
```
  RT01:E0/0(.1) ── RT02:E0/0(.2)   10.140.242.0/30
  RT02:E0/1(.1) ── RT03:E0/0(.2)   10.126.252.0/30
  RT03:E0/1(.1) ── RT04:E0/0(.2)   10.88.67.0/30
  RT04:E0/1(.1) ── RT01:E0/1(.2)   10.233.228.0/30
```

各ルータの Loopback1 が、拠点のネットワーク(/24)です。論理構成(AS 番号・ピアリングの詳細)は、示されていません。機器において、確認してください。

## 要件

1. それぞれの拠点が、対向拠点のネットワーク(`172.16.70.0/24` / `172.16.123.0/24`)へ、到達することができること。
2. 対向拠点への経路が、**両方の事業者を経由するところの、2つの経路**として、保持されていること(片系の障害に、備えるため)。
3. 経路の AS パスが、実際に経由するところの AS を、正しく反映していること。

## 遵守事項

1. お客様のASに対する経路広告の内容に関するものを除き、事業者装置(RT03 / RT01)の構成は、変更されてはなりません。
2. スタティック・ルートの追加、および、既存のアドレス設計の変更は、許可されていません。

SSH で各機にログイン（`SUZUKI / CCNP`・mgmt IP は出題時に提示）。

