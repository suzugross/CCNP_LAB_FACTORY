# [PoC] containerlab 学習モード — Junos × FRR

> containerlab のラボをワークスペースで解く確かめ用です(採点する問題ではありません)。

## トポロジ

```
JUN01 et-0/0/0 ──── eth1 FRR1
       10.0.14.0/30
```

| 機器 | インターフェース | アドレス |
|---|---|---|
| JUN01 | et-0/0/0.0 | 10.0.14.1/30 |
| JUN01 | lo0.0 | 192.168.0.1/32 |
| FRR1 | eth1 | 10.0.14.2/30 |
| FRR1 | lo | 192.168.0.4/32 |

FRR1 は設定済みです。変更しないでください。

## M0 操作に慣れる

JUN01 は管理用の接続のほかに設定がありません。Topology タブで機器をクリックすると、その機器のコンソールが開きます。

### 課題 M0-1  リンクとループバックにアドレスを付ける

表のアドレスを JUN01 の et-0/0/0.0 と lo0.0 に設定し、有効にしてください。

### 課題 M0-2  FRR1 と経路を交換する

JUN01 と FRR1 の間で OSPF を area 0 で動かしてください。JUN01 はループバックを広告し、ループバックでは隣接を作らないこと。
JUN01 のループバックから、FRR1 のループバック(192.168.0.4)へ ping が通ること。
