1. **VRF**: `TENANT-A` (rd **65000:120**) = `Ethernet0/0`, `Ethernet0/1` /
   `TENANT-B` (rd **65000:240**) = `Ethernet0/2`。リンクアドレスは現行計画を維持。
2. **EIGRP**: named mode の単一仮想インスタンス **`AGGR01`** に両テナントの
   アドレスファミリを収容。テナントA = **AS 120** / テナントB = **AS 240**。
3. **認証**: テナントA の CE 向け IF は **MD5**
   (key chain **`KC-A`** / key **6** / key-string **`Ten8987Key`**)。
4. **集約**: テナントA site2 (RT04) へは site1 の 2 つの /24 を
   **`172.25.164.0/23` に集約して広告**。site2 に明細 /24 を見せない。
