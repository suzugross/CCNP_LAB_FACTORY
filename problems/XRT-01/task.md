# XR トラック 01 — 入り方と調べ方／設定の管理

このラボは、XR トラックの 2 つの単元 **M0 入り方と調べ方** と **M1 設定の管理** の実践編です。
先に単元の読み物を読み、その後でここの課題に取り組みます。ラボは 2 単元で共用します。M0 を先に行います。

## 進め方の約束

- 設定するのは **XR01 だけ**です。RT01 と RT02 は据え付けで、変更しません。ログインして表示を見るのは構いません。
- コマンド例は示しません。各課題は求める挙動だけを述べます。CLI のヘルプ(`?`)、`show` コマンド、
  Cisco IOS XR のコンフィギュレーション ガイドとコマンド リファレンスを使って、コマンドを自分で探します。
- **Steps** タブに課題ごとの **確認** ボタンがあります。機器のいまの状態を読みます。
  押す前に設定モードを抜けてください。
- ヒントは 1 段ずつ開きます(キーワード → 参照先 → コマンド)。開いた段数は記録されます。
- ラボのログイン情報でログインします。管理アクセス(インターフェイス `MgmtEth0/RP0/CPU0/0`、VRF `MGMT`)は
  最後まで動作し続ける必要があります。確認はこの経路で XR01 に到達します。

## トポロジ

| リンク | XR01 | 対向 | アドレス |
|---|---|---|---|
| LINK1 | GigabitEthernet0/0/0/0 | RT01 Ethernet0/0 | 10.0.12.0/24(XR01 .1、RT01 .2)、2001:DB8:12::/64(XR01 ::1、RT01 ::2) |
| LINK2 | GigabitEthernet0/0/0/2 | RT01 Ethernet0/1 | 10.0.21.0/24(XR01 .1、RT01 .2) |
| CUST-A | GigabitEthernet0/0/0/1 | RT02 Ethernet0/0 | 10.0.13.0/24(XR01 .1、RT02 .2) |
| LINK3 | GigabitEthernet0/0/0/3 | RT01 Ethernet0/2 | 10.0.31.0/24(XR01 .1、RT01 .2) |

- XR01 の Loopback0 は 1.1.1.1/32、RT01 の Loopback0 は 2.2.2.2/32 です。
- RT01 は OSPF プロセス 1 のエリア 0 を LINK1、LINK2、LINK3、Loopback0 で実行しています。LINK3 は MD5 認証を使用します。OSPF に含まれない 8.8.8.8/32 も
  保持しており、LINK1 上で XR01 と eBGP ピアリングする準備ができています(RT01 は AS 65002、XR01 は AS 65001 を想定)。
- RT02 は顧客 A の CE です。LAN は 172.16.2.0/24(RT02 は 172.16.2.1)で、XR01 へのデフォルト ルートを持ちます。

## M0 — 入り方と調べ方

XR01 は設定が途中の状態で引き渡されました。設定の一部は入っていますが、誤っているか不完全です。
変更する前に、何が入っているかを調べます。

### 課題 M0-1

XR01 と RT01 が、LINK1 上で IPv4 と IPv6 の両方で相互に到達できることを確認します。

### 課題 M0-2

XR01 が LINK1 上の OSPF で RT01 から 2.2.2.2/32 を学習し、RT01 が XR01 から 1.1.1.1/32 を学習することを確認します。
LINK1 はエリア 0 のリンクである必要があります。LINK2 と LINK3 は現状のままにします(課題 M1-6 と M1-7 で扱います)。

### 課題 M0-3

顧客 A は、グローバル ルーティング テーブルから分離されている必要があります。
RT02 へのリンクが VRF `CUST-A` に属し、アドレスを保持し、XR01 がその VRF 内で顧客の LAN 172.16.2.0/24 に
到達できることを確認します。リンクのサブネットは、グローバル テーブルに現れてはなりません。

### 課題 M0-4

XR01 が、宛先不明のトラフィックを LINK1 経由で RT01 に転送することを確認します。XR01 に設定するルートを使用します。
XR01 は 8.8.8.8 に到達できる必要があります。

## M1 — 設定の管理

課題がラベルを指定している場合は、そのコミットに必ずラベルを付けます。確認はラベルでコミットを探します。
ラベルは 1 回しか使えません。ラベル付きのコミットをやり直す場合は、ラベルの末尾に `-2`、`-3` … を付けます
(例: `M1-T3-2`)。確認はそれらのうち最も新しいものを使います。

### 課題 M1-1

**ラベル:** `M1-T1`(2 つ目)

1. そのまま残ると自分が切り離される変更を行います。XR01 の LINK1 を管理上ディセーブルにします。
   以後何も操作しなければ XR01 が自動的に以前の設定に戻す方法で、この変更を適用します。
   何も操作せず、LINK1 が復旧したことを確認します。
2. アドレス 10.50.50.50/32 の Loopback50 を追加します。同じ方法で、ラベル `M1-T1` を付けて適用し、
   今回は XR01 が以前の設定に戻す前に、変更を恒久的なものにします。

### 課題 M1-2

**ラベル:** `M1-T2A`(1 つ目)、`M1-T2B`(2 つ目)

1. アドレス 10.61.61.61/32 の Loopback61 を、ラベル `M1-T2A` のコミットで追加します。
2. アドレス 10.62.62.62/32 の Loopback62 を、別のコミット(ラベル `M1-T2B`)で追加します。
3. `M1-T2A` が行った内容だけを取り消します。逆の設定を自分で入力してはなりません。`M1-T2B` は取り消しません。

### 課題 M1-3

**ラベル:** `M1-T3`(課題を完了するコミット。最初の拒否されるコミットではラベルは消費されません)

ラベル `M1-T3` の **1 回の**コミットで、LINK1 上の RT01 との eBGP セッションを確立し(XR01 は AS 65001、
ルータ ID 1.1.1.1)、アドレス 10.70.70.70/32 の Loopback70 を追加します。XR01 は、すべてを受け入れる
`RP-IN` という名前の着信ポリシーを通じて、RT01 が送信するプレフィックスを受け入れる必要があります。

最初は `RP-IN` を定義**せずに**コミットを試みます。修正する前に、次の点を自分で答えます。

- コミットが拒否された理由は何か。XR01 はそれをどこで示しているか。
- Loopback70 は実行コンフィギュレーションに入ったか。
- 入力した設定は失われたか。

その後、課題を完了します。

### 課題 M1-4

XR01 への 2 つ目のセッションを開き(たとえば RT01 から 10.0.12.1 へ Telnet)、同時に 2 つのセッションを持ちます。

1. セッション A でコンフィギュレーション モードに入り、変更をコミットせずに用意します。セッション B で
   別の変更をコミットします。次にセッション A でコミットし、XR01 が示す内容を読みます。
2. セッション A で、自分が入っている間は他の誰も実行コンフィギュレーションを変更できない方法で、
   コンフィギュレーション モードに入ります。セッション B で変更のコミットを試みます。
   誰がロックを保持しているかを、セッション B から調べます。

セッション A がロックを保持している間に **確認** を押します。その後、両方のセッションで
コンフィギュレーション モードを抜け、コミットしていない内容は破棄します。

### 課題 M1-5(確認なし)

コンフィギュレーション モードに入り、ホスト名 `XR01-NEW` だけを用意します。コミット**しません**。

用意した内容でコンフィギュレーション全体を置き換えた場合に、実行コンフィギュレーションから何が削除されるかを
正確に調べます。次の点を自分で答えます。置き換えた後も、確認は XR01 に到達できるか。
その後、用意した変更を破棄します。

### 課題 M1-6

NOC から、XR01 に一連の変更が行われて以降、LINK2 上の XR01 と RT01 の間の OSPF 隣接関係がダウンしていると
報告がありました。複数の変更がコミットされていますが、原因はそのうちの 1 つだけです。

隣接関係を壊した変更を特定し、その変更だけを取り消します。他の変更は残す必要があります。
RT01 は変更しません。

### 課題 M1-7

変更 `CHG2001` は変更期間外に行われたため、完全に取り消す必要があります。`CHG2001` が変更した XR01 の部分は、
すべて変更前とまったく同じ状態である必要があります。変更前に設定されていた値は、どこにも記録されていません。
XR01 にコミットされたその他の内容(`CHG2001` の前後を問わず、前の課題で行った作業を含む)は、すべて残す必要があります。
RT01 は変更しません。
