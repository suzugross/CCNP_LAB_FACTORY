# 問題 GEN-TWIST-11599 : OSPF ルートフィルタ（自動生成・tree・4台）

各ルータ間リンクと Loopback には IP 設定済み。

## 要件
1. OSPF プロセス 1 / エリア 0 を全ルータ・全リンク・全 Loopback で構成し、すべてのルータが他の全ルータの Loopback に到達できるようにせよ。
2. ただし **RT01** は **RT02 の Loopback (`21.21.21.21/32`)** を自身のルーティングテーブルに**保持しないこと**。
   - 他の全ルータは `21.21.21.21/32` へ到達できること。
   - RT01 自身も、RT02 以外の全 Loopback へは到達できること。

## ループバック
- RT01: 83.83.83.83/32
- RT02: 21.21.21.21/32
- RT03: 41.41.41.41/32
- RT04: 60.60.60.60/32
