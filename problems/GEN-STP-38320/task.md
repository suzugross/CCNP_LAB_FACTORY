# 障害対応 GEN-STP-38320 : キャンパス L2 のスパニングツリーが設計書と一致しない

## 状況
分配層 2 台(SW01・SW02)とアクセス層 2 台(SW03・SW04)で構成されたキャンパス L2 です。
定期点検の結果、スパニングツリーの状態が設計書と一致しないことが判明しました。
運用から次の申告も上がっています。

> - 新設 VLAN について、設計書と実際の root ブリッジが一致しないとの点検結果がある。
> - アクセススイッチの上りリンクの 1 本が、起動以来一度も使われていない。

設計書どおりの状態に復旧してください。**原因は 1 か所とは限りません。**

## 設計書(抜粋)

| 項目 | 設計 |
|---|---|
| STP モード | 全スイッチ Rapid PVST+ |
| VLAN242・VLAN138 | root= SW02(priority 24576)・予備 root= SW01(priority 28672) |
| VLAN77 | root= SW01(priority 24576)・予備 root= SW02(priority 28672) |
| アクセス層 | root にも予備 root にもならない(bridge priority は既定のまま) |
| DS 間 2 本の使い分け | VLAN242・VLAN138 はリンク1(Gi0/0 同士)、VLAN77 はリンク2(Gi0/1 同士)で転送する |
| DS 間ポート | 両端で loop guard |
| DS のアクセス向きポート(Gi0/2・Gi0/3) | root guard |
| アクセスのエッジ(Gi1/0〜Gi1/3) | PortFast+BPDU ガード。BPDU を受けたポートは err-disabled のまま保持する(復旧は申請後) |
| trunk | 802.1Q・許可 VLAN は 77,138,242 のみ(全 trunk 共通) |
| パスコスト | 既定(short)・VLAN ごとのコスト変更はしない |

## 構成台帳

| 機器 | 役割 | 配線 |
|---|---|---|
| SW01 | 分配 DS1 | Gi0/0・Gi0/1→SW02 / Gi0/2→SW03 / Gi0/3→SW04 |
| SW02 | 分配 DS2 | Gi0/0・Gi0/1→SW01 / Gi0/2→SW03 / Gi0/3→SW04 |
| SW03 | アクセス AS1 | Gi0/0→SW01 / Gi0/1→SW02 |
| SW04 | アクセス AS2 | Gi0/0→SW01 / Gi0/1→SW02 |
| SW05 | 持ち込み機器(管理外・ログイン禁止) | SW04 Gi1/3(未使用ポート・駐車 VLAN 99)に接続 |

SVI(疎通確認用): VLAN77= 10.137.77.<SW 番号>/24 / VLAN138= 10.137.138.<SW 番号>/24 / VLAN242= 10.137.242.<SW 番号>/24

## 注意
- 管理 VLAN(999)・各機の GigabitEthernet3/3 には触れないこと。SW05 にはログインしないこと。
- 設計書にない設定で辻褄を合わせないこと(採点は設計書との一致も見る)。
