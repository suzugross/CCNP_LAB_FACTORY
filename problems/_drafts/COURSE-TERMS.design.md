# 教材の日本語の用語 — 訳しすぎない(BL-282)

2026-11-17 ユーザ指摘で起票し、同日ルールを決めた。CLAUDE.md の読み物 §2・§6 の規定の全文。

## 1. 経緯

- ユーザ指摘:「非キーの欄は、普通は日本語でもノンキー フィールドと言う。訳しすぎな用語が目立つ。」
- そういう規定はなかった。書き下ろし教材は英語版が原文で、日本語版は英語から起こしている。その時に英単語を
  一語ずつ一般語へ和訳した、書き手の癖による。「読みやすい日本語」を「カタカナを減らす」と取り違えた。
- 用語集にも collector = 収集役 と登録し、訳しすぎを固定していた(本文の「収集役」は 112 回)。以前の設計メモ
  (GEN-FNFTS)では「コレクタ」と書いており、方針として選んだものではない。
- 訳しすぎは 3 つの型に分かれる。
  1. **和語への置き換え**: 欄(field)・収集役(collector)・輸出/輸入(export/import)・印を付ける(marking)・
     版 9(version 9)・鎖(chain)
  2. **複合語を「の」でほどく**: フローのレコード・VPN のラベル・トランスポートのラベル・通知のビュー
  3. **直訳の造語**: 一致の型(match type)・終端の動作(terminating action)・信頼の起点(trust anchor)

## 2. ルール(2026-11-17 決定)

| # | 規定 |
|---|---|
| R1 | **用語は、日本のネットワーク エンジニアが普段使う言い方で書く**。カタカナ語が定着していればカタカナ(ノンキー フィールド・コレクタ・エクスポート)、漢語が定着していれば漢語(秘密鍵・証明書・輻輳・集約経路)。どちらも無ければ英語のまま書く。英語の原文の単語を一語ずつ和訳しない |
| R2 | **確かめ方**: その語で検索し、ベンダーの日本語の文書や解説サイトにその形で出てくるかを見る。出てこない訳語は作らない。形が割れていれば多いほうを採る |
| R3 | **複合語を「の」でほどかない**: フロー レコード・VPN ラベル・トランスポート ラベル |
| R4 | **たとえは説明の中だけで使う**: 仕組みを説明するところで一度「RT は経路に付ける荷札のようなもの」と言う。それ以後の本文・見出し・表では用語(RT・マーキング・署名)で書く |
| R5 | **説明の文は平易なままにする**: そろえるのは用語だけ。用語の意味を言う文は今までどおりかみ砕く(例: ノンキー フィールド= フローを分けるのには使わず、記録するだけの値) |
| R6 | **表記**: カタカナの複合語の区切りは、今の教材と同じく半角スペース(フロー キャッシュ)。長音の有無などの表記は、ベンダーの日本語の文書の表記に合わせる(コレクタ・フィルタ) |
| R7 | **用語集(`glossary/*.yml`)の `ja` の訳語も同じ基準で決める**。新しい語を足す時も R1〜R6 で確かめる |

### R2 の取り方の注意

- Cisco の日本語の文書(cisco.com)は直接取ってよい。
- **juniper.net は robots.txt で全ロボットを拒否している**ので自動で取りに行かない(CLAUDE.md の裏どりの節と同じ)。
  Junos の用語は検索結果・Juniper の KB・解説サイトで見て、それでも決まらなければユーザに判定してもらう。
- 判定に迷う語は、勝手に決めず候補の一覧に載せてユーザが判定する。

## 5. 直す手順(BL-282 の残り)

1. **候補の一覧を作る**: 用語集の `ja` の訳語と、範囲の本文によく出る語から、R1〜R4 に当たりそうなものを機械的に拾う。
   「今の形・直す案・R2 の根拠(どこにその形で出てくるか)・出てくる回数」を並べ、ユーザが判定する。
   → 2026-11-17 作成= [COURSE-TERMS.candidates.md](COURSE-TERMS.candidates.md)(A 48・B 33・②の原則)。
2. **判定した対応表で直す**: 本文・用語集・読み物・ゲーム・素振り台の `ja`。英語版は変えない。
   - 日英で見出しの並びと段落の数をそろえる規定(読み物 §6)を崩さない。
   - 見出しを変えたら、実践ページの読み物へのリンクの文(`scripts/course.sh` が作る)と `learn.yml` の `read:` を確かめる。
   - 素振り台を変えたら `python3 topologies/cli_drill.py embedtest` を通す。
3. **作り直して同期する**: `scripts/course.sh <名前> …`・`scripts/read.sh build`・Drive の sync。

## 6. 再発の防止

- 英語の原文から日本語版を起こす時は、用語を英単語の和訳で置き換えない。R2 で確かめた形を使う。
- 用語集に新しい語を足す時も同じ。用語集の `ja` が、本文の用語の基準になる。
