# BL-282 候補の一覧 — 訳しすぎた用語(2026-11-17)

規定は [COURSE-TERMS.design.md](COURSE-TERMS.design.md)。この一覧は §5 ①(候補の一覧をユーザが判定する)。

## 0. 見方と判定の付け方

- **A**: 直す見込みの語。案どおりに直すのを既定にする。止めたい行・案を変えたい行だけ「判定」に書く。
- **B**: 判定が要る語。「判定」に ○(推しどおり)・×(残す)・別の案 を書く。
- **C**: 検討したうえで残す語(参考)。
- 「回数」の記号: X= XR の日本語版・J= Junos の日本語版・G= 学習ゲームと素振り台・R= 訳文の読み物・用= 用語集の `ja`。
  - 回数は機械的に数えた**おおよその数**。同じ字の別の意味(表の「列」、比喩の「道」、`組む` など)も混ざる。
    直す時は 1 か所ずつ文脈を見て、当たるものだけを直す。ゲームの数にはプログラムの注釈(画面に出ない)も入る。
- 「根拠」: R2 の確かめ方で見た資料。「定着」は、現場で迷う人がいない語として、個別の検索は省いたもの。
  判定に迷う A の行があれば、その行だけ検索して確かめる。

## 3. ②「の」でほどいた複合語 — 原則と主な語

## 6. 判定と結果(2026-11-17)

### 6.1 一覧に無かったが、同じ規定で直した主な語

- EVPN の経路: 種類 N の経路 → タイプ N ルート。名前は用語集の形(イーサネット自動検出ルートなど)。
- QoS: 1 速度 2 色 → シングル レート 2 カラー・2 速度 3 色 → 2 レート 3 カラー・階層の QoS → 階層型 QoS・信頼の境界 → 信頼境界・
  捨てられにくさ / 捨てられやすさ(drop precedence)→ ドロップ優先度(★日本語版の表は「捨てられにくさ」で、本文の「捨てられやすさ」と
  意味が逆向きに食い違っていた。この直しで解消)・流れ → フロー・遅れ / 揺れ → 遅延 / ジッタ・トラフィックの種類(DS-TE)→ クラス タイプ・
  洗浄の装置 → スクラビング センター。
- ルーティング・MPLS: ネクストホップ / 次のホップ → ネクスト ホップ・経路の漏らし → ルート リーク・付け所 → アタッチ ポイント・
  反映(route reflector)→ リフレクト・重み(weight)→ ウェイト・ラベルの表 → ラベル テーブル・束(LACP)→ バンドル・
  黙った故障 → サイレント障害・既定の VRF → デフォルト VRF・抑え(BFD の dampening)→ ダンプニング・FEC の種類 → FEC タイプ。

- Junos: 動作(action)→ アクション・表(inet.0 など)→ テーブル・静的 → スタティック・入れ物(container)→ コンテナ・
