# [PoC] containerlab 単独 OSPF (vJunos EVO ×2)

> containerlab だけで回す問題の基盤の確かめ用です(出題用ではありません)。

## トポロジ

```
JUN01 et-0/0/0 ── et-0/0/0 JUN02
        10.0.12.0/30
```

JUN02 は設定済みです。変更しないでください。

## 接続

```
ssh admin@172.20.20.2   # JUN01
ssh admin@172.20.20.3   # JUN02(確認用)
```

## 要件

1. JUN01 の et-0/0/0.0 に 10.0.12.1/30、lo0.0 に 192.168.0.1/32 を設定してください。
2. JUN01 で OSPF area 0 を有効にし、et-0/0/0.0 と lo0.0 を収容してください。lo0.0 は passive にしてください。
3. JUN01 の lo0 から JUN02 の lo0(192.168.0.2)へ ping が通ることを確認してください。
