# 障害対応 GEN-BGPRING-12669 : プレフィックス単位の経路制御（難易度4）

## 状況

4つの組織のルータが、リング状に、相互接続されています。あなたの会社(RT04)は、RT01 のネットワークを、RT03 に対して、中継しています。運用上の要請により、RT01 のネットワークのうちの1本(`172.16.121.0/24`)についてのみ、RT03 からのトラフィックを、もう一方の中継事業者(RT02)の側へ、寄せることとなりました。先般、そのための設定が、実施されています。しかしながら、その後の確認において、**RT01 のネットワークのすべて**が、RT02 の側を経由している、ということが、判明しました。

## トポロジ（物理）

```
  RT01 ──── RT02
   │          │
  RT04 ──── RT03
```
リンク一覧(接続・アドレス):
```
  RT01:E0/0(.1) ── RT02:E0/0(.2)   10.9.50.0/30
  RT02:E0/1(.1) ── RT03:E0/0(.2)   10.250.254.0/30
  RT03:E0/1(.1) ── RT04:E0/0(.2)   10.227.181.0/30
  RT04:E0/1(.1) ── RT01:E0/1(.2)   10.7.167.0/30
```

各ルータの Loopback1 が、拠点のネットワーク(/24)です。論理構成(AS 番号・ピアリングの詳細)は、示されていません。機器において、確認してください。

## 要件

1. RT03 から `172.16.121.0/24` へのトラフィックは、RT02 を経由すること（この動作は、すでに実現されており、維持されなければなりません）。
2. RT03 から RT01 のその他のネットワークへのトラフィックは、あなたの会社(RT04)を、経由すること。
3. RT03 は、あなたの会社のネットワーク(`172.16.225.0/24`)に対して、あなたの会社を経由して、到達すること。
4. 経路制御は、既存の route-map によって、実装されていること。`172.16.121.0/24` に対する AS パスの付加は、維持されること。
5. すべてのネットワークへの到達性が、維持されていること。

## 遵守事項

1. 構成の変更は、あなたの会社の管理下にあるところのデバイス(RT04)においてのみ、許可されています。
2. BGP セッションの削除、および、スタティック・ルートの追加は、許可されていません。
