## 設問

名前付きモードの EIGRP で、左側の①〜④のコマンドを入力するモードを、右側の A〜D から選択してください。

### 対応させる項目

| # | コマンド |
|---|------|
| ① | `metric weights 0 1 0 1 0 0` |
| ② | `maximum-paths 2` |
| ③ | `address-family ipv4 unicast autonomous-system 100` |
| ④ | `authentication key-chain KC1` |

## 選択肢

A. アドレス ファミリ インターフェイス コンフィギュレーション モード (config-router-af-interface)#

B. アドレス ファミリ トポロジ コンフィギュレーション モード (config-router-af-topology)#

C. ルータ コンフィギュレーション モード (config-router)#

D. アドレス ファミリ コンフィギュレーション モード (config-router-af)#
