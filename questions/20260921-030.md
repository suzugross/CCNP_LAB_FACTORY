# 問題 20260921-030

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

MPLS 網の保護(MPLS-TE Fast Reroute・LFA・SRLG)について、正しく述べられているものは、次のうちどれですか。(1つを選択してください)

## 選択肢

A. SRLG-disjoint では、プライマリ経路と同じ SRLG に属するリンクをバックアップ経路の候補から除外する。

B. MPLS-TE Fast Reroute は、IP 網でのみ使用できる。

C. LDP のルータ ID は、明示的に構成されていない場合、ループバック・インターフェイスの中で最も大きい IP アドレスが選ばれる。

D. SRLG は、同じ IGP エリアに属するリンクの集合である。
