# 問題 20260811-012

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたは、下記のネットワークの保守を担当する技術者です。ある企業のネットワークにおいて、RT02 は、顧客の側のネットワークと、サーバの側のネットワークとの間に、配置されています。

```
   RT03 (顧客の側)                     RT01 (サーバの側)
        |  10.125.253.0/24        10.125.254.0/24  |
  Ethernet1/0 --------- RT02 --------- Ethernet1/1
                 (被験のデバイス)
                        |
                  Ethernet1/2
              10.125.255.0/24 (管理セグメント)
```

## 要件

1. サーバの側のネットワークから、顧客の側のネットワークへ向かう通信には、影響を与えてはなりません。
2. 不要なトラフィックは、可能なかぎり早い段階において、破棄されなければなりません。
3. 管理のための構成に対して、変更が加えられてはなりません。
4. 顧客の側のネットワークから、サーバの側のネットワークへ向かう通信は、送信元が `10.125.160.0`、`10.125.161.0`、`10.125.162.0` のネットワークにあるものに限り、許可されなければなりません。
5. 示されているところのアクセス・リストは、変更されてはなりません。

## 現在の状態

```
RT02# show ip access-lists
Standard IP access list 20
    10 permit 10.125.160.0, wildcard bits 0.0.0.255
    20 permit 10.125.161.0, wildcard bits 0.0.0.255
    30 permit 10.125.162.0, wildcard bits 0.0.0.255
```

## 設問

示されているところのすべての要件を満たすためには、当該のアクセス・リストを、どこに、どの方向に適用しなければなりませんか。(1つを選択してください)

## 選択肢
A. `interface Ethernet1/2` において `ip access-group 20 in`

B. `interface Ethernet1/2` において `ip access-group 20 out`

C. `interface Ethernet1/0` において `ip access-group 20 out`

D. `interface Ethernet1/1` において `ip access-group 20 in`

E. `interface Ethernet1/0` において `ip access-group 20 in`

F. `interface Ethernet1/1` において `ip access-group 20 out`
