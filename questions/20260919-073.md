# 問題 20260919-073

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
P2# show mpls ldp neighbor detail
    Peer LDP Ident: 10.0.0.2:0; Local LDP Ident 10.0.0.4:0
        TCP connection: 10.0.0.2.646 - 10.0.0.4.14709; MD5 on
        State: Oper; Msgs sent/rcvd: 1020/1019; Downstream
        Up time: 02:13:40
        LDP discovery sources:
          Ethernet0/1; Src IP addr: 10.0.34.3
            holdtime: 15000 ms, hello interval: 5000 ms
        Addresses bound to peer LDP Ident:
          10.0.0.2        10.0.13.3       10.0.34.3
        Peer holdtime: 180000 ms; KA interval: 60000 ms; Peer state: estab
```

上は P2(10.0.0.4)で採った出力である。`Peer LDP Ident` の値は相手の LDP ルータ ID とラベル空間 ID の組で、末尾の :0 は［①］を意味する。`TCP connection` の行で、ポート 646 で待ち受けているのは［②］側で、一時ポートを使っている自分(10.0.0.4) 側が接続を開始した。これはトランスポートアドレス(既定はルータ ID)の［③］方がアクティブになる規則と一致する。`State: Oper` はセッション確立済み、`Downstream` はラベル配布が［④］であることを示す。`Addresses bound to peer` が重要なのは、自分の RIB のネクストホップ(10.0.34.3)がこの一覧に含まれていて初めて、相手から受けたラベルを LFIB に採用できるからである。

## 選択肢

A. 相手(10.0.0.2)

B. 自分(10.0.0.4)

C. Upstream Assigned

D. Downstream Unsolicited

E. 小さい

F. プラットフォーム全体のラベル空間

G. インターフェースごとのラベル空間

H. 大きい
