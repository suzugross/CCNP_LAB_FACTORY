# 問題 20260913-029

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

archive と構成の管理について、正しく述べられているものを、次のうちから 2 つ選択してください。

## 選択肢

A. archive の log config は、投入された構成コマンドの変更ログを記録する。

B. configure replace は、保存済みの構成へ差分だけを適用してロールバックする。

C. archive の time-period の単位は秒である。

D. archive の log config は、show や debug のコマンドも記録する。

E. show ip cef の drop のエントリは、そのプレフィックス宛のパケットが破棄されることを示す。
