## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

RSTP(802.1w)は 802.1D の役割と状態を整理し、収束を［①］にした。ポート役割は root・designated に加え、root port の予備である alternate port と、同じセグメントに自分のポートが 2 本ある時の予備である backup port を持つ。ポート状態は 802.1D の 5 つを三つに畳み、blocking と listening は discarding にまとめられた。BPDU は［②］が hello ごとに出し、［③］回続けて届かなければ隣接情報を捨てる(802.1D の max age を待たない)。2 台の間で designated port を即座に forwarding にする仕組みが［④］で、対向が全二重の［⑤］リンクであることが前提になる(半二重は shared 扱いで 802.1D と同じタイマ待ちになる)。端末が繋がるポートは edge port(PortFast) として宣言すると即 forwarding になり、トポロジ変化にも数えられない。トポロジ変化(TC)を受けたスイッチは edge 以外のポートで学習した MAC を消し、802.1D のように root へ TCN を上げる必要はない。対向が 802.1D しか話せない場合、そのポートだけが 802.1D(旧 STP)モードに落ちる。
