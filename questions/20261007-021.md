# 問題 20261007-021

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
! Hub
interface Tunnel0
 ip address 172.31.255.1 255.255.255.0
 no ip redirects
 ip mtu 1400
 ip tcp adjust-mss 1360
 ip nhrp authentication CCNP2026
 ［①］
 ip nhrp network-id 10
 ［②］
 no ip split-horizon eigrp 100
 tunnel source GigabitEthernet0/1
 tunnel mode gre multipoint
 tunnel key 100
 tunnel protection ipsec profile DMVPN-PROF
!
! Spoke(抜粋): ip nhrp nhs 172.31.255.1 nbma 203.0.113.1 multicast / tunnel mode gre multipoint
!              ip nhrp shortcut
```

この構成は Phase ［③］である。［①］は［④］ための行で、これが無いとスポークはハブからの Hello を受け取れず隣接が片側だけになる。no ip split-horizon eigrp 100 は同じ Tunnel から学んだスポークの経路を、他のスポークへ同じ Tunnel から広告するために要る(Phase に関係なく必須)。［②］が Phase を決める行で、スポークが持つ対向スポークの LAN 経路の next-hop はハブのトンネル IP(172.31.255.1)のままになる。この Phase でハブが対向スポークの経路を集約することは［⑤］。tunnel key は全メンバで一致させ、`no ip redirects` は Tunnel 上で ICMP Redirect を出さないための定石である。

## 選択肢

A. ip summary-address eigrp 100 0.0.0.0 0.0.0.0

B. 1

C. ip nhrp nhs dynamic

D. できる(next-hop はもともとハブ・Redirect で直接通信が成立)

E. ip nhrp map multicast dynamic

F. スポークからのマルチキャスト登録を受け付ける

G. 3

H. ip nhrp redirect

I. どちらの Phase でもできない

J. 登録してきたスポークの NBMA を Hello などマルチキャストの宛先に自動で加える
