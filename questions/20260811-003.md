> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたは、ネットワークの運用を担当しています。ある企業のネットワークにおいて、RT02 は、顧客の側のネットワークと、サーバの側のネットワークとの間に、配置されています。

```
   RT01 (顧客の側)                RT03 (サーバの側)
        |  10.148.253.0/24        10.148.254.0/24  |
        +--------- RT02 ---------+
                (被験のデバイス)
```

## 要件

1. RT02 において、`10.148.8.0/24`、`10.148.9.0/24`、`10.148.10.0/24` のネットワークからの通信のみが、サーバである `172.16.177.65` の TCP ポート 443 に到達できなければなりません。
2. 当該のサーバの他のポートへの通信、および当該のサーバ以外の宛先への通信は、許可されてはなりません。
3. 本作業は、日中の時間帯において実施されるという理由により、対象外であるところのデバイスに対する構成の変更は、許可されていません。
4. `10.148.13.0/24` からの通信は、許可されてはなりません。
5. アクセス リストのエントリは、1行で構成されなければなりません。
