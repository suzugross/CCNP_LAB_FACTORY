# 問題 20260822-013

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたの組織は、下記に示されているところのネットワークを運用しています。2台のルータが、1本のリンクによって直接に接続されており、そして、それぞれのループバック・インターフェイスを使用して、BGP のピアが構成されています。RT01 は AS 64798、RT02 は AS 65451 に所属しています。

```
  [RT01]  Lo0=47.47.47.47          [RT02]  Lo0=77.77.77.77
    10.164.102.1 ────────────────── 10.164.102.2   (10.164.102.0/30)
```

- 対向のループバックへの到達性は、OSPF 92 によって提供されています。

## 要件

1. 両ルータの間で、BGP のピアが確立されること。
2. ループバック・インターフェイスの間でピアリングを行う設計が、維持されること。
3. 対向のループバックへの到達性を提供している構成は、変更しないこと。

## 設問

示されているところのすべての要件が満たされることを確実にするために、行われなければならない構成の変更は、どれとどれですか。(2つを選択してください)

**A.**
```
! RT02
router bgp 65451
 neighbor 47.47.47.47 ebgp-multihop 2
```

**B.**
```
! RT01
ip route 77.77.77.77 255.255.255.255 10.164.102.2
```

**C.**
```
! RT02
router bgp 65451

```

**D.**
```
! RT01 と RT02 の両方で
clear ip bgp *
```
