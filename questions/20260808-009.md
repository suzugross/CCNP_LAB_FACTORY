## 選択肢
A. MAP-A の match を「match ip address ACL-A」に設定し直す

B. MAP-A の match を「match ip address prefix-list PL-A」に変更する(PL-A: 172.16.32.0/24 と 172.16.38.0/24 を permit)

C. ACL-A を「deny ip 192.168.151.0 0.0.0.255 172.16.39.0 0.0.0.255」「permit ip 192.168.151.0 0.0.0.255 172.16.32.0 0.0.7.255」の2行(deny 先行)に置き換える

D. ACL-A を「permit ip 192.168.151.0 0.0.0.255 172.16.32.0 0.0.6.255」の1行に置き換える

E. ACL-A を「permit ip 192.168.151.0 0.0.0.255 172.16.32.0 0.0.16.255」の1行に置き換える

F. ACL-A を「permit ip 192.168.151.0 0.0.0.255 172.16.32.0 0.0.0.255」「permit ip 192.168.151.0 0.0.0.255 172.16.38.0 0.0.0.255」の2行に置き換える

G. ACL-A を「permit ip 192.168.151.0 0.0.0.255 172.16.32.0 0.0.2.255」の1行に置き換える
