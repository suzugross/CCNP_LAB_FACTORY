# 問題 20260920-020

## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

| 項目 | trap | inform |
|---|---|---|
| 受信側の確認応答 | なし(受信側は何も返さない) | ［①］ |
| 届かなかったとき | 再送しない(送りっぱなし) | 応答が来るまで再送する(回数・間隔は設定可) |
| 送信側の負担 | 小さい | 応答待ちの間メモリに保持するので大きい |
| 使える SNMP バージョン | v1 / v2c / v3 | ［②］ |
| 宛先ポート(管理ステーション側) | UDP 162 | UDP 162 |

通知の宛先は `snmp-server host` で、何を通知するかは［③］で決める。両方が揃って初めて通知が飛ぶ。`snmp-server host 192.168.100.20 mon-ro` のように version を省略するとバージョン 1 の trap として送られる(実測)。inform を送るには host 行に［④］を付け、version は 2c 以上を指定する。v1 を指定すると設定自体が拒否される(実測)。v3 で通知を送るときは `version 3` の後ろにセキュリティレベル(noauth/auth/priv)とユーザ名を書き、通知に使うユーザの鍵で認証・暗号化される。エージェントが要求を受けるのは UDP 161、通知を受け取る管理ステーション側は UDP ［⑤］である。
