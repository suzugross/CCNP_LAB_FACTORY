# 問題 20260807-003

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたは、下記のネットワークの保守を担当する技術者です。拠点のルータ RT01 は、複数のループバック・インターフェイスによって、サービスのためのアドレスのブロック 10.64.32.0/29 を収容しています。RT01 と RT02 は、1本のリンクによって直接に接続されており、そして、EIGRP 65100 が構成されています。

```
  [RT01]  Lo: 10.64.32.1, 10.64.32.2, 10.64.32.3, 10.64.32.4 (+ 10.235.54.13)
    10.210.53.1 ─────(GigabitEthernet0/1)───── 10.210.53.2
  [RT02]
```

## 要件

1. 管理のための構成に対して、変更が加えられてはなりません。
2. ただし、監視のためのホストである 10.64.32.4 (/32) の明細のルートは、集約とともに、受信されなければなりません。
3. 運用のためのループバック 10.235.54.13 (/32) は、引き続き受信されなければなりません。
4. RT02 に対して、ブロック 10.64.32.0/29 は、集約のルートとして広告される必要があります。
5. ブロックの内部の明細のルートは、広告されることはできません。
6. 集約のルートおよび明細のルートは、いずれも、EIGRP の内部のルートとして受信されなければなりません。
