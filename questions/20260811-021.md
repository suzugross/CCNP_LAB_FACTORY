# 問題 20260811-021

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

あなたは、下記のネットワークの保守を担当する技術者です。ある企業のネットワークにおいて、RT02 は、顧客の側のネットワークと、サーバの側のネットワークとの間に配置されており、IPv6 によって運用されています。`2001:DB8:DC:65::/64` からの通信は、許可されてはなりません。アクセス・リストのエントリは、1行で構成される必要があります。RT02 において、`2001:DB8:DC:60::/64`、`2001:DB8:DC:61::/64`、`2001:DB8:DC:62::/64` のネットワークからの通信のみが、`2001:DB8:DC:FF::10` の TCP ポート 22 に到達できなければなりません。本作業は、日中の時間帯において実施されるという理由により、対象外であるところのデバイスに対する構成の変更は、許可されていません。

```
   RT03 (顧客の側) --- RT02 (被験のデバイス) --- RT01 (サーバの側)
```

## 出力

```
RT02# show ipv6 access-list
IPv6 access list V6-EDGE-IN
    permit ipv6 2001:DB8:DC:60::/61 any sequence 10
    deny ipv6 2001:DB8:DC:65::/64 any sequence 20
```
```
RT02# show running-config | section ipv6 access-list|traffic-filter
ipv6 access-list V6-EDGE-IN
 sequence 10 permit ipv6 2001:DB8:DC:60::/61 any
 sequence 20 deny ipv6 2001:DB8:DC:65::/64 any
interface Ethernet0/0
 ipv6 traffic-filter V6-EDGE-IN in
```

## 設問

示されているところの構成において、破棄されるものは、どれですか。(1つを選択してください)

## 選択肢
A. 送信元が 2001:DB8:DC:60::/64 のネットワークにあるホストから、2001:DB8:DC:FF::10 の TCP ポート 22 宛ての通信

B. 送信元が 2001:DB8:DC:65::/64 のネットワークにあるホストから、2001:DB8:DC:FF::10 の TCP ポート 22 宛ての通信

C. 送信元が 2001:DB8:DC:62::/64 のネットワークにあるホストから、2001:DB8:DC:FF::10 の TCP ポート 22 宛ての通信

D. 送信元が 2001:DB8:DC:61::/64 のネットワークにあるホストから、2001:DB8:DC:FF::10 の TCP ポート 22 宛ての通信

E. 送信元が 2001:DB8:DC:FA::/64 のネットワークにあるホストから、2001:DB8:DC:FF::10 の TCP ポート 22 宛ての通信
