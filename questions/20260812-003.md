# 問題 20260812-003

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

あなたの組織は、下記に示されているところのネットワークを運用しています。ある企業のネットワークにおいて、RT01 は、顧客の側のネットワークと、サーバの側のネットワークとの間に配置されており、IPv6 によって運用されています。対象としていないネットワークが、一致の対象に含まれてはなりません。また、拒否のエントリを使用してはなりません。RT01 において、`2001:DB8:42:10::/64`、`2001:DB8:42:11::/64`、`2001:DB8:42:12::/64` のネットワークからの通信のみが、`2001:DB8:42:FF::10` の TCP ポート 443 に到達できなければなりません。本作業は、日中の時間帯において実施されるという理由により、対象外であるところのデバイスに対する構成の変更は、許可されていません。`2001:DB8:42:15::/64` からの通信は、許可されてはなりません。

```
   RT03 (顧客の側) --- RT01 (被験のデバイス) --- RT02 (サーバの側)
```

## 出力

```
RT01# show ipv6 access-list
IPv6 access list V6-CUST-IN
    permit ipv6 2001:DB8:42:10::/62 any sequence 10
    deny ipv6 any any sequence 20
```
```
RT01# show running-config | section ipv6 access-list|traffic-filter
ipv6 access-list V6-CUST-IN
 sequence 10 permit ipv6 2001:DB8:42:10::/62 any
 sequence 20 deny ipv6 any any
interface Ethernet0/0
 ipv6 traffic-filter V6-CUST-IN in
```

## 設問

送信元が 2001:DB8:42:10::5 である1つのパケット が処理されるとき、一致のカウンタが増加するのは、どの行ですか。(1つを選択してください)

## 選択肢
A. `permit ipv6 2001:DB8:42:10::/62 any sequence 10` の行

B. いずれの行のカウンタも増加しない(暗黙の拒否によって処理される)

C. `deny ipv6 any any sequence 20` の行
