# 問題 20260920-025

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
ip flow-export destination 198.51.100.100 2055
ip flow-export version 5
!
interface Ethernet0/0
 ［①］
!
ip flow-top-talkers
 ［②］ 5
 ［③］ packets
!
RT02# ［④］
SrcIf   SrcIPaddress   DstIf   DstIPaddress   Pr SrcP DstP Bytes
Et0/0   192.168.7.30      Et0/1   192.168.9.40      06 C1A2 0050  921600
Et0/0   192.168.7.31      Et0/1   192.168.9.53      11 A3F0 0035  30720
2 of 5 top talkers shown. 2 flows processed.
```

従来の NetFlow で上位フローを見るには、まず IF に［①］を付けて採取を有効にし、`ip flow-top-talkers` 配下で［②］に表示件数(1〜200)、［③］に並べ替えの基準(bytes か packets)を書く。結果は［④］で見る。これは［⑤］ので、コレクタへのエクスポートが動いていなくても使える。FNF で同じことをするには show flow monitor MON-WAN cache sort highest counter bytes のようにキャッシュをその場でソートし、末尾に件数の指定を付けて絞る。ただし並べ替えに使えるのはそのレコードに含まれるフィールドだけなので、バイト数で並べたければレコードに collect counter bytes が要る。

## 選択肢

A. 装置上のキャッシュをソートして表示するだけ

B. top

C. count

D. エクスポートパケットを並べ替えて送る

E. ip flow ingress

F. rank

G. sort-by

H. show ip flow export

I. ip flow-export enable

J. show ip flow top-talkers
