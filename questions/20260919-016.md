# 問題 20260919-016

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

ISP-A(AS 100)- EDGE(AS 200)- ISP-B(AS 300)の順に eBGP で接続されています。ISP-A は 172.16.1.0/24、EDGE は 10.2.2.0/24、ISP-B は 192.168.1.0/24 を広告しています。AS 200 を非トランジット AS にしようとしましたが、AS 100 と AS 300 がそれぞれの経路を交換しています。

```
ISP-A# show ip bgp | begin Network
     Network          Next Hop            Metric LocPrf Weight Path
 *>  172.16.1.0/24    0.0.0.0                  0         32768 i
 *>  10.2.2.0/24      10.255.0.2               0             0 200 i
 *>  192.168.1.0/24   10.255.0.2                             0 200 300 i

【EDGE に追加する設定】
EDGE(config)# 【?】
EDGE(config)# router bgp 200
EDGE(config-router)# neighbor 10.255.0.1 distribute-list 30 out
EDGE(config-router)# neighbor 10.255.0.6 distribute-list 10 out
```

## 設問

AS 100 に AS 300 の経路、AS 300 に AS 100 の経路が届かないようにするために EDGE で必要な【?】に当てはまる設定はどれですか。なお、ISP-A と ISP-B は AS 200 の経路を動的に学習する必要があり、EDGE は AS 100 と AS 300 の経路を動的に学習する必要があります。(1つを選択してください)
