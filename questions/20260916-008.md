# 問題 20260916-008

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

ファイル転送(tftp/ftp/scp)について、正しく述べられているものは、次のうちどれですか。(1つを選択してください)

## 選択肢

A. ftp のパスワードは、URL に含めることができない。

B. SCP のサーバには、ip scp server enable は不要である。

C. SCP は SSH のうえで動作し、SSH が有効である必要がある。

D. SSH の認証のタイムアウトと再試行の既定値は、それぞれ 120 秒と 3 回である。
