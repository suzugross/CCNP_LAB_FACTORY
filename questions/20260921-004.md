# 問題 20260921-004

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

あなたの組織は、AS 65000 の MPLS L3VPN 網を運用しています。要件は、次のとおりです。

- 各拠点は PE-A に収容されたハブ拠点とだけ通信でき、ハブ以外の拠点同士は直接には通信できないこと。

```
PE-A# show running-config | section vrf definition
vrf definition VPN_ALPHA
 rd 65000:101
 !
 address-family ipv4
  route-target export 65000:3000
  route-target import 65000:310
 exit-address-family
!
```
```
PE-A# show running-config | section router bgp
router bgp 65000
 bgp router-id 1.1.1.1
 no bgp default ipv4-unicast
 neighbor 2.2.2.2 remote-as 65000
 neighbor 2.2.2.2 update-source Loopback0
 neighbor 3.3.3.3 remote-as 65000
 neighbor 3.3.3.3 update-source Loopback0
 !
 address-family vpnv4
  neighbor 2.2.2.2 activate
  neighbor 2.2.2.2 send-community extended
  neighbor 3.3.3.3 activate
  neighbor 3.3.3.3 send-community extended
 exit-address-family
 !
 address-family ipv4 vrf VPN_ALPHA
  redistribute connected
  redistribute static
 exit-address-family
```

```
PE-B# show running-config | section vrf definition
vrf definition VPN_ALPHA
 rd 65000:102
 !
 address-family ipv4
  route-target export 65000:310
  route-target import 65000:3000
 exit-address-family
!
```

```
PE-C# show running-config | section vrf definition
vrf definition VPN_ALPHA
 rd 65000:103
 !
 address-family ipv4
  route-target export 65000:555
  route-target import 65000:3000
 exit-address-family
!
```
```
PE-C# show running-config | section router bgp
router bgp 65000
 bgp router-id 3.3.3.3
 no bgp default ipv4-unicast
 neighbor 1.1.1.1 remote-as 65000
 neighbor 1.1.1.1 update-source Loopback0
 neighbor 2.2.2.2 remote-as 65000
 neighbor 2.2.2.2 update-source Loopback0
 !
 address-family vpnv4
  neighbor 1.1.1.1 activate
  neighbor 1.1.1.1 send-community extended
  neighbor 2.2.2.2 activate
  neighbor 2.2.2.2 send-community extended

 !
 address-family ipv4 vrf VPN_ALPHA
  redistribute connected
  redistribute static

```

PE-A に収容されている VRF VPN_ALPHA の拠点から、PE-C に収容されている VRF VPN_ALPHA の拠点 172.20.3.0/24 へ通信できない、ということが、報告されています。PE-A の VRF VPN_ALPHA の経路表に、172.20.3.0/24 は存在しません。一方、PE-C の VRF VPN_ALPHA の経路表には、PE-A 側の拠点の経路が存在しています。なお、PE-B の VRF VPN_ALPHA の拠点は、PE-A の VRF VPN_ALPHA の拠点と、正常に通信できています。

## 設問

示されている構成に基づいて、この事象の原因として最も適切なものは、次のうちどれですか。(1つを選択してください)

## 選択肢

A. 被疑の PE の VRF のアドレス・ファミリで、顧客の経路が BGP に取り込まれていない

B. vpnv4 のネイバーに send-community extended が構成されていない

C. PE 間で VRF の RD が一致していない

D. 被疑の PE の VRF の route-target import が、対向の VRF の export と一致していない

E. 対向の PE の VRF の route-target export が、被疑の VRF の import と一致していない
