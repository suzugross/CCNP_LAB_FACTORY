# 問題 20260913-018

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

FTP のサーバ 10.1.10.142 は、ユーザ名 `netops`・パスワード `cisco123` での認証を要求し、匿名のログインを拒否します。この装置には ip ftp username および ip ftp password は構成されていません。

## 設問

この装置の running-config を、このサーバへファイル名 `backup.cfg` で保存するコマンドとして正しいものは、次のうちどれですか。(1つを選択してください)

## 選択肢

**A.**

```
copy running-config tftp://netops:cisco123@10.1.10.142/backup.cfg
```

**B.**

```
copy running-config ftp://10.1.10.142/backup.cfg
```

**C.**

```
copy running-config ftp:/netops:cisco123@10.1.10.142/backup.cfg
```

**D.**

```
copy running-config ftp://netops:cisco123@10.1.10.142/backup.cfg
```
