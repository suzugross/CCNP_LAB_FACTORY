# 問題 20260929-011

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

SNMP のコミュニティ・v3・通知について、正しく述べられているものを、次のうちから 2 つ選択してください。

## 選択肢

A. trap は確認応答を必要とせず、inform は受信側からの確認応答を受け取るまで再送される。

B. RO のコミュニティに SET を試みると、noAccess のエラーが返る。

C. snmp-server host にバージョンを指定しない場合、既定でバージョン 2c の inform が送信される。

D. show ntp associations は、参照先の同期の状態を表示する。

E. SNMPv3 のユーザは、show running-config に鍵を含めて平文で表示される。
