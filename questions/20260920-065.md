# 問題 20260920-065

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

あなたは、ネットワークの運用を担当しています。2台のルータが、1本のリンクによって直接に接続されており、そして、それぞれのループバック・インターフェイスを使用して、BGP のピアが構成されています。両ルータは、同一の AS 64570 に所属しています。ネイバーの状態に関する事象が、報告されています。調査のために、両方のルータにおいて `debug ip bgp` が有効にされ、そして、ログが採取されました。両ルータの間で、BGP のピアが確立されること。ループバック・インターフェイスの間でピアリングを行う設計が、維持されること。ピアの確立が、いずれか一方の側からの接続の開始に、依存しないこと。

```
  [RT02]  Lo0=8.8.8.8          [RT01]  Lo0=48.48.48.48
    10.150.219.1 ────────────────── 10.150.219.2   (10.150.219.0/30)
```

- 対向のループバックへの到達性は、OSPF 89 によって提供されています。

## 設問

示されているところのすべての要件が満たされることを確実にするために、行われなければならない構成の変更は、どれとどれですか。(2つを選択してください)

## 選択肢
**A.**
```
! RT01
router bgp 64570
 neighbor 8.8.8.8 update-source Loopback0
```

**B.**
```
! RT02 と RT01 の両方で
clear ip bgp *
```

**C.**
```
! RT01
ip route 8.8.8.8 255.255.255.255 10.150.219.1
```

**D.**
```
! RT02
router bgp 64570
 no neighbor 48.48.48.48 remote-as 64570
 neighbor 10.150.219.2 remote-as 64570
```

**E.**
```
! RT01
router bgp 64570
 no neighbor 10.150.219.1 remote-as 64570
 neighbor 8.8.8.8 remote-as 64570
```

**F.**
```
! RT02
router bgp 64570
 neighbor 48.48.48.48 ebgp-multihop 2
```
