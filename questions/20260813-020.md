# 問題 20260813-020

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたは、下記のネットワークの保守を担当する技術者です。ある企業のネットワークにおいて、RT03 は、顧客の側のネットワークと、サーバの側のネットワークとの間に配置されており、IPv6 によって運用されています。

```mermaid
graph LR
  DN["RT01<br/>顧客の側"]
  DUT["RT03<br/>被験のデバイス"]
  UP["RT02<br/>サーバの側"]
  DN --- DUT
  DUT --- UP
```

## 要件

1. RT03 において、`2001:DB8:DF:60::/64`、`2001:DB8:DF:61::/64`、`2001:DB8:DF:62::/64` のネットワークからの通信のみが、`2001:DB8:DF:FF::10` の TCP ポート 80 に到達できなければなりません。
2. 対象としていないネットワークが、一致の対象に含まれてはなりません。また、エントリの行数は、最小でなければなりません。
3. `2001:DB8:DF:65::/64` からの通信は、許可されることはできません。
4. インタフェースの IP アドレッシングは、変更されてはなりません。
5. `2001:DB8:DF:63::/64` からの通信は、許可されてはなりません。

## 現在の状態

```
RT03# show ipv6 access-list
IPv6 access list V6-FILTER-IN
    permit ipv6 2001:DB8:DF:60::/64 any sequence 10
```

## 設定抜粋

```
RT03# show running-config | section ipv6 access-list|traffic-filter
ipv6 access-list V6-FILTER-IN
 sequence 10 permit ipv6 2001:DB8:DF:60::/64 any
interface Ethernet0/0
 ipv6 traffic-filter V6-FILTER-IN in
```
