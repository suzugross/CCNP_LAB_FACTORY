# 問題 20260927-036

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
snmp-server community NOC-RO RO 99
snmp-server community cfg-rw RW 66
access-list 99 permit 10.99.0.2
! (access-list 66 は定義されていない)
```

コミュニティは RO と RW の 2 種類で、RO では GET は成功するが SET は［①］として拒否され、RW では両方成功する。コミュニティに付けた ACL が要求の送信元を許可しないとき、装置は応答を返さない(タイムアウトになる)。一方、参照している ACL が定義されていないときは全許可になる(拒否しない)(実測)。したがって上の cfg-rw は送信元を問わず書き込める危険な状態である。誤ったコミュニティ名での要求は `show snmp` の［②］カウンタ、RO への SET は［③］カウンタに現れる。コミュニティ名は running-config に［④］ので、v3 のユーザ(表示されない)とは扱いが違う。

## 選択肢

A. Unknown community name

B. Illegal operation

C. 表示されない

D. ハッシュで表示される

E. 平文で表示される

F. authorizationError

G. noAccess

H. No such name errors
