# 問題 20260920-026

## 設問

次の説明文(設定例を含む)の空欄 ①〜⑥ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

| 項目 | Phase 1 | Phase 2 | Phase 3 |
|---|---|---|---|
| スポークのトンネル | p2p GRE(tunnel destination でハブを固定) | mGRE | mGRE |
| スポーク間トラフィックの経路 | 常にハブ経由 | ［①］ | ［②］ |
| スポークが持つ経路 | ［③］ | 対向 LAN ごとの具体的な経路が要る(集約不可・next-hop= 対向スポーク) | 集約や default でよい(next-hop はハブのまま) |
| ハブの追加設定(EIGRP の場合) | なし | no ip next-hop-self eigrp(+ no ip split-horizon eigrp) | ip nhrp redirect(+ no ip split-horizon eigrp) |
| スポークの追加設定 | なし | なし | ip nhrp shortcut |
| OSPF ネットワークタイプの定石 | ［④］ | broadcast(ハブが DR・スポークは priority 0) | broadcast(同左) |

Phase の番号は［⑤］で、ハブは 3 つのどれでも mGRE である。Phase 2 でハブが経路を集約できないのは、スポーク間直接通信のきっかけが経路の next-hop が対向スポークのトンネル IP であること(その解決で NHRP が走る) だからである。Phase 3 では［⑥］がきっかけになるので、スポークの経路はハブ向きのままでよく、ハブで集約しても直接通信が成立する。どの Phase でもハブの EIGRP には no ip split-horizon が要る(同じ Tunnel から学んだスポークの経路を他のスポークへ反射させるため)。

## 選択肢

A. スポーク間の動的トンネルで直接(経路はハブ向きのまま転送だけ切り替え)

B. 経路は不要(NHRP が全て解決する)

C. NHRP プロトコルのバージョン

D. スポーク同士の IKE の事前交渉

E. point-to-multipoint

F. スポーク間の動的トンネルで直接(経路の next-hop が対向スポーク)

G. 設定の組合せで決まる動作モード(ソフトウェアの版ではない)

H. ハブが中継時に送る NHRP Redirect と、それを受けたスポークの解決(shortcut)

I. 集約や default でよい(next-hop はハブ)

J. point-to-point(既定のまま)
