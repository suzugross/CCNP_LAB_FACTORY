# 問題 20260920-095

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

LDPについて、正しく述べられているものを、すべて選んでください。

## 選択肢

A. LDP には、MPLS トラフィック・エンジニアリングが必要である。

B. MPLS のラベル配布に使われるプロトコルには、LDP と RSVP-TE がある。

C. LDP の自動構成は、EIGRP と RIPv2 で利用できる。

D. LDP のルータ ID は、ループバックの有無にかかわらず、最も大きい IP アドレスを持つ物理インターフェイスから選ばれる。

E. LDP の既定の配布方式は Downstream Unsolicited であり、要求が無くてもラベルを隣接に広告する。
