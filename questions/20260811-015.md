# 問題 20260811-015

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

あなたは、ネットワークの運用を担当しています。ある企業のネットワークにおいて、RT01 は、顧客の側のネットワークと、サーバの側のネットワークとの間に、配置されています。アクセス・リストは、顧客の側のインターフェイスである `Ethernet0/0` において、着信の方向に適用される必要があります。対象としていないネットワークが、一致の対象に含まれてはなりません。また、エントリの行数は、最小でなければなりません。本作業は、日中の時間帯において実施されるという理由により、対象外であるところのデバイスに対する構成の変更は、許可されていません。`10.19.55.0/24` からの通信は、許可されることはできません。RT01 において、`10.19.48.0/24` から `10.19.54.0/24` までの範囲にあるネットワークからの通信のみが、サーバである `172.19.18.83` の TCP ポート 3389 に到達できなければなりません。当該のサーバの他のポートへの通信、および当該のサーバ以外の宛先への通信は、許可されてはなりません。`10.19.57.0/24` からの通信は、許可されることはできません。

```
   RT02 (顧客の側)                     RT03 (サーバの側)
        |  10.19.253.0/24        10.19.254.0/24  |
  Ethernet0/0 --------- RT01 --------- Ethernet0/1
                 (被験のデバイス)
                        |
                  Ethernet0/2
              10.19.255.0/24 (管理セグメント)
```

次のうち、正しいものは、どれですか。
