# 問題 20260920-029

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
! Hub
interface Tunnel0
 ip address 10.200.0.1 255.255.255.0
 no ip redirects
 ip mtu 1400
 ip tcp adjust-mss 1360
 ip nhrp authentication DMVPNKEY
 ip nhrp map multicast dynamic
 ip nhrp network-id 1
 ［①］
 no ip split-horizon eigrp 1
 tunnel source Ethernet0/0
 tunnel mode gre multipoint
 tunnel key 65001
 tunnel protection ipsec profile IPSEC-DMVPN
!
! Spoke(抜粋): ip nhrp nhs 10.200.0.1 nbma 10.0.14.1 multicast / tunnel mode gre multipoint
!              (ip nhrp shortcut は設定されていない)
```

この構成は Phase ［②］である。ip nhrp map multicast dynamic は［③］ための行で、これが無いとスポークはハブからの Hello を受け取れず隣接が片側だけになる。no ip split-horizon eigrp 1 は［④］ために要る(Phase に関係なく必須)。［①］が Phase を決める行で、スポークが持つ対向スポークの LAN 経路の next-hop は［⑤］になる。この Phase でハブが対向スポークの経路を集約することはできない(集約すると next-hop がハブになり直接通信が消える)。tunnel key は全メンバで一致させ、`no ip redirects` は Tunnel 上で ICMP Redirect を出さないための定石である。

## 選択肢

A. 2

B. 対向スポークのトンネル IP

C. 対向スポークの NBMA アドレス

D. ip nhrp redirect

E. スポーク間の直接トンネルを禁止する

F. 3

G. スポークからのマルチキャスト登録を受け付ける

H. no ip next-hop-self eigrp 1

I. 登録してきたスポークの NBMA を Hello などマルチキャストの宛先に自動で加える

J. 同じ Tunnel から学んだスポークの経路を、他のスポークへ同じ Tunnel から広告する
