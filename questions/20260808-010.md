# 問題 20260808-010

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたは、下記のネットワークの保守を担当する技術者です。2 つの拠点のルータが、共通の認証サーバ群を用いて、管理者の認証を行うように構成されています。一方のルータはサーバと直結しており、他方はそのルーターを経由してサーバに到達します。

```mermaid
graph RL
  S2 --- A
  A("RT-福1")
  S2["SRV02<br/>認証サーバ"]
  B --- A
  S1 --- A
  S1("SRV01<br/>認証サーバ")
  B("RT-札2")
```

### 認証サーバの仕様

| 項目 | SRV01 | SRV02 |
|---|---|---|
| アドレス | 10.99.176.2 | 10.99.177.2 |
| 待受ポート | 1812 / 1813 | 1645 / 1646 |
| 共有鍵 | Ccnp-Aaa-77 | Ccnp-Aaa-77 |
| 受理する送信元 | 10.1.0.1 ・ 10.8.0.2 | 同左 |
| 台帳 | noc-hanako(15) ・ watch-op(1) ・ SUZUKI(15) | 同左 |
| 現在の稼働状態 | 稼働中 | 稼働中 |

## 要件

1. 福岡・札幌 の両拠点で、利用者 noc-hanako が権限レベル 15 で機器を操作できること。
2. 認証サーバが全て停止した場合でも、コンソールからは操作できること。
3. 認証は認証サーバ群 RAD-GROUP を用いること。

## 現在の状態

通信の一部において、想定されていない挙動が、観測されています。示されているところの出力および構成に基づいて、要求されているところの動作が得られていない理由が、判断されなければなりません。

| 拠点 | ユーザ | 結果 |
|---|---|---|
| 福岡 | noc-hanako | ログイン不可 |
| 福岡 | watch-op | ログイン不可 |
| 福岡 | backup-adm | ログインは通るが exec 拒否 |
| 福岡 | watch-op からの特権昇格 | 昇格可(15) |
| 札幌 | noc-hanako | ログイン可(権限レベル 15) |
| 札幌 | watch-op | ログイン可(権限レベル 1) |
| 札幌 | backup-adm | ログイン不可 |
| 札幌 | watch-op からの特権昇格 | 昇格可(15) |
