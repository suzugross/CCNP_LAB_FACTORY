# 問題 20260918-004

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

R1 と R2 は GigabitEthernet0/1 同士で直接接続され、OSPF プロセス 100 のエリア 1 で隣接を形成する構成です。 隣接が形成されないため、R1 でデバッグを有効にしたところ、次の出力が得られました。

```
R1# debug ip ospf hello
*Sep 18 03:24:21.000: OSPF-100 HELLO Gi0/1: Rcv hello from 4.4.4.4 area 1 10.152.208.1
*Sep 18 03:24:21.000: OSPF-100 HELLO Gi0/1: Hello from 10.152.208.1 with mismatched Stub/Transit area option bit
*Sep 18 03:24:31.370: OSPF-100 HELLO Gi0/1: Rcv hello from 4.4.4.4 area 1 10.152.208.1
*Sep 18 03:24:31.370: OSPF-100 HELLO Gi0/1: Hello from 10.152.208.1 with mismatched Stub/Transit area option bit
```

## 設問

この事象を解消するための変更として最も適切なものは、次のうちどれですか。(1つを選択してください)

## 選択肢

A. R1 と R2 の GigabitEthernet0/1 で ip ospf hello-interval をそろえる。

B. R1 と R2 の GigabitEthernet0/1 に ip ospf mtu-ignore を構成する。

C. R2 の router ospf 100 で area 1 nssa を構成する。

D. R1 の router ospf 100 で area 1 stub を構成し、R2 とそろえる。
