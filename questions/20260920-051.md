## 設問

ファイル転送(tftp/ftp/scp)について、正しく述べられているものは、次のうちどれですか。(1つを選択してください)

## 選択肢

A. SSH を有効にするには、vty 回線の transport input に ssh を含める必要がある。

B. SCP のサーバには、ip scp server enable は不要である。

C. ftp のパスワードは、URL に含めることができない。

D. SCP は SSH のうえで動作し、SSH が有効である必要がある。
