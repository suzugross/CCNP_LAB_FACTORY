# 問題 20260919-061

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
aaa new-model
!
radius server RAD1
 address ipv4 10.99.1.2 auth-port 1812 acct-port 1813
 key Rad-Key-2026
radius server RAD2
 address ipv4 10.99.2.2 auth-port 1812 acct-port 1813
 key Rad-Key-2026
!
aaa group server radius AAA-SRV
 server name RAD1
 server name RAD2
!
ip radius source-interface Loopback0
radius-server dead-criteria time 3 tries 1
!
aaa authentication login default group AAA-SRV ［①］
aaa authorization exec default group AAA-SRV ［①］
［②］
!
username break-glass privilege 15 secret 9 $9$xxxx
line vty 0 15
 transport input ssh
```

上の設定を上から読む。サーバは radius server で名前を付けて定義し、アドレス・ポート・共有鍵を持たせる。ポートは既定の 1812/1813 以外も指定でき、サーバ側の設定と一致していればよい。2 台をサーバグループ(aaa group server radius) にまとめ、メソッドリストからはこのグループ名で参照する。ip radius source-interface は要求の送信元アドレスを固定するもので、サーバ側の［③］に登録したアドレスと一致させるために要る。これが無いと出力インターフェースのアドレスが送信元になり、サーバは要求を［④］として黙って捨てる。認証と認可の両方に［①］を末尾に置き、サーバ無応答時にローカルの break-glass で入れるようにしている。［②］はコンソールにも exec 認可を効かせるための行で、これが無いとコンソールでは認可が実行されない。

## 選択肢

A. 認可プロファイル

B. aaa authorization console

C. local

D. enable

E. unknown client

F. クライアント(NAS)一覧

G. aaa authentication console

H. invalid password
