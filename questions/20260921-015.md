# 問題 20260921-015

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
aaa new-model
!
radius server RAD1
 address ipv4 192.168.100.11 auth-port 1645 acct-port 1646
 key N0c-Radius
radius server RAD2
 address ipv4 192.168.100.12 auth-port 1645 acct-port 1646
 key N0c-Radius
!
aaa group server radius RADGRP
 server name RAD1
 server name RAD2
!
［①］ Loopback0
radius-server dead-criteria time 3 tries 1
!
aaa authentication login default group RADGRP ［②］
aaa authorization exec default group RADGRP ［②］
aaa authorization console
!
username local-admin privilege 15 secret 9 $9$xxxx
line vty 0 15
 transport input ssh
```

上の設定を上から読む。サーバは radius server で名前を付けて定義し、アドレス・ポート・共有鍵を持たせる。ポートは既定の 1645/1646 以外も指定でき、サーバ側の設定と一致していればよい。2 台を［③］にまとめ、メソッドリストからはこのグループ名で参照する。［①］は要求の送信元アドレスを固定するもので、サーバ側の［④］に登録したアドレスと一致させるために要る。これが無いと出力インターフェースのアドレスが送信元になり、サーバは要求を unknown client として黙って捨てる。認証と認可の両方に［②］を末尾に置き、サーバ無応答時にローカルの local-admin で入れるようにしている。aaa authorization console はコンソールにも exec 認可を効かせるための行で、これが無いとコンソールでは認可が実行されない。

## 選択肢

A. メソッドリスト

B. ip source-route

C. local

D. クライアント(NAS)一覧

E. enable

F. ip radius source-interface

G. ユーザ台帳

H. サーバグループ(aaa group server radius)
