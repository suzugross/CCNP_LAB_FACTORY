# 問題 20260920-023

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
RT02(config)# flow record REC-CORP
RT02(config-flow-record)# match ipv4 tos
% Object is in use
RT02(config-flow-record)# exit
RT02(config)# interface Ethernet0/2
RT02(config-if)# no ip flow monitor MON-CORP input
RT02(config-if)# flow record REC-CORP
RT02(config-flow-record)# match ipv4 tos
% Object is in use
```

レコードのキーを 1 つ追加しようとして拒否された場面である。使用中のレコードのフィールドは参照しているモニタが存在する限り変更できない。上のように IF から外しただけでは足りず(実測)、変更するには［①］という 3 段が要る。モニタ側の record 行も別名で上書きできないので、レコードを差し替えるときは no record → record の 2 段で書く。エクスポータは扱いが違い、destination・source・transport udp は参照されたままでも変更できるが、［②］だけは参照中は変更できない。新規に組むときは［③］の順に投入すれば、このロックには当たらない。変更後は［④］でフローが採れているかを確認する。

## 選択肢

A. show flow monitor MON-CORP cache

B. destination

C. record → exporter → monitor → IF 適用

D. モニタで no record(参照解除)→ レコードを編集 → モニタに record を戻す

E. clear flow monitor → レコードを編集 → write memory

F. exporter → IF 適用 → record → monitor

G. export-protocol

H. show flow exporter EXP-CORP
