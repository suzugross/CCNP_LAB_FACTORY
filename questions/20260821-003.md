# 問題 20260821-003

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたは、下記のネットワークの保守を担当する技術者です。ある企業のネットワークにおいて、RT03 は、顧客の側のネットワークと、サーバの側のネットワークとの間に、配置されています。

```mermaid
graph LR
  DN["RT01<br/>顧客の側"]
  DUT["RT03<br/>被験のデバイス"]
  UP["RT02<br/>サーバの側"]
  DN --- DUT
  DUT --- UP
  MGMT(["管理セグメント"])
  DUT --- MGMT
```

| 区間 | 被験デバイス側のインターフェイス | ネットワーク |
|------|----------------------------------|--------------|
| RT01（顧客の側） ⇔ RT03 | `Ethernet0/0` | 10.52.253.0/24 |
| RT03 ⇔ RT02（サーバの側） | `Ethernet0/1` | 10.52.254.0/24 |
| RT03 ⇔ 管理セグメント | `Ethernet0/2` | 10.52.255.0/24 |

## 要件

1. 当該のサーバの他のポートへの通信、および当該のサーバ以外の宛先への通信は、許可されることはできません。
2. `10.52.163.0/24` からの通信は、許可されてはなりません。
3. アクセス・リストは、顧客の側のインターフェイスである `Ethernet0/0` において、着信の方向に適用されなければなりません。
4. 本作業は、日中の時間帯において実施されるという理由により、対象外であるところのデバイスに対する構成の変更は、許可されていません。
5. アクセス・リストのエントリは、1行で構成される必要があります。
6. `10.52.162.0/24` からの通信は、許可されてはなりません。
7. RT03 において、`10.52.160.0/24`、`10.52.161.0/24`、`10.52.164.0/24`、`10.52.165.0/24` のネットワークからの通信のみが、サーバである `172.28.167.83` の TCP ポート 22 に到達できなければなりません。

## 現在の状態

```
RT03# show logging | include SEC-6
%SEC-6-IPACCESSLOGP: list EDGE-IN denied tcp 10.52.163.7(19477) -> 172.28.167.83(22), 1 packet
```

## 設定抜粋

```
RT03# show ip access-lists EDGE-IN
Extended IP access list EDGE-IN
    10 deny   tcp 10.52.163.0 0.0.0.255 host 172.28.167.83 eq 22 log
    20 deny   tcp 10.52.162.0 0.0.0.255 host 172.28.167.83 eq 22
    30 permit ip any any
```

## 設問

示されているところの記録および構成から読み取ることができるものは、どれですか。(2つを選択してください)

## 選択肢
A. 拒否のエントリのうち、`log` のキーワードを伴うものは1つだけである。

B. 記録に現れていない通信は、いずれも許可されたものである。

C. `10.52.162.7` からの通信は、許可された。

D. `10.52.160.7` からの通信は、拒否された。

E. `10.52.163.7` からの通信は、アクセス・リストによって拒否された。
