## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
interface Tunnel0
 ip address 10.255.0.2 255.255.255.0
 ip mtu ［①］
 ip tcp adjust-mss 1360
 ip nhrp authentication NHRPK3Y
 ip nhrp network-id 1
 ip nhrp nhs 10.255.0.1 nbma 203.0.113.1 multicast
 ［②］
 tunnel source GigabitEthernet0/1
 tunnel mode gre ［③］
 tunnel key 100
 tunnel protection ipsec profile IPSEC-DMVPN
!
! ハブ: トンネル IP 10.255.0.1 / NBMA 203.0.113.1   スポークの WAN IF= GigabitEthernet0/1
```

NHS の行は従来の map・map multicast・nhs の 3 行を 1 行にまとめた現代構文で、末尾の multicast は［④］を意味する。203.0.113.1 はハブの NBMA(WAN 物理)アドレスである。tunnel destination を書かないのは［⑤］からで、そのために tunnel mode を gre ［③］にする。［②］はハブからの Redirect を受けて解決・直接転送するための Phase 3 のスポーク設定である。MSS は IP ヘッダと TCP ヘッダの分だけ ip mtu より 40 バイト小さくする。tunnel protection を付けると GRE パケット全体が ESP で保護される(平文 GRE は相手に捨てられる)。

## 選択肢

A. ip

B. multipoint

C. IPsec プロファイルが宛先を持つ

D. ルーティングプロトコルの Hello などマルチキャストをハブへ送るための対応

E. 1500

F. ip nhrp shortcut

G. ip nhrp map multicast dynamic

H. 1400

I. スポークが DR になることの宣言

J. 宛先(ハブや対向スポークの NBMA)を NHRP が解決する
