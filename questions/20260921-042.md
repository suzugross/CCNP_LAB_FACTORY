# 問題 20260921-042

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

SSH の有効化と vty の構成について、正しく述べられているものを、すべて選んでください。

## 選択肢

A. SSH の認証のタイムアウトと再試行の既定値は、それぞれ 120 秒と 3 回である。

B. SSH のサーバを有効にするには鍵ペア(RSA または EC)の生成が必要であり、鍵が無いあいだ show ip ssh は SSH Disabled と表示する。

C. ラベルを指定せずに生成した RSA 鍵の名前は、ホスト名とドメイン名から作られる。

D. SSH を有効にするには、vty 回線の transport input に ssh を含める必要がある。

E. ip ssh authentication-retries は、認証のタイムアウトを秒で指定する。
