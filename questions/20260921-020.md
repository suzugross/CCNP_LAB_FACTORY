# 問題 20260921-020

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

```mermaid
graph LR
  n_EDGE["EDGE"]
  n_CORE["CORE<br/>10.10.100.2"]
  n_DIST["DIST"]
  LAN["172.16.20.0/24"]
```

EDGE は OSPFによって 172.16.20.0/24 の正しい経路(next-hop 10.10.100.2)を学習していますが、PC から 172.16.20.0/24 への ping が失敗します。

```
EDGE# show ip route 172.16.20.0
Routing entry for 172.16.20.0/24
  Known via "static", distance 1, metric 0
  Routing Descriptor Blocks:
  * 192.168.10.1
      Route metric is 0, traffic share count is 1

EDGE# show running-config | include ip route
ip route 172.16.20.0 255.255.255.0 192.168.10.1

EDGE# show ip ospf database router DIST | include Link ID|Network/subnet
     (Link ID) Network/subnet number: 172.16.20.0
```

## 設問

EDGE で ping を成功させることができる設定はどれですか。なお、OSPF の設定は変更しません。(1つを選択してください)
