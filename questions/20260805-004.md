# 問題 20260805-004 : 送信元アドレスの検証のための分析

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたの会社のエッジのルータは、2つのアップリンクによって、2つのサービス・プロバイダへ
接続されている、というものです。顧客のネットワーク 192.168.35.0/24 および
192.168.126.0/24 は、それぞれのプロバイダを経由して、広告されています。

```
          RT01 (エッジ・被験のデバイス)
   Ethernet0/0 |            | Ethernet0/1
  10.119.12.0/30      10.119.13.0/30
        |                    |
      RT03 (ISP-A)        RT02 (ISP-B)
```

- 監視のためのホスト: `192.168.126.28` および `192.168.126.197`
  (192.168.126.0/24 の中に存在し、ISP-B 側から着信します)

## 要件

1. 例外のリスト(アクセス・リスト)の運用は、実施されてはなりません。検証のモードの選択によって対処すること。
2. 着信のインターフェイスと一致しない送信元を持つところのトラフィックは、破棄されなければなりません。
3. エッジのルータの両方のアップリンクのインターフェイスにおいて、送信元アドレスの検証(anti-spoofing)が、有効にされていなければなりません。
4. 監視のためのホストである 192.168.126.28 および 192.168.126.197 からの、正規のトラフィックが、破棄されてはなりません。
5. 管理のための構成(SSH / SNMP / NTP)に対して、変更が加えられてはなりません。

## 設定抜粋

```
RT01# show running-config | section interface
interface Ethernet0/0
 ip address 10.119.12.1 255.255.255.252
 ip verify unicast source reachable-via rx
interface Ethernet0/1
 ip address 10.119.13.1 255.255.255.252
 ip verify unicast source reachable-via rx 130
```

## 設問

示されているところのすべての要件が満たされることを確実にするために、適用されなければならない構成は、どれですか。(1つを選択してください)

interface Ethernet0/1
