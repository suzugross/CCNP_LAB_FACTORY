# 問題 20260922-001

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
SW2# show spanning-tree vlan 10

VLAN0010
  Spanning tree enabled protocol rstp
  Root ID    Priority    24586
             Address     5254.0012.0f01
             Cost        4
             Port        2 (GigabitEthernet0/2)
             Hello Time   2 sec  Max Age 20 sec  Forward Delay 15 sec

  Bridge ID  Priority    32778  (priority 32768 sys-id-ext 10)
             Address     0011.2233.bb02
             Hello Time   2 sec  Max Age 20 sec  Forward Delay 15 sec
             Aging Time  300 sec

Interface           Role Sts Cost      Prio.Nbr Type
------------------- ---- --- --------- -------- --------------------------------
Gi0/1               Altn BLK 19        128.1    P2p
Gi0/2               Root FWD 4         128.2    P2p
Gi0/3               Desg FWD 4         128.3    P2p Edge
```

この出力に「This bridge is the root」の行が無いので、SW2 は root ではない(root の情報を Root ID 欄に持つだけ) である。Root ID の priority 24586 は［①］を意味し、Bridge ID の 32778 は既定の 32768 に VLAN 番号 10(extended system ID) を足した表示である。SW2 の root port は［②］で、Gi0/1 と Gi0/2 の両方が root に届くが、root path cost が小さい(4 と 19 の比較) ためにそちらが選ばれた。選ばれなかった方が Altn BLK なのは、［③］だからである。Gi0/3 の Type 欄の Edge は［④］を、P2p は［⑤］を表す。

## 選択肢

A. BPDU guard が有効

B. GigabitEthernet0/3

C. 別セグメントの designated が負けた予備(backup)

D. 全二重リンク(proposal/agreement で高速収束)

E. root の priority 設定 24586 そのまま

F. root の priority 設定 24576 + VLAN 10(root primary の既定値)

G. 半二重の共有リンク(Shr)

H. PortFast 相当の端末向けポート(TC に数えない)

I. root への別経路を持つが cost で負けた予備(discarding)

J. GigabitEthernet0/2
