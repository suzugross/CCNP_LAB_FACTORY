# 問題 20260920-022

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
flow record REC-CORP
 match ipv4 source address
 match ipv4 destination address
 match ipv4 protocol
 match transport source-port
 match transport destination-port
 collect counter bytes
 collect counter packets
!
flow exporter EXP-CORP
 ［①］ 198.51.100.100
 ［②］ Loopback0
 transport udp 9995
 export-protocol ipfix
!
flow monitor MON-CORP
 ［③］ EXP-CORP
 ［④］ REC-CORP
!
interface Ethernet0/2
 ip flow monitor MON-CORP output
```

FNF は 3 つの部品と 1 つの適用で組む。レコードでは match で指定したフィールドがキーになり、その値の組が同じパケットは 1 つのフローにまとめられる。collect で指定したフィールドは集計や付加情報(バイト数・パケット数など) で、フローの識別には使われない。エクスポータはコレクタの宛先・送信元・UDP ポート・export-protocol(既定は［⑤］)を持つ。モニタはキャッシュを持つ実体で、レコードとエクスポータを名前で束ねる。最後にインターフェースへ適用して初めて計測が始まる。Ethernet0/2 は隣接ルータ側の IF なので、そこへ出ていく通過トラフィックを見るには output に適用する。コレクタが無くても show flow monitor MON-CORP cache でフローが採取されているかを確認できる。

## 選択肢

A. destination

B. origin

C. record

D. collector

E. source

F. exporter

G. template

H. netflow-v9

I. flow-record

J. netflow-v5
