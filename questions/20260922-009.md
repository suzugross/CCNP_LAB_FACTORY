# 問題 20260922-009

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

ASW1 のアクセス ポートに利用者がハブを接続したと申告があった後、そのポートの通信ができなくなりました。ASW1 では次のログと出力を確認しました。

```
*Sep 22 05:10:42.525: %SPANTREE-2-BLOCK_BPDUGUARD: Received BPDU from bridge 001a.a17c.1a57 on port Gi1/0/17 with BPDU Guard enabled. Disabling port.
*Sep 22 05:10:42.525: %PM-4-ERR_DISABLE: bpduguard error detected on Gi1/0/17, putting Gi1/0/17 in err-disable state

ASW1# show interfaces status err-disabled

Port         Name         Status       Reason               Err-disabled Vlans

Gi1/0/17                  err-disabled bpduguard
```

## 設問

この出力から読み取れることとして正しいものはどれですか。(1つを選択してください)

## 選択肢

A. このポートは BPDU を受信したことで err-disabled になった

B. このポートはブロッキング状態で BPDU の受信だけは続けている

C. このポートは既定で 300 秒後に自動で回復する

D. このポートは root-inconsistent 状態になっている
