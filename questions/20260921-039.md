# 問題 20260921-039

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

アクセス スイッチ ACC-SW2 の VLAN 100 には、正規のルータ RTR-A(Ethernet0/0)、端末 CLIENT1(Ethernet0/1)、および管理者が把握していない装置(Ethernet0/2)が接続されています。RTR-A は優先度 Medium の RA で プレフィックス 2001:DB8:20::/64 を広告し、DHCPv6 で DNS サーバとドメイン名を配布しています。Ethernet0/2 の装置は優先度 High の RA でプレフィックス 2001:DB8:FFFF::/64 を広告し、DHCPv6 サーバとしても応答しています。ACC-SW2 には次の構成があります。

```
ACC-SW2# show running-config | section raguard|dhcp guard|prefix-list|vlan configuration|interface Ethernet0/
ipv6 nd raguard policy HOSTS
ipv6 nd raguard policy ROUTERS
 device-role router
ipv6 nd raguard policy TRUSTED
 trusted-port
ipv6 dhcp guard policy NO-SERVER
 device-role client
ipv6 dhcp guard policy DHCP-SERVER
 device-role server
interface Ethernet0/0
 description to RTR-A
 switchport access vlan 100
 switchport mode access
 ipv6 nd raguard attach-policy ROUTERS
 ipv6 dhcp guard attach-policy DHCP-SERVER
interface Ethernet0/1
 description to CLIENT1
 switchport access vlan 100
 switchport mode access
 ipv6 nd raguard attach-policy HOSTS
 ipv6 dhcp guard attach-policy NO-SERVER
interface Ethernet0/2
 description access
 switchport access vlan 100
 switchport mode access
 ipv6 nd raguard attach-policy TRUSTED
 ipv6 dhcp guard attach-policy NO-SERVER
```

CLIENT1 が Ethernet0/2 に接続された装置の広告するプレフィックス 2001:DB8:FFFF::/64 のアドレスを取得し、その装置をデフォルト ルータとして使用しています。

## 設問

Ethernet0/2 の装置からの不正なメッセージを止めたうえで、CLIENT1 が RTR-A から正しくアドレスと DHCPv6 の情報を取得できるようにします。ACC-SW2 に加える変更として最も適切なものは、次のうちどれですか。なお、端末とルータの構成は変更できません。(1つを選択してください)

## 選択肢

**A.**

```
ipv6 nd raguard policy TRUSTED
 trusted-port
interface Ethernet0/0
 ipv6 nd raguard attach-policy TRUSTED
```

**B.**

```
ipv6 nd raguard policy ROUTERS
 router-preference maximum high
```

**C.**

```
vlan configuration 100
 ipv6 nd raguard attach-policy ROUTERS
```

**D.**

```
interface Ethernet0/2
 ipv6 nd raguard attach-policy HOSTS
```
