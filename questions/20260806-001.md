# 問題 20260806-001 : 送信元アドレスの検証のための分析

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたの会社のエッジのルータは、2つのアップリンクによって、2つのサービス・プロバイダへ
接続されている、というものです。顧客のネットワーク 192.168.33.0/24 および
192.168.132.0/24 は、それぞれのプロバイダを経由して、広告されています。

```
          RT02 (エッジ・被験のデバイス)
   Ethernet0/0 |            | Ethernet0/1
  10.153.12.0/30      10.153.13.0/30
        |                    |
      RT03 (ISP-A)        RT01 (ISP-B)
```

- 監視のためのホスト: `192.168.132.62` および `192.168.132.108`
  (192.168.132.0/24 の中に存在し、ISP-B 側から着信します)

## 要件

1. 監視のためのホストである 192.168.132.62 および 192.168.132.108 からの、正規のトラフィックが、破棄されてはなりません。
2. 検証に対する例外は、個々のホストのアドレスに限定して、アクセス・リストによって明示的に許可されなければなりません(ネットワーク単位での許可は、認められていません)。
3. エッジのルータの両方のアップリンクのインターフェイスにおいて、送信元アドレスの検証(anti-spoofing)が、有効にされていなければなりません。
4. 着信のインターフェイスと一致しない送信元を持つところのトラフィックは、破棄されなければなりません。
5. ルーティング・プロトコルの種別およびプロセスの配置(ドメインの構成)は、変更されてはなりません。

## 設定抜粋

```
RT02# show running-config | section interface
interface Ethernet0/0

interface Ethernet0/1
 ip address 10.153.13.1 255.255.255.252
```

## 設問

示されているところのすべての要件が満たされることを確実にするために、適用されなければならない構成は、どれですか。(1つを選択してください)
