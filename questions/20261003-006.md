## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

| 項目 | 従来の NetFlow(v5) | NetFlow v9 | IPFIX(v10) |
|---|---|---|---|
| レコードの形式 | ［①］ | テンプレートベース(フィールドを選べる) | テンプレートベース |
| IPv6 / MPLS などのフロー | ［②］ | 可 | 可 |
| 標準化 | Cisco 独自 | Cisco 独自(RFC 3954 で公開) | ［③］ |
| FNF の export-protocol | netflow-v5(v5 固定分のフィールドだけ) | ［④］ | ipfix |
| 有効化のしかた | ［⑤］ | flow monitor を IF に適用 | flow monitor を IF に適用 |

従来の NetFlow はフローの定義が固定で、キーは送信元/宛先 IP・送信元/宛先ポート・プロトコル・ToS・入力 IF の 7 項目である。v9 と IPFIX はレコードの構成をテンプレートで先に通知するため、コレクタはテンプレートを受け取ってからでないとデータレコードを解釈できない。従来 NetFlow のキャッシュは show ip cache flow で、FNF のキャッシュは `show flow monitor <名> cache` で見る。従来 NetFlow のエクスポート先は `ip flow-export destination` と `ip flow-export version` で指定する。

## 選択肢

A. netflow-v9(既定)

B. 不可(IPv4 のみ)

C. 固定フォーマット(フィールドを変えられない)

D. JSON 形式

E. ip flow-top-talkers を有効化

F. 可

G. ipfix(既定)

H. IF に ip flow ingress / egress

I. Cisco 独自
