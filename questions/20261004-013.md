## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
crypto isakmp policy 10
 encryption aes 256
 hash sha256
 authentication pre-share
 group 14
crypto isakmp key Wan#Key2026 address ［①］
crypto isakmp keepalive 10 3
crypto ipsec transform-set TS-AES esp-aes 256 esp-sha256-hmac
 mode ［②］
crypto ipsec profile IPSEC-PROF
 set transform-set TS-AES
!
interface Tunnel0
 ［③］ ipsec profile IPSEC-PROF
```

isakmp policy は［④］で、encryption・hash・authentication・group・lifetime を相手と一致させる。事前共有鍵の address を［①］にしているのはスポーク間直接通信の相手 NBMA が事前に分からないためである。transform-set は IKE フェーズ 2(IPsec SA)で使う ESP のアルゴリズムとモードで、GRE 済みのトンネルなので［②］にする。IPsec プロファイルは transform-set(と pfs)を束ねる器で、［③］で Tunnel に貼ると Tunnel を通る全パケットが対象になる。crypto map 方式との違いは暗号化対象を ACL で列挙せず、物理 IF ではなく Tunnel IF に適用するである。`crypto isakmp keepalive` は［⑤］である。
