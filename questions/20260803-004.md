# 問題 20260803-004 : 送信元アドレスの検証のための分析

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたの会社のエッジのルータは、2つのアップリンクによって、2つのサービス・プロバイダへ
接続されている、というものです。顧客のネットワーク 192.168.76.0/24 および
192.168.192.0/24 は、それぞれのプロバイダを経由して、広告されています。

```
          RT03 (エッジ・被験のデバイス)
   Ethernet0/0 |            | Ethernet0/1
  10.105.12.0/30      10.105.13.0/30
        |                    |
      RT02 (ISP-A)        RT01 (ISP-B)
```

- 監視のためのホスト: `192.168.192.80` および `192.168.192.143`
  (192.168.192.0/24 の中に存在し、ISP-B 側から着信します)

## 要件

1. インタフェースの IP アドレッシングは、変更されてはなりません。
2. 監視のためのホストである 192.168.192.80 および 192.168.192.143 からの、正規のトラフィックが、破棄されてはなりません。
3. 着信のインターフェイスと一致しない送信元を持つところのトラフィックは、破棄されなければなりません。
4. 検証に対する例外は、当該のネットワークの単位で、アクセス・リストによって許可されなければなりません(個々のホストの列挙による運用は、認められていません)。
5. エッジのルータの両方のアップリンクのインターフェイスにおいて、送信元アドレスの検証(anti-spoofing)が、有効にされていなければなりません。

```
RT03# show running-config | section interface
interface Ethernet0/0
 ip address 10.105.12.1 255.255.255.252
 ip verify unicast source reachable-via rx
interface Ethernet0/1
 ip address 10.105.13.1 255.255.255.252
 ip verify unicast source reachable-via rx
```

## 設問

この事象の原因である可能性が、最も高いものは、どれですか。(1つを選択してください)

## 選択肢

A. ISP-B 向けインターフェイスに検証の構成が適用されていない
B. ISP-B 向けインターフェイスの検証モードが、非対称に広告されているネットワークに対して厳格すぎる
C. アクセス・リストが、インターフェイスの in 方向に適用されている
D. エッジのルータに、既定のルートが構成されていない
E. 検証の構成が参照しているアクセス・リストの番号と、定義されているアクセス・リストの番号とが一致していない
F. アクセス・リストにおいて許可されているホストが、対象のホストと異なっている
