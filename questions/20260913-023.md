# 問題 20260913-023

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

SNMP のコミュニティ・v3・通知について、正しく述べられているものを、次のうちから 2 つ選択してください。

## 選択肢

A. コミュニティに付与したアクセス・リストが未定義の場合、すべての送信元からのアクセスが許可される。

B. SNMPv3 のセキュリティ・レベル authPriv は、認証と暗号化の両方を行う。

C. コンソール・モニタ・バッファのロギングの既定のレベルは debugging(7)である。

D. snmp-server host にバージョンを指定しない場合、既定でバージョン 2c の inform が送信される。

E. 読み取り専用(RO)のコミュニティでも、SNMP の SET は成功する。
