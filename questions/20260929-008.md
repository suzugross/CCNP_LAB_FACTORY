# 問題 20260929-008

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

2台のルータが、1本のリンクによって直接に接続されており、そして、それぞれのループバック・インターフェイスを使用して、BGP のピアが構成されています。両ルータは、同一の AS 65153 に所属しています。ネイバーの状態に関する事象が、報告されています。調査のために、両方のルータにおいて `debug ip bgp` が有効にされ、そして、ログが採取されました。ピアの確立が、いずれか一方の側からの接続の開始に、依存しないものとします。両ルータの間で、BGP のピアが確立される、かつ、ループバック・インターフェイスの間でピアリングを行う設計が、維持されるという条件において、示されているところのすべての要件が満たされることを確実にするために、行われなければならない構成の変更は、どれとどれですか。(2つを選択してください)

```
  [RT01]  Lo0=63.63.63.63          [RT02]  Lo0=32.32.32.32
    10.208.220.1 ────────────────── 10.208.220.2   (10.208.220.0/30)
```
