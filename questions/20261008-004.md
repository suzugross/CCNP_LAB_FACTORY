## 設問

archive と構成の管理について、正しく述べられているものを、次のうちから 2 つ選択してください。

## 選択肢

A. archive の time-period は、指定した分の間隔で構成を自動で保存する。

B. archive の log config は、show や debug のコマンドも記録する。

C. configure replace は、reload を伴って構成を置き換える。

D. SCP は SSH のうえで動作し、SSH が有効である必要がある。

E. archive の log config は、投入された構成コマンドの変更ログを記録する。
