# 問題 20260919-071

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
aaa new-model
aaa authentication login default group AAA-SRV local
aaa authorization exec default group AAA-SRV
aaa authorization console
username emg-admin privilege 15 secret 9 $9$xxxx      ! local だけに存在
! サーバ台帳: noc-taro= shell:priv-lvl=15 / helpdesk= shell:priv-lvl=1
```

認証が通ってもログイン後の権限は認可が決める。サーバは Access-Accept に［①］を付けて返す。この盤面でサーバが正常なとき、noc-taro がログインした直後の権限レベルは 15(特権 EXEC)、helpdesk は 1(ユーザ EXEC)。サーバが 2 台とも無応答のとき、local だけにいる emg-admin は認証には通り、その後 EXEC を拒否され入れない(local ユーザも締め出し)。この構成に対する評価は［②］。なお認証は local で通っても、認可がサーバへ照会して［③］された場合は EXEC が拒否される(拒否は権威の原則)。コンソールは［④］が無いと exec 認可自体が実行されない。

## 選択肢

A. aaa authorization exec default group AAA-SRV local を追加すべき

B. aaa authorization console

C. exec 認可の末尾に local(または if-authenticated)を追加すべき

D. shell:priv-lvl=15

E. Framed-Protocol=PPP

F. タイムアウト

G. line con 0 の privilege level 15

H. 拒否(Reject)
