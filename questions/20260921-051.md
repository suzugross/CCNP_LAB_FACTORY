# 問題 20260921-051

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
RT01# test aaa group RADGRP noc-taro Noc-1234 legacy
Attempting authentication test to server-group RADGRP using radius
No authoritative response from any server.

(参考) radius-server timeout 3 / radius-server retransmit 2 / グループ内サーバ 2 台
```

`test aaa` の応答は 3 種類しかない。即座(0.1 秒)に返る「User was successfully authenticated.」、約 1 秒で返る「User authentication request was rejected by server.」、そして約 18 秒待って返る「No authoritative response from any server.」である。3 つ目の秒数は［①］から来る。ログインの見え方も同じ 3 値で、拒否なら local に同じユーザがいても［②］、無応答なら 18 秒ほど待たされたあと［③］。したがって「待たされて入れた」はサーバに届いていない/鍵不一致/ポート違いを、「すぐ弾かれた」はユーザ未登録やパスワード誤り(サーバが拒否) を疑う。厄介なのは共有鍵の不一致で、サーバは実は Reject を返しているのに、装置は鍵が違うため応答の Response Authenticator を検証できず捨てる。結果として装置側は「無応答」と全く同じ文言・同じ秒数になり、送信元アドレスの誤り(サーバ側で unknown client として破棄)とは［④］でしか区別できない。

## 選択肢

A. show aaa servers

B. timeout 3 秒 × 4 回

C. サーバ台帳のユーザだけ入れる

D. 権限レベル 1 で入れる

E. サーバ側のログ

F. 入れない

G. local のユーザなら入れる

H. timeout 3 秒 × (1+再送 2)回 × 2 台
