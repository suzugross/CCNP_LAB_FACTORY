# 問題 20260927-006

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

```
R1# show running-config(抜粋)
interface Ethernet0/0
 ip address 192.168.20.1 255.255.255.0
! (クライアントを収容)
! DHCP サーバは 10.1.191.219 に存在する
```

## 設問

この LAN のクライアントが IP アドレスを取得できない。 この事象を解消するために必要な構成として最も適切なものは、次のうちどれですか。(1つを選択してください)

## 選択肢

**A.**

```
interface Ethernet0/0
 ip flow monitor MON input
```

**B.**

```
ip dhcp excluded-address 192.168.20.1 192.168.20.10
```

**C.**

```
interface Ethernet0/0
 ip helper-address 10.1.191.219
```

**D.**

```
service dhcp
```
