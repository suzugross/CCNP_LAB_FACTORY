## 設問

GRE は元のパケットに新しい IP ヘッダ 20 バイトと GRE ヘッダ［①］バイト(tunnel key 付きなら +4)を足すので、物理 MTU 1500 の Tunnel IF の既定 ip mtu は［②］になる。IPsec(ESP transport)がさらに 50〜60 バイトほど足す。DMVPN の定石は Tunnel IF に `ip mtu ［③］` と `ip tcp adjust-mss 1360` で、MSS は ip mtu から IP と TCP のヘッダ分を引いた値にする。adjust-mss は TCP の SYN に載る MSS を書き換えて端末に最初から小さいセグメントを送らせるので、PMTUD が ICMP フィルタで壊れている環境でも効く。ip mtu を書かなくても小さな ping は通る(実測では外側 GRE が断片化して救済され、DF は外側に複製されない)が、断片化は［④］を招くので明示するのが定石である。
