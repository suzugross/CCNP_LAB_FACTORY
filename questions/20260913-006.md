# 問題 20260913-006

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

SSH の有効化と vty の構成について、正しく述べられているものを、すべて選んでください。

## 選択肢

A. vty の access-class は、SSH で接続できる送信元を制限する。

B. vty に transport input telnet だけを構成しても、SSH で接続できる。

C. ip ssh authentication-retries は、認証のタイムアウトを秒で指定する。

D. SSH を有効にするには、vty 回線の transport input に ssh を含める必要がある。

E. crypto key generate rsa に label を指定すると、鍵はその名前で作られる。
