# 問題 20260913-028

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたは、ネットワークの運用を担当しています。2台のルータが、1本のリンクによって直接に接続されており、そして、それぞれのループバック・インターフェイスを使用して、BGP のピアが構成されています。両ルータは、同一の AS 65093 に所属しています。

```
  [RT02]  Lo0=11.11.11.11          [RT01]  Lo0=75.75.75.75
    10.228.53.1 ────────────────── 10.228.53.2   (10.228.53.0/30)
```

- 対向のループバックへの到達性は、OSPF 37 によって提供されています。

## 要件

1. 両ルータの間で、BGP のピアが確立されること。
2. ループバック・インターフェイスの間でピアリングを行う設計が、維持されること。
3. ピアの確立が、いずれか一方の側からの接続の開始に、依存しないこと。

## 設問

router bgp 65093

```

```
