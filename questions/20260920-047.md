# 問題 20260920-047

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

MPLS L3VPN における RD・RT・MP-BGPについて、正しく述べられているものを、次のうちから 2 つ選択してください。

## 選択肢

A. mpls ldp router-id コマンドに force を付けると、構成したルータ ID が即座に反映される。

B. 同一の VRF において、RT の import の値と export の値は異なっていてもよい。

C. MP-BGP は、顧客拠点のネットワークを集約するために使用される。

D. send-community extended が構成されていない場合、RT が伝わらず、対向の PE の VRF に経路が取り込まれない。

E. VPNv4 経路は、LDP によって PE ルータ間で配布される。
