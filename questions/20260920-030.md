## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

| 項目 | EIGRP | OSPF |
|---|---|---|
| ハブがスポークの経路を他スポークへ広告するために | ［①］ | 不要(リンクステートに split horizon の概念は無い) |
| Phase 2 で next-hop を対向スポークのまま届ける | no ip next-hop-self eigrp <AS> | ip ospf network broadcast(next-hop が元のまま届く) |
| トンネル IF のネットワークタイプ | (概念なし) | ［②］ |
| DR/BDR | (概念なし) | ハブだけが DR(スポークは ip ospf priority 0) |
| Phase 3 のハブでの経路集約 | ［③］ | エリア境界でしか集約できない(全員が同一エリアなら不可) |

OSPF の point-to-multipoint は［④］ので Phase 1 向きで、Phase 2 の直接通信には使えない。broadcast タイプではスポークが DR になると［⑤］ため、スポーク側で priority を 0 にする。Tunnel IF の OSPF ネットワークタイプは既定で point-to-point であり、そのままでは複数のスポークと隣接を張れない。EIGRP では Phase を問わずハブの split horizon 解除が要り、Phase 2 だけ next-hop-self の無効化も要る。

## 選択肢

A. ip summary-address eigrp <AS> <集約> <マスク>

B. 全 Phase で point-to-point

C. no ip split-horizon eigrp <AS>

D. Phase 1= broadcast / Phase 2・3= point-to-multipoint

E. hello の間隔が変わって隣接が落ちる

F. 他のスポークがその DR と直接隣接を張れず LSDB が同期しない

G. ホスト経路を広告しない

H. DR を必要とする

I. next-hop を常に広告元(ハブ)に書き換える

J. Phase 1= point-to-multipoint / Phase 2・3= broadcast
