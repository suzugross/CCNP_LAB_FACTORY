## シナリオ

RB で次の出力が得られました。

```
RB# show ipv6 interface brief
Ethernet0/0            [up/up]
    FE80::0C2A:11FF:FE3B:9C01
    2001:DB8:100::0C2A:11FF:FE3B:9C01

RB# show ipv6 routers
Router FE80::A8BB:CCFF:FE01:5800 on Ethernet0/0, last update 0 min
  Hops 64, Lifetime 1800 sec, AddrFlag=0, OtherFlag=0, MTU=1500
  HomeAgentFlag=0, Preference=Medium
  Reachable time 0 (unspecified), Retransmit time 0 (unspecified)
  Prefix 2001:DB8:100::/64 onlink autoconfig
    Valid lifetime 2592000, preferred lifetime 604800
```

## 設問

この出力から分かることとして、正しく述べられているものは、次のうちどれですか。(1つを選択してください)

## 選択肢

A. RB のグローバル ユニキャスト アドレスは、DHCPv6 サーバから割り当てられたものである。

B. RA のプレフィックスは autoconfig フラグ(A)が立っていない。

C. DHCPv6 サーバは RB にアドレスを割り当てていない。

D. RB はステートフル DHCPv6 でアドレスと DNS を取得している。
