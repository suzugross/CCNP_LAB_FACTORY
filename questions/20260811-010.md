# 問題 20260811-010

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

あなたは、ネットワークの運用を担当しています。ある企業のネットワークにおいて、RT01 は、顧客の側のネットワークと、サーバの側のネットワークとの間に、配置されています。アクセス・リストは、示されているところの内容から変更されていません。RT01 には、社内の複数のネットワークからサーバ `172.27.139.36` および DNS サーバ `172.27.139.202` へのアクセスを制御するためのアクセス・リストが構成されています。

```
   RT02 (顧客の側)                RT03 (サーバの側)
        |  10.55.253.0/24        10.55.254.0/24  |
        +--------- RT01 ---------+
                (被験のデバイス)
```

## 出力

    20 permit tcp 10.55.16.0 0.0.0.255 host 172.27.139.36 eq 443

RT01# show running-config | section access-list|access-group|distribute-list|verify unicast|ip nat|access-class|class-map

## 設問

次の3つの通信について、示されているところの構成において正しく述べているものは、どれですか。(1つを選択してください)
1. `10.55.16.5` から `172.27.139.36` の TCP ポート 443 宛て
2. `10.55.17.5` から `172.27.139.36` の TCP ポート 443 宛て
3. `10.55.87.11` から `172.27.139.36` の TCP ポート 16434 宛て

## 選択肢
A. 2、3 のみが転送される。

B. 3 のみが転送される。

C. いずれも破棄される。

D. 1、3 のみが転送される。

E. 2 のみが転送される。

F. いずれも転送される。

G. 1、2 のみが転送される。
