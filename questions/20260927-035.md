# 問題 20260927-035

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
aaa new-model
aaa authentication login default local group TAC-GRP
!
username emg-admin privilege 15 secret 9 $9$xxxx    ! local だけに存在
! 認証サーバの台帳: ope-suzuki(サーバだけに存在)
!
line vty 0 15
 transport input ssh
 ! (login authentication 未指定)
```

aaa new-model を入れた瞬間に全回線が AAA のメソッドリストで認証されるので、投入前に別のセッションを開いたままにしておく。上の default のリストは［①］に効く。メソッドは左から順に試され、次へ進むのは前のメソッドが応答しない(タイムアウト/到達不能) ときだけで、［②］場合はそこで確定する(次へは行かない)。この盤面でサーバが正常に応答しているとき、local だけにいる emg-admin は local で即座に入れる。サーバだけにいる ope-suzuki は［③］。サーバが 2 台とも無応答のとき、emg-admin は［④］。なお、回線に付けたリスト名が定義されていないと、IOS は default と同じ動きをする(実測)。

## 選択肢

A. 拒否(Reject)した

B. タイムアウトした

C. コンソールだけ

D. サーバで即座に入れる

E. local に無いので次のサーバへ進み、入れる

F. 待たされずに local で入れる

G. 名前付きリストを付けていない全回線

H. 約 12 秒待ったあと local で入れる
