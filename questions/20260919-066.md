## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
aaa new-model
aaa authentication login default local group AAA-SRV
!
username local-admin privilege 15 secret 9 $9$xxxx    ! local だけに存在
! 認証サーバの台帳: ope-suzuki(サーバだけに存在)
!
line vty 0 15
 transport input ssh
 ! (login authentication 未指定)
```

aaa new-model を入れた瞬間に全回線が AAA のメソッドリストで認証されるので、投入前に別のセッションを開いたままにしておく。上の default のリストは［①］に効く。メソッドは左から順に試され、次へ進むのは前のメソッドが応答しない(タイムアウト/到達不能) ときだけで、［②］場合はそこで確定する(次へは行かない)。この盤面でサーバが正常に応答しているとき、local だけにいる local-admin は［③］。サーバだけにいる ope-suzuki は local に無いので次のサーバへ進み、入れる。サーバが 2 台とも無応答のとき、local-admin は待たされずに local で入れる。なお、回線に付けたリスト名が［④］と、IOS は default と同じ動きをする(実測)。

## 選択肢

A. サーバが拒否するので入れない

B. コンソールだけ

C. DEAD 判定された

D. local で即座に入れる

E. 2 つ以上ある

F. 名前付きリストを付けていない全回線

G. 拒否(Reject)した

H. 定義されていない
