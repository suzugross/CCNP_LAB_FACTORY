## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
aaa accounting exec default ［①］ group RADGRP
aaa accounting commands 15 default stop-only group RADGRP
aaa accounting ［②］ default start-stop group RADGRP
aaa accounting system default start-stop group RADGRP
```

アカウンティングは「誰が・いつ・何を」をサーバへ送る機能で、認証や認可と違い失敗してもログインや操作は妨げない。種類は、ログインセッションの［③］、打ったコマンドの記録である commands <レベル>、PPP などの［②］、装置の再起動などの system がある。記録のタイミングは［①］なら開始と終了の 2 レコード、stop-only なら終了時の 1 レコード、wait-start なら開始レコードがサーバに受理されるまでセッションを始めない。RADIUS では Accounting-Request が UDP 1813 へ送られ、サーバは Accounting-Response で受領を返す。コマンド単位の記録は［④］でのみ実用的で、変更履歴の監査に使う。

## 選択肢

A. start-stop

B. resource

C. stop-only

D. exec

E. TACACS+

F. network

G. RADIUS

H. login
