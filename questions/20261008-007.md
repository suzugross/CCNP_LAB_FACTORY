# 問題 20261008-007

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜⑤ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
ip flow-export destination 198.51.100.100 2055
ip flow-export version 5
!
interface Ethernet0/2
 ［①］
!
ip flow-top-talkers
 ［②］ 10
 ［③］ bytes
!
RT02# show ip flow top-talkers
SrcIf   SrcIPaddress   DstIf   DstIPaddress   Pr SrcP DstP Bytes
Et0/2   192.168.7.30      Et0/1   192.168.9.40      06 C1A2 0050  4608000
Et0/2   192.168.7.31      Et0/1   192.168.9.53      11 A3F0 0035  122880
2 of 10 top talkers shown. 2 flows processed.
```

従来の NetFlow で上位フローを見るには、まず IF に［①］を付けて採取を有効にし、`ip flow-top-talkers` 配下で［②］に表示件数(1〜200)、［③］に並べ替えの基準(bytes か packets)を書く。結果は show ip flow top-talkers で見る。これは［④］ので、コレクタへのエクスポートが動いていなくても使える。FNF で同じことをするには show flow monitor MON-CORP cache sort highest counter bytes のようにキャッシュをその場でソートし、末尾に件数の指定を付けて絞る。ただし並べ替えに使えるのは［⑤］だけなので、バイト数で並べたければレコードに collect counter bytes が要る。

## 選択肢

A. 任意のフィールド

B. ip route-cache flow

C. そのレコードに含まれるフィールド

D. top

E. order-by

F. limit

G. エクスポートパケットを並べ替えて送る

H. sort-by

I. 装置上のキャッシュをソートして表示するだけ

J. ip flow ingress
