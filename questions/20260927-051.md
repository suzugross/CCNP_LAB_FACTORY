# 問題 20260927-051

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## シナリオ

FTP のサーバ 10.1.10.165 は、ユーザ名 `netops`・パスワード `Backup!9` での認証を要求し、匿名のログインを拒否します。この装置には ip ftp username および ip ftp password は構成されていません。

## 設問

この装置の running-config を、このサーバへファイル名 `config.txt` で保存するコマンドとして正しいものは、次のうちどれですか。(1つを選択してください)

## 選択肢

**A.**

```
copy running-config ftp://10.1.10.165/config.txt
```

**B.**

```
copy running-config tftp://netops:Backup!9@10.1.10.165/config.txt
```

**C.**

```
copy running-config ftp://netops:Backup!9@10.1.10.165/config.txt
```

**D.**

```
copy running-config ftp:/netops:Backup!9@10.1.10.165/config.txt
```
