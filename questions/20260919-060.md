# 問題 20260919-060

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
aaa new-model
aaa authentication login default group AAA-SRV local
aaa authentication login REMOTE group AAA-SRV local-case
aaa authentication login CONSOLE ［①］
!
line con 0
 login authentication CONSOLE
line vty 0 4
 login authentication REMOTE
line vty 5 15
 ! (login authentication 未指定)
```

aaa new-model を入れた瞬間に全回線が AAA のメソッドリストで認証されるようになるので、投入前に別のセッションを開いたままにしておく。リストは「メソッドを最大 4 つ順に並べたもの」で、名前が default のものは［②］に自動で効き、名前付きのものは回線に `login authentication <名前>` で付けたときだけ効く。上の例では vty 5〜15 には［③］が効く。重要なのは次のメソッドへ進む条件で、先頭のサーバグループが応答しない(タイムアウト/到達不能) ときだけ次(local)へ進む。サーバが応答して［④］場合はそこで確定し、local に同じユーザがいてもログインできない。この「拒否は権威・無応答だけが素通り」の原則は認可と enable 認証にも同じく効く。`local-case` はユーザ名の大文字小文字を区別する local である。回線に付けたリスト名が定義されていないと、IOS は default と同じ動きをする(実測)。上の CONSOLE リストにある［①］は「認証なしで許可」のメソッドで、締め出し保険に使えるが、そのぶん危険でもある。

## 選択肢

A. 拒否(Reject)した

B. CONSOLE のリスト

C. vty だけ

D. default のリスト

E. 名前付きリストを付けていない全回線

F. タイムアウトした

G. line

H. none
