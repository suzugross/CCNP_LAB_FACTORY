# Question 20261008-003

> **Answer this question without connecting to any device. No additional show commands may be run.**

## Scenario

The following configuration and output are shown.

```
RT01# show running-config | include ntp
ntp authentication-key 10 md5 <hidden>
ntp authenticate
ntp server 10.99.175.2 key 10

RT01# show ntp associations
  address         ref clock       st   when   poll reach  delay  offset   disp
 ~10.99.175.2    .AUTH.          16      -     64     0  0.000   0.000 15937.
 * sys.peer, # selected, + candidate, - outlyer, x falseticker, ~ configured
```

## Question

This router does not synchronize with the specified NTP server. Which of the following is the most likely cause of this issue? (Choose one.)

## Choices

A. The time source specified by ntp server is not reachable.

B. ntp trusted-key is not configured, and the authentication is not complete.

C. The value of the NTP authentication key does not match between the client and the server.

D. The server has no return route to the source address specified by ntp source.

E. ntp authenticate is not configured, and the key is not verified.
