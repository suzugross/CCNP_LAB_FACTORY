## Question

For each of the blanks ① through ⑤ in the following explanation (which includes a configuration example), select one term from choices A through J below. No term is used in two blanks. The choices include terms that do not fit any of the blanks.

```
spanning-tree mode mst
!
spanning-tree mst configuration
 name HQ-MST
 revision 1
 instance 1 vlan 10,20
 instance 2 vlan 30,40
!
spanning-tree mst 1 priority 24576
spanning-tree mst 2 priority 28672
```

The default STP mode on Cisco switches is ［①］, which builds an independent 802.1D tree for each VLAN. With `spanning-tree mode rapid-pvst`, the trees remain per VLAN but run RSTP. When there are many VLANs, the BPDUs and the computation increase with the number of trees, so MST (Multiple Spanning Tree) (802.1s) groups multiple VLANs into 1 instance. In the configuration above, VLANs 10 and 20 share 1 tree and VLANs 30 and 40 share 1 tree, and the load is shared by using a different root for each. A VLAN that is not listed in any instance (for example, VLAN 50) belongs to IST (instance 0). To be considered part of the same region, all 3 of ［②］ must match exactly; a switch on which even 1 of them differs is treated as a different region, and a port between them takes the role of ［③］. For connections between regions and to 802.1D/PVST+, only 1 ［④］ is built, and from the outside each region appears as 1 giant switch. The configuration is verified with `show spanning-tree mst configuration`, and changes do not take effect until ［⑤］.
