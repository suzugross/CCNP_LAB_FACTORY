# 問題 20261007-007

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
radius-server timeout 3
radius-server retransmit 1
! (radius-server dead-criteria なし)
aaa group server radius RADGRP
 server name RAD1
 server name RAD2
 deadtime 5
!
RT01# show aaa servers
RADIUS: id 1, priority 1, host 192.168.100.11, auth-port 1812, acct-port 1813, hostname RAD1
     State: current UP, duration 4333s, previous duration 0s
RADIUS: id 2, priority 2, host 192.168.100.12, auth-port 1912, acct-port 1913, hostname RAD2
     State: current UP, duration 4021s, previous duration 0s
```

RAD1(192.168.100.11)が停止して 5 分ほど経っている。radius-server dead-criteria time/tries は「何秒応答が無く、何回失敗したら DEAD とみなすか」の条件で、［①］は DEAD とみなしたサーバを何分間スキップするかである。この 2 つは片方だけでは機能しない。上の出力で RAD1 の State が UP(スキップされない) なのは［②］ためで、いまログインすると待ち時間は［③］。この構成に対する評価は radius-server dead-criteria time 3 tries 1 を追加すべき。RAD2 のポート 1912/1913 のように［④］は許され、サーバ側と一致していれば動く。なお DEAD は「応答が無かった」の判定であって、UP でも認証できないこと(鍵不一致など)はある。

## 選択肢

A. deadtime

B. 0 秒

C. 12 秒のまま(毎回 RAD1 のタイムアウトを待つ)

D. dead-criteria

E. IPv6 アドレス

F. 判定条件(time 3・tries 1)を満たした

G. 判定条件が無く、何回失敗しても状態が変わらない

H. 非標準ポート
