1. スタティック・ルートおよび既定のルートによる迂回は、実施されることはできません。
2. アクセス リストは、対象であるところのネットワークのみに、一致させなければなりません。
3. ムンバイ および フランクフルト のそれぞれのサイトから、業務のサービスのネットワーク `172.16.128.0/24`・`172.16.133.0/24` へ、到達することができること。
4. PBR が適用されるポイントおよびネクスト ホップの設計は、変更されることはできません。
5. 検証および隔離のためのネットワーク `172.16.134.0/24`・`172.16.144.0/24` へは、ポリシーによる転送が、実施されることはできません。

## 設問

次のうち、正しいものは、どれですか。

## 選択肢
A. MAP-A の match を「match ip address ACL-A」に設定し直す
B. ACL-A を「permit ip 192.168.112.0 0.0.0.255 172.16.128.0 0.0.1.255」の1行に置き換える
C. MAP-A の match を「match ip address prefix-list PL-A」に変更する(PL-A: 172.16.128.0/24 と 172.16.133.0/24 を permit)
D. ACL-A を「permit ip 192.168.112.0 0.0.0.255 172.16.128.0 0.0.16.255」の1行に置き換える
E. ACL-A を「permit ip 192.168.112.0 0.0.0.255 172.16.128.0 0.0.5.255」の1行に置き換える
F. ACL-A を「permit ip 192.168.112.0 0.0.0.255 172.16.128.0 0.0.0.255」「permit ip 192.168.112.0 0.0.0.255 172.16.133.0 0.0.0.255」の2行に置き換える
G. ACL-A を「deny ip 192.168.112.0 0.0.0.255 172.16.134.0 0.0.0.255」「permit ip 192.168.112.0 0.0.0.255 172.16.128.0 0.0.7.255」の2行(deny 先行)に置き換える
