## 設問

示されている要件のもとで、顧客の拠点間の通信を回復させるために適用されなければならない構成は、次のうちどれですか。(1つを選択してください)

## 選択肢

**A.**

```
CE-Red1(config)#router bgp 65210
CE-Red1(config-router)#address-family ipv4
CE-Red1(config-router-af)#neighbor 192.168.21.2 as-override
CE-Red2(config)#router bgp 65210
CE-Red2(config-router)#address-family ipv4
CE-Red2(config-router-af)#neighbor 192.168.22.2 as-override
```

**B.**

```
PE1(config)#router bgp 64512
PE1(config-router)#address-family ipv4 vrf Red
PE1(config-router-af)#neighbor 192.168.21.1 as-override
PE2(config)#router bgp 64512
PE2(config-router)#address-family ipv4 vrf Red
PE2(config-router-af)#neighbor 192.168.22.1 as-override
```

**C.**

```
CE-Red1(config)#router bgp 65210
CE-Red1(config-router)#address-family ipv4
CE-Red1(config-router-af)#neighbor 192.168.21.2 allowas-in
CE-Red2(config)#router bgp 65210
CE-Red2(config-router)#address-family ipv4
CE-Red2(config-router-af)#neighbor 192.168.22.2 allowas-in
```

**D.**

```
CE-Red1(config)#router bgp 65210
CE-Red1(config-router)#neighbor 192.168.21.2 ebgp-multihop 2
CE-Red2(config)#router bgp 65210
CE-Red2(config-router)#neighbor 192.168.22.2 ebgp-multihop 2
```

**E.**

```
PE1(config)#router bgp 64512
PE1(config-router)#address-family ipv4 vrf Red
PE1(config-router-af)#neighbor 192.168.21.1 allowas-in
PE2(config)#router bgp 64512
PE2(config-router)#address-family ipv4 vrf Red
PE2(config-router-af)#neighbor 192.168.22.1 allowas-in
```
