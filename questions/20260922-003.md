## 設問

次の説明文(設定例を含む)の空欄 ①〜⑥ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

root の位置は運任せにせず priority で決める。`spanning-tree vlan 10 root primary` は priority を［①］にする(現 root がそれより低ければ、現 root より priority を 1 段階下げた値)。`root secondary` は［②］に固定される。priority を直接書く場合は［③］の倍数しか受け付けない(既定 32768)。ポートのコストは帯域から決まり、short 方式では 100 Mbps= ［④］・1 Gbps= 4・10 Gbps= 2 である。long 方式(`spanning-tree pathcost method long`)では 1 Gbps= 20000 になる。root への経路を変えたいとき、自分のどのポートを root port にするかは［⑤］で変える。一方、対向スイッチのどのポートを root port にするかを自分側で決めるには `spanning-tree port-priority <値>`(インタフェース) を使う(既定 128・［⑥］刻み・小さいほど優先。対向から見た送信元 port ID として効く)。hello・forward delay・max age を変えるときは root bridge(root で設定した値が配られる) で設定する(BPDU に載って全体へ配られるため)。
