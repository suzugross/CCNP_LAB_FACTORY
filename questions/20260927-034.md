## 設問

次の説明文(設定例を含む)の空欄 ①〜⑥ に入る語句を、下の語群 A〜J から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

| 経路の出所 | AD |
|---|---|
| 直接接続 | ［①］ |
| スタティック | 1 |
| eBGP | ［②］ |
| EIGRP(内部) | ［③］ |
| OSPF | 110 |
| IS-IS | 115 |
| RIP | ［④］ |
| EIGRP(外部) | 170 |
| iBGP | 200 |
| 不明(使わない) | 255 |

AD は同じプレフィックスを複数の出所から学んだときに、どれを経路表に載せるかを決める信頼度で、［⑤］方が勝つ。同じプロトコル内の優劣はメトリックで決めるが、プロトコルをまたぐ比較はメトリックでは行えないので AD が要る。EIGRP は内部経路と外部(再配送)経路で値が違い、再配送ループを防ぐ意図で外部の方が［⑥］。BGP も eBGP と iBGP で値が違い、iBGP が大きいのは AS 内では IGP の経路を優先させたいためである。値はプロトコル配下の `distance` コマンドで変えられ、AD を最大値にした経路は「信頼しない」扱いで経路表に載らない。

B. 大きい(信頼度が低い)

D. 0
