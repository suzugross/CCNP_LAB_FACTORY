# 問題 20260920-046

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## 設問

MPLS のラベルと LSPについて、正しく述べられているものを、すべて選んでください。

## 選択肢

A. ラベルのフィールドは 32 ビットである。

B. LSP は、ラベルが付加されたパケットが入口の LER から出口の LER まで通過する片方向の経路である。

C. LDP の自動構成(autoconfig)は、OSPF と IS-IS で利用できる。

D. S フィールドは 8 ビットである。

E. PHP は、入口の LER でラベルを除去する動作である。
