## 設問

ファイル転送(tftp/ftp/scp)について、正しく述べられているものは、次のうちどれですか。(1つを選択してください)

## 選択肢

A. SCP のサーバには、ip scp server enable は不要である。

B. archive の write-memory は、write memory のたびに構成を自動で保存する。

C. URL の書式は、プロトコル名の後に単一のスラッシュを 1 つ置く(例 ftp:/host/file)。

D. ルータを SCP のサーバにするには、ip scp server enable が必要である。
