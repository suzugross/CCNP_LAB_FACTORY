# 問題 20260812-001

> **本問は機器に接続せずに解答すること。追加の show 実行は認めない。**

## トポロジ

あなたは、下記のネットワークの保守を担当する技術者です。拠点のルーター RT01 は、複数のループバック インターフェイスによって、サービスのためのアドレスのブロック 172.21.129.8/30 を収容しています。RT01 と RT02 は、1本のリンクによって直接に接続されており、そして、EIGRP 6571 が構成されています。

```
  [RT01]  Lo: 172.21.129.9, 172.21.129.10, 172.21.129.11 (+ 10.233.113.188)
    10.216.30.1 ─────(GigabitEthernet0/1)───── 10.216.30.2
  [RT02]
```

## 要件

1. RT02 に対して、ブロック 172.21.129.8/30 は、集約のルートとして広告されなければなりません。
2. 運用のためのループバック 10.233.113.188 (/32) は、引き続き受信されなければなりません。
3. インターフェイスにおける集約の構成は、過去の障害の経緯という理由により、認められていません。
4. ブロックの内部の明細のルートは、広告されてはなりません。
5. インタフェースの IP アドレッシングは、変更されてはなりません。
6. ただし、監視のためのホストである 172.21.129.10 (/32) の明細のルートは、集約とともに、受信されなければなりません。

## 設問

次のうち、正しいものは、どれですか。

## 選択肢
A. RT01 において、インターフェイスの集約の構成、および、172.21.129.10 を除くところのブロックのループバックの network のステートメントを削除する。`ip route 172.21.129.8 255.255.255.252 Null0` のスタティック・ルートを作成し、それを EIGRP 6571 へ再配送する

B. RT01 において、集約を `ip summary-address eigrp 6571 172.21.129.8 255.255.255.252 leak-map RM-NEW` の形へ構成し直し、RM-NEW は、172.21.129.11/32 を許可するところのプレフィックス・リストに一致させる

C. RT01 において、ブロックのループバックの network のステートメントを削除し、それらを `redistribute connected route-map` によって EIGRP 6571 へ注入する。そして、集約を `ip summary-address eigrp 6571 172.21.129.8 255.255.255.252 leak-map RM-NEW` の形へ構成し直し、RM-NEW は、172.21.129.10/32 を許可するところのプレフィックス・リストに一致させる

D. RT01 において、インターフェイスの集約の構成を削除し、172.21.129.10/32 および 10.233.113.188/32 を許可するところのプレフィックス・リストを、distribute-list として GigabitEthernet0/1 の out の方向に適用する

E. RT01 において、ブロックのループバックのすべてを network のステートメントによって EIGRP 6571 へ参加させる。そして、集約を `ip summary-address eigrp 6571 172.21.129.8 255.255.255.252 leak-map RM-NEW` の形へ構成し直し、RM-NEW は、172.21.129.10/32 を許可するところのプレフィックス・リストに一致させる
