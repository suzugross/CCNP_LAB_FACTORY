## 設問

次の説明文(設定例を含む)の空欄 ①〜④ に入る語句を、下の語群 A〜H から 1 つずつ選択してください。同じ語句を 2 つの空欄に使うことはありません。語群にはどの空欄にも当てはまらない語句が含まれます。

```
aaa new-model
!
tacacs server TAC1
 address ipv4 10.99.1.5
 key N0c-Tacacs
aaa group server tacacs+ TAC-SRV
 server name TAC1
ip tacacs source-interface Loopback0
!
aaa authentication login default group TAC-SRV local
aaa authorization exec default group TAC-SRV if-authenticated
aaa authorization commands 15 default group TAC-SRV local
［①］
aaa accounting exec default start-stop group TAC-SRV
aaa accounting commands 15 default start-stop group TAC-SRV
```

TACACS+ の価値はコマンド単位の制御にある。`aaa authorization commands 15` により、権限レベル 15 のユーザが打つコマンドは［②］サーバに問い合わせて許可・拒否される。ただし既定では設定モードのコマンドは認可対象に含まれず、［①］を入れて初めてインターフェース配下などの設定コマンドも照会される。exec 認可の末尾に置いた if-authenticated は「認証に成功していれば許可」というメソッドで、サーバ無応答時に締め出されないための保険である。アカウンティングは start-stop にすると開始と終了の両方が記録され、コマンドのアカウンティングでは「誰がいつ何を打ったか」が残る。TACACS+ はこの照会と記録を［③］の上で行うので、サーバとの間に TCP 49 が通っている必要がある。なおコマンド認可はサーバが応答している限り厳密に効くため、サーバの障害時に備えて［④］を末尾に置くのが定石である。
