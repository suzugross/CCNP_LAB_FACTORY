configure設定モードへ。プロンプトが (config)# になり、interface … などで下位モード((config-if)# など)へ入ります。下位モードで通らない文は上のモードで試されます

    
exit・root・end1 つ上へ・設定モードの一番上へ・設定モードを出る(コミットしていない変更があると聞かれます)

    
no …文を消す(まだ効かない)

    
show configuration編集中の変更(まだ効いていない分)。show commit changes diff で稼働中との差、show running-config で稼働中の設定

    
commit編集中の変更を確定。label・comment・confirmed <秒> を付けられます。abort は変更を捨てて出る

    
履歴show configuration commit list・… commit changes <回>。load rollback changes <回> でその 1 回の逆を編集中に入れる。運用モードの rollback configuration last <N> でまとめて戻す

Rules (Junos)

  

    
?Lists the words that can come next. In the middle of a word, only the words that start with those letters

    
Tab, SpaceCompletes the word (when there is one candidate). With several candidates, Tab lists them

    
↑ ↓Command history

    
configureEnters configuration mode. The prompt ends in # and [edit …] appears above it

    
set, deleteChange the candidate configuration (not in effect yet)

    
edit, up, topGo into a level, one level up, to the top. [edit …] shows where you are

    
showThe candidate configuration at this level. | display set for the set form, | compare for the difference from the committed configuration

    
insertMoves an ordered item such as a term (insert … term A before term B)

    
commitCommits the candidate. commit check only checks it. rollback 0 resets the candidate to the committed configuration

    
exitUp one level. At the top, leaves configuration mode

  

  

  

  
Rules (IOS XR)

  

    
?Lists the words that can come next. In the middle of a word, only the words that start with those letters

    
Tab, SpaceCompletes the word (when there is one candidate). With several candidates, Tab lists them

    
↑ ↓Command history

    
configureEnters configuration mode. The prompt becomes (config)#; interface … and the like enter submodes ((config-if)# and so on). A statement that a submode does not accept is tried in the modes above it

    
exit, root, endUp one level, to the top of configuration mode, out of configuration mode (you are asked first if there are uncommitted changes)

    
no …Removes a statement (not in effect yet)

    
show configurationYour uncommitted changes. show commit changes diff for the difference from the running configuration, show running-config for the running configuration

    
commitCommits your changes. You can add label, comment and confirmed <seconds>. abort discards the changes and leaves

    
Historyshow configuration commit list, … commit changes <commit>. load rollback changes <commit> puts the reverse of that one commit into your changes. rollback configuration last <N> in EXEC mode rolls back several commits at once
