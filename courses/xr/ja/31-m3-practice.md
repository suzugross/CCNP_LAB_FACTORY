# M3 — 実践

ラボ **XRT-02** の課題です。ラボから離れた場所でも読めるように、ここに載せています。
取り組むのはラボのワークスペースです。**Steps** タブに、課題ごとの確認ボタン、段階式のヒント、
通過後に開く模範解があります。コマンド例は意図して示していません。

## トポロジ

| リンク | XR01 | 相手 | アドレッシング |
|---|---|---|---|
| LINK1 | GigabitEthernet0/0/0/0 | RT01 Ethernet0/0 | 10.0.12.0/24(XR01 .1、RT01 .2) |
| SERVERS | GigabitEthernet0/0/0/1 | SRV01 | 10.0.50.0/24(XR01 .1、SRV01 .10) |
| LINK2 | GigabitEthernet0/0/0/2 | RT01 Ethernet0/1 | 10.0.21.0/24(XR01 .1、RT01 .2) |
| LINK3 | GigabitEthernet0/0/0/3 | RT02 Ethernet0/0 | 10.0.23.0/24(XR01 .1、RT02 .2) |

- XR01 の Loopback0 は 1.1.1.1/32 です。RT01 の Loopback0 2.2.2.2/32 は NOC の端末の代わりです。
  RT01 の Loopback100 198.51.100.1/24 はゲスト ネットワークです。
- XR01 と RT01 は LINK1 上で OSPF プロセス 1、エリア 0 を実行しています。上記のアドレスは、LINK2 と LINK3 の先(M3 の題材)を除き、
  最初から到達可能です。
- IPv6: LINK1 は 2001:DB8:12::/64(XR01 ::1、RT01 ::2)です。XR01 の Loopback0 は 2001:DB8::1/128、RT01 の Loopback0 は 2001:DB8::2/128 です。
- LINK2 は RT01 へのバックアップ リンクです。RT01 は OSPF コスト 100 を設定しています。
- RT02 は OSPF エリア 1 の拠点ルータで、エリア 1 をスタブ エリアとして動作させています。LAN は 172.16.1.0/24、
  172.16.2.0/24、172.16.3.0/24(RT02 .1)で、Loopback0 は 3.3.3.3/32 です。
- SRV01 は TACACS+ サーバです。サーバの管理者によれば、XR01 は **1.1.1.1** のクライアントとして、
  キー `XRT02-Tac-Key` で登録されており、次のユーザを保持しています。

  | ユーザ | パスワード | サーバが与える権限 |
  |---|---|---|
  | `ops1` | `Ops1-Pass` | ネットワーク管理 |
  | `view1` | `View1-Pass` | 読み取り専用 |
  | ラボのアカウント | ラボのパスワード | フル アクセス |

## M3 — OSPF

### 課題 M3-1
<p class="tolab"><a href="/_learn?id=XRT-02&amp;step=m3t1">ワークスペースで開く</a> — 読み物: <a href="30-m3-ospf.html#s2">2. 継承</a></p>


XR01 の OSPF に LINK2 が追加されましたが、LINK2 上で隣接関係が形成されません。
XR01 と RT01 が LINK2 上で OSPF 隣接関係を形成するようにしてください。
XR01 の設計規則は引き続き有効です。OSPF に追加されたインターフェイスは、隣接関係の形成を明示的に意図したものでない限り、
hello を送信してはなりません。SERVERS セグメントは隣接関係を持たないままにしてください。

### 課題 M3-2
<p class="tolab"><a href="/_learn?id=XRT-02&amp;step=m3t2">ワークスペースで開く</a> — 読み物: <a href="30-m3-ospf.html#s3">3. OSPFv3</a></p>


XR01 と RT01 が、LINK1 上の OSPFv3 で IPv6 のループバック プレフィックスを交換するようにしてください。
XR01 は 2001:DB8::2/128 を、RT01 は 2001:DB8::1/128 を学習する必要があります。

### 課題 M3-3
<p class="tolab"><a href="/_learn?id=XRT-02&amp;step=m3t3">ワークスペースで開く</a> — 読み物: <a href="30-m3-ospf.html#s4">4. エリア</a></p>


XR01 はエリア 1 のエリア境界ルータです。

- XR01 と RT02 が LINK3 上で隣接関係を形成するようにしてください。
- RT02 がエリア 1 の外から受け取るものは、デフォルト ルートだけにしてください。
- エリア 0 には、拠点の LAN を個別の /24 プレフィックスではなく、単一のプレフィックス 172.16.0.0/22 として学習させてください。
