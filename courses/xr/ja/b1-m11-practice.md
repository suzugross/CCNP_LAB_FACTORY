# M11 — 実践(1) E-Line と疑似回線

ラボ **XRT-11** の課題です。ラボから離れた場所でも読めるように、ここに載せています。
取り組むのはラボのワークスペースです。**Tasks** タブに、課題ごとの確認ボタン、段階式のヒント、
通過後に開く模範解があります。コマンド例は意図して示していません。

## 進め方の約束

- 設定するのは **XR01** と **XR03**、課題 M11-3 では **XR02** もです。他のルータはすべて据え付けで、変更しないでください。
  確認のためにログインするのは構いません。CE、SVC、INET は、顧客、共有サービス、インターネットのものです。
- 課題の中にはコマンド例を示しません。各課題は必要な動作を記述しています。読み物の各ページには設定例がありますが、
  課題の答えと同じ形のものは折りたたんであります。先に自分で解くなら、CLI のヘルプ(`?`)、`show` コマンド、
  Cisco IOS XR のコンフィギュレーション ガイドとコマンド リファレンスを使って、コマンドを見つけてください。
- **Tasks** タブには課題ごとに **Check** ボタンがあります。デバイスの現在の状態を読み取ります。
  押す前にコンフィギュレーション モードを抜けてください。コミットの後は、LDP と BGP が落ち着くまで 30 秒ほど待ってください。
- ヒントは 1 段ずつ開きます(キーワード → 参照先 → コマンド)。開いたヒントは記録されます。
- XR01 と XR03 は **IOS XRv 9000** 26.1.1 で動作しています。このプラットフォームの IOS XR が実行するのは、レイヤ 2 の
  サービスのうちポイントツーポイントのもの(VPWS)だけで、ブリッジングは行いません。XR02 は **IOS XRd** 26.1.1(IOS XR の
  コンテナ版)で動作しています。XR02 はルート リフレクタ兼 PCE で、転送パスの外にあります。

|---|---|---|---|
| PRIMARY | XR01 GigabitEthernet0/0/0/0 ─ RT01 Ethernet0/0 | 10.0.1.0/24(XR01 .1、RT01 .11) | 10 |
| BACKUP | XR01 GigabitEthernet0/0/0/1 ─ RT03 Ethernet0/0 | 10.0.3.0/24(XR01 .1、RT03 .13) | 100 |
| CORE-A | RT01 Ethernet0/1 ─ RT02 Ethernet0/0 | 10.0.12.0/24(RT01 .11、RT02 .12) | 10 |
| CORE-B | RT03 Ethernet0/1 ─ RT02 Ethernet0/1 | 10.0.23.0/24(RT03 .13、RT02 .12) | 100 |
| RR-LINK | RT03 Ethernet0/2 ─ XR02 GigabitEthernet0/0/0/0 | 10.0.33.0/24(RT03 .13、XR02 .21) | 10 |
| CORE-C | RT01 Ethernet0/2 ─ XR03 GigabitEthernet0/0/0/0 | 10.0.31.0/24(RT01 .11、XR03 .3) | 10 |

| ルータ | 役割 | プラットフォーム | Loopback0 | プレフィックス SID のインデックス |
|---|---|---|---|---|
| XR01 | プロバイダー エッジ | IOS XRv 9000 26.1.1 | 10.255.0.1/32 | 1 |
| XR02 | VPNv4 ルート リフレクタ、PCE | IOS XRd 26.1.1 | 10.255.0.21/32 | — |
| XR03 | プロバイダー エッジ(新規) | IOS XRv 9000 26.1.1 | 10.255.0.3/32 | 3 |
| RT01 | コア | IOS XE 17.15 | 10.255.0.11/32 | 11 |
| RT02 | プロバイダー エッジ | IOS XE 17.15 | 10.255.0.12/32 | 12 |
| RT03 | コア | IOS XE 17.15 | 10.255.0.13/32 | 13 |

| サイト | 接続先 | レイヤ 3 VPN | 同じポートのレイヤ 2 のサブインタフェース |
|---|---|---|---|
| 顧客 A のサイト 1(CEA1) | XR01 GigabitEthernet0/0/0/2 | VRF CUST-A(タグなし) | VLAN 100 |
| 顧客 A のサイト 2(CEA2) | RT02 Ethernet0/2 | VRF CUST-A(タグなし) | VLAN 200 |
| 顧客 B のサイト 1(CEB1) | XR01 GigabitEthernet0/0/0/3 | VRF CUST-B(タグなし) | VLAN 300、310、400、410、420、S-VLAN 500 |
| 顧客 B のサイト 2(CEB2) | RT02 Ethernet1/0 | VRF CUST-B(タグなし) | VLAN 300、310 |
| 顧客 B のサイト 3(CEB3) | XR03 GigabitEthernet0/0/0/1 | — | VLAN 40、41、42、S-VLAN 500 |

- コアでは、すべてのルータでセグメント ルーティング付きの IPv4 の IS-IS インスタンス `CORE` が動作しています。XR01 には
  課題 M10-2 以降 LDP がありません。IOS ルータどうしでは LDP を引き続き実行しています。XR03 は IS-IS と SR(プレフィックス SID の
  インデックス 3)だけを実行しています。
- レイヤ 3 VPN、SR ポリシー、PCE はラボ XRT-10 のものです。これらは動作し続ける必要があります。
- 顧客の 2 つのサイトの間のイーサネットのサービスを **E-Line** と呼びます。各ポートで、レイヤ 3 VPN はタグなしのままで、
  E-Line は同じポートのタグ付きのサブインタフェースを使います。E-Line の両端は、異なる VLAN を使うことがあります。
- プロバイダーのサイト番号: サイト 1 = **1**、サイト 2 = **2**、サイト 3 = **3**。E-Line が両端ごとに識別子を必要とする場合、
  端の識別子はそのサイトの番号です。

## M11 — L2VPN とキャリア イーサネット

### 課題 M11-1
<p class="tolab"><a href="/_learn?id=XRT-11&amp;step=m11t1">ワークスペースで開く</a> — 読み物: <a href="b0-m11-e-line.html#s2-1">2.1 アタッチメント回線と疑似回線</a> · <a href="b0-m11-e-line.html#s2-2">2.2 1 ホップずつ: CEA1 から CEA2 へ</a> · <a href="b0-m11-e-line.html#s2-3">2.3 疑似回線のラベルを配る: targeted LDP</a> · <a href="b0-m11-e-line.html#s2-4">2.4 タグの扱い: rewrite と PW タイプ</a> · <a href="b0-m11-e-line.html#s3-1">3.1 設定の置き場</a></p>


顧客 A は、レイヤ 3 VPN とは別に、サイト 1 とサイト 2 の間の E-Line を契約しました。サイト 2 側(RT02)は据え付け済みです。

- CEA1 が VLAN 100 で送信するフレームを CEA2 の VLAN 200 に届け、その逆も届けてください。この E-Line では、CE は
  172.31.10.0/24 を使います。
- この E-Line は、XR01 と RT02 の間の、LDP でシグナリングする ID **100** の疑似回線です。
- LDP は疑似回線のシグナリングだけに使ってください。XR01 のコアのリンクでは LDP を実行してはなりません。トランスポートの
  ラベルは引き続きセグメント ルーティングから来ます。
- 顧客 A のレイヤ 3 VPN は動作し続ける必要があります。

### 課題 M11-2
<p class="tolab"><a href="/_learn?id=XRT-11&amp;step=m11t2">ワークスペースで開く</a> — 読み物: <a href="b0-m11-e-line.html#s2-5">2.5 MTU: 3 つの数</a> · <a href="b0-m11-e-line.html#s3-2">3.2 状態の読み方</a> · <a href="b0-m11-e-line.html#s3-3">3.3 上がらないときの読み方</a></p>


同僚が変更 CHG-1401 と CHG-1402 で、顧客 B のサイト 1 とサイト 2 の間に 2 本の E-Line(VLAN 300 と 310)を作りました。
どちらも一度も動作したことがありません。サイト 2 側(RT02)は据え付けで、正しく設定されています。

- 両方の E-Line を動作させてください。CE は VLAN 300 で 172.31.30.0/24、VLAN 310 で 172.31.31.0/24 を使います。
- RT02 は変更しないでください。
