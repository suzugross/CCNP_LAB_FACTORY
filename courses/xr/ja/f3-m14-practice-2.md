## M14 — マルチキャスト

### 課題 M14-3
<p class="tolab"><a href="/_learn?id=XRT-16&amp;step=m14t3">ワークスペースで開く</a> — 読み物: <a href="f2-m14-ssm-bidir.html#s2-1">2.1 SSM: 受信者が送信元を指定する</a> · <a href="f2-m14-ssm-bidir.html#s2-2">2.2 盤面の上の SSM: RP も Register もない</a> · <a href="f2-m14-ssm-bidir.html#s2-3">2.3 SSM 範囲</a> · <a href="f2-m14-ssm-bidir.html#s3-1">3.1 SSM: 既定の範囲と、広げた範囲</a> · <a href="f2-m14-ssm-bidir.html#s3-2">3.2 SSM の確かめ方</a></p>


2 つ目のサービスは、送信元特定マルチキャストを使用します。セットトップ ボックスは、チャネルとその送信元の両方を指定します。

- すべてのルータ(PE1、PE2、P1、PE3、PE4)で、232.0.0.0/8 と 239.232.0.0/16 を SSM の範囲として扱ってください。
- 送信元に SRC1 を指定した受信者は、どちらの範囲のチャネルも受信できる必要があります。送信元を指定せずにこれらの範囲の
  グループに参加した受信者は、何も受信してはなりません。
- ホストに面するルータのインタフェースでは、すべて IGMP バージョン 3 を使用してください。

### 課題 M14-4
<p class="tolab"><a href="/_learn?id=XRT-16&amp;step=m14t4">ワークスペースで開く</a> — 読み物: <a href="f2-m14-ssm-bidir.html#s2-4">2.4 双方向 PIM: 1 本のツリーを、パケットが両方向に流れる</a> · <a href="f2-m14-ssm-bidir.html#s2-5">2.5 DF(Designated Forwarder)</a> · <a href="f2-m14-ssm-bidir.html#s3-3">3.3 双方向 PIM</a> · <a href="f2-m14-ssm-bidir.html#s3-4">3.4 2 つのスタティック RP が同じグループに当たるとき</a> · <a href="f2-m14-ssm-bidir.html#s3-5">3.5 双方向 PIM の確かめ方</a></p>


会議のサービスでは、どの拠点もほかのすべての拠点へ送信できます。

- すべてのルータで、239.48.0.0/16 に双方向 PIM を使用し、PE3 の Loopback0(10.255.0.3)を RP にしてください。
- どのホストも 239.48.0.0/16 のグループへ送信でき、そのグループに参加したすべてのホストが受信できる必要があります。
- これらのグループについて、どのルータも送信元ごとの状態を持ってはなりません。
