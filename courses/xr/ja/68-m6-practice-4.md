## M6 — BGP(追補)

### 課題 M6-9
<p class="tolab"><a href="/_learn?id=XRT-17&amp;step=m6t9">ワークスペースで開く</a> — 読み物: <a href="67-m6-limit-damp-agg.html#s2-1">2.1 経路数の上限</a> · <a href="67-m6-limit-damp-agg.html#s3-1">3.1 maximum-prefix の設定例</a> · <a href="67-m6-limit-damp-agg.html#s3-4">3.4 出力の読み方と落とし穴</a></p>


顧客の設定の誤りによって、大量の経路が PE1 へ流れ込むことを防ぎます。

- PE1 が CE1 から受け付ける IPv4 ユニキャストの経路は 4 本までとし、3 本に達したら警告を記録してください。
- 4 本を超えた場合、PE1 は CE1 とのセッションを切断し、2 分後に自動で再確立する必要があります。

### 課題 M6-10
<p class="tolab"><a href="/_learn?id=XRT-17&amp;step=m6t10">ワークスペースで開く</a> — 読み物: <a href="67-m6-limit-damp-agg.html#s2-2">2.2 ダンプニング: ペナルティと半減期</a> · <a href="67-m6-limit-damp-agg.html#s2-3">2.3 集約と、より詳細な経路の抑制</a> · <a href="67-m6-limit-damp-agg.html#s3-2">3.2 ダンプニングの設定例</a> · <a href="67-m6-limit-damp-agg.html#s3-3">3.3 集約の設定例</a> · <a href="67-m6-limit-damp-agg.html#s3-4">3.4 出力の読み方と落とし穴</a></p>


- PE2 は、X1 から学習した経路に、ルート フラップ ダンプニングを使用してください。半減期は 10 分とし、そのほかの値は既定値とします。
- PE2 と PE3 は、顧客のアドレス 192.168.0.0/22 を 1 本の経路にまとめて X1 と X2 へ広告し、その中の個別の経路を X1 と X2 へ
  広告してはなりません。
