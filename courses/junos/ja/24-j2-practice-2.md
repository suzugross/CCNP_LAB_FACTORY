# J2 — 実践 2

ラボ **JNT-03** の課題です。ラボから離れた場所でも読めるように、ここに載せています。
取り組むのはラボのワークスペースです。**Tasks** タブに、課題ごとの確認ボタン、段階式のヒント、
通過後に開く模範解があります。

## トポロジ

```
SRV1 eth1 ──── et-0/0/1 JUN01 et-0/0/0 ──── et-0/0/0 JUN02 et-0/0/1 ──── eth1 FRR1(ISP) eth2 ──── eth1 NET1
       172.16.10.0/24                10.0.12.0/30                10.0.23.0/30                 192.0.2.0/30
```

| 機器 | インターフェース | アドレス |
|---|---|---|
| SRV1 | eth1 | 172.16.10.10/24(既定経路は 172.16.10.1) |
| SRV1 | lo(サーバの網) | 172.16.20.1/24 |
| JUN01 | et-0/0/1.0 | 172.16.10.1/24 |
| JUN01 | et-0/0/0.0 | 10.0.12.1/30 |
| JUN01 | lo0.0 | 192.168.0.1/32 |
| JUN02 | et-0/0/0.0 | 10.0.12.2/30 |
| JUN02 | et-0/0/1.0 | 10.0.23.1/30 |
| JUN02 | lo0.0 | 192.168.0.2/32 |
| FRR1 | eth1 | 10.0.23.2/30 |
| FRR1 | eth2 | 192.0.2.1/30 |
| FRR1 | lo | 203.0.113.1/32 |
| NET1 | eth1 | 192.0.2.2/30(既定経路は 192.0.2.1) |
| NET1 | lo | 198.51.100.10/32・203.0.113.10/32・10.200.0.1/32・192.168.50.1/32 |

- JUN01 と JUN02 は AS 65000 です。2 台の間で OSPF を area 0 で動かし、JUN02 は FRR1(ISP・AS 64500)と eBGP のセッションを張っています。
  J1 のとおり、JUN02 は ISP へ 172.16.0.0/16 だけを広告し、ISP から受け取った既定経路を OSPF で JUN01 へ配っています。
- NET1 は ISP の先にいるインターネットの端末です。ループバックのアドレスを、送信元として使い分けます。198.51.100.10 はふつうのホスト、
  203.0.113.10 は ISP の運用の網のホスト、10.200.0.1 と 192.168.50.1 は私的アドレスをかたる送信元です。

## J2 firewall filter

単元 J2 に沿った課題です。JUN02 を通る通信と、JUN02 自身が受け取る通信を、Junos の firewall filter で制御してください。

### 課題 J2-3  JUN02 の RE を守る
<p class="tolab"><a href="/_learn?id=JNT-03&amp;step=j2t3">ワークスペースで開く</a> — 読み物: <a href="23-j2-protect-re.html#s2-1">2.1 RE 行きのパケットが通る順</a> · <a href="23-j2-protect-re.html#s2-2">2.2 RE が受け取る通信を数え上げる</a> · <a href="23-j2-protect-re.html#s2-3">2.3 apply-path: 相手のアドレスを設定から拾う</a> · <a href="23-j2-protect-re.html#s2-4">2.4 自分が始めた通信の戻り</a> · <a href="23-j2-protect-re.html#s2-6">2.6 確かめ方</a></p>


JUN02 自身(RE)が受け取る通信を、次のものだけにすること。どのインターフェースから来たものも同じに扱うこと。

- BGP。相手は、JUN02 の BGP の設定にある neighbor だけとすること。neighbor を足したり変えたりしても、このフィルタは書き直さずに済むこと
- OSPF
- ICMP
- SSH。サーバの網 172.16.0.0/16 から来るものだけ
- JUN02 自身が始めた TCP の通信の戻り

ほかの通信は捨てて、数をカウンタ `RE-DENY` で数えること。
