## 注入した故障

- 種別: `wrong_id` — redistribute の参照プロセス/AS が誤り(config は一見完備・無言で経路ゼロ)
- 対象: RT07 の router ospf 42 への注入方向(EIGRP AS 208 出自)

## 各選択肢の判定

- **A**: 参照先のプロセス/AS が実在しない以上、メトリックを与えても注入は発生しない。症状は解消しない。
- **B**: 経路は注入されるようになる(症状は改善する)が、実在しないプロセス/AS への参照が残置され、要件4を満たさない。
- **C**: (正解)
- **D**: 逆方向の再配送は参照 ID も含めて正常(対比側の経路表で確認できる)。削除すればかえって逆方向の到達性を壊す。

## 検証コマンドと期待される出力

- `show ip protocols`(RT07): 対象プロセスの Redistributing 節に出自プロトコルが
  正しい ID・(EIGRP なら) metric 付きで載ること。
- `show ip route`(症状側 RT01): 対岸 Loopback 群が `O E2` として
  現れること。是正前は当該経路が不在(対比側 RT02 には最初からある)。
- 是正後に反映が遅い場合は境界ルータで `clear ip route *`。
