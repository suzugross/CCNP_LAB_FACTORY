## 解説

### 完成文: アカウンティングの種類と記録のタイミング

```
aaa accounting exec default ［①］start-stop group RADGRP
aaa accounting commands 15 default stop-only group RADGRP
aaa accounting ［②］network default start-stop group RADGRP
aaa accounting system default start-stop group RADGRP
```

アカウンティングは「誰が・いつ・何を」をサーバへ送る機能で、認証や認可と違い失敗してもログインや操作は妨げない。種類は、ログインセッションの **［③］exec**、打ったコマンドの記録である commands <レベル>、PPP などの **［②］network**、装置の再起動などの system がある。記録のタイミングは **［①］start-stop** なら開始と終了の 2 レコード、stop-only なら終了時の 1 レコード、wait-start なら開始レコードがサーバに受理されるまでセッションを始めない。RADIUS では Accounting-Request が UDP 1813 へ送られ、サーバは Accounting-Response で受領を返す。コマンド単位の記録は **［④］TACACS+** でのみ実用的で、変更履歴の監査に使う。

### 各空欄の要点

- ① = **A. start-stop** — 開始+終了
- ② = **F. network** — PPP/SLIP などは network
- ③ = **D. exec** — EXEC セッションの記録は exec
- ④ = **E. TACACS+** — コマンドアカウンティングは TACACS+

### 語群の残り(どの空欄にも入らない)

- C. stop-only — 開始+終了
- B. resource — PPP/SLIP などは network
- H. login — EXEC セッションの記録は exec
- G. RADIUS — コマンドアカウンティングは TACACS+
