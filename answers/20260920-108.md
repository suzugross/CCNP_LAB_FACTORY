## 解説

### 完成文: VPN ラベルの割り当てモード

出口 PE が VPN ラベルをどう割り当てるかには 2 つのモードがある。IOS XE の既定は per-prefix で、CE から学んだ経路 1 つずつに別のラベルを割り当てるため、出口 PE はラベル(LFIB)の検索だけで出力インターフェースと次ホップを決められる。一方 VRF 単位のモードを有効にすると VRF 全体で 1 つの集約ラベルになり、出口 PE はラベルで **［①］所属 VRF** を特定した後に、その中で IP 宛先の経路検索を行う。**［②］ラベル数(メモリ)** の消費を抑えたい多 VRF 環境で使い、コマンドは `mpls label mode vrf <名前> protocol bgp-vpnv4 **［③］per-vrf**`、割り当て結果は `show ip bgp vpnv4 all **［④］labels**` で確認する。なお PE 自身に由来する経路(connected や Null0 宛の集約)は既定でも VRF 単位の集約ラベルになる。

### 各空欄の要点

- ① = **C. 所属 VRF** — 集約ラベルが示すのは VRF まで。出力先は IP 検索で決める
- ② = **H. ラベル数(メモリ)** — per-vrf の目的はラベル消費の削減
- ③ = **B. per-vrf** — VRF 単位に切り替えるキーワードは per-vrf
- ④ = **F. labels** — ラベル割当は show ip bgp vpnv4 all labels

### 語群の残り(どの空欄にも入らない)

- E. 出力インターフェース — 集約ラベルが示すのは VRF まで。出力先は IP 検索で決める
- A. 帯域 — per-vrf の目的はラベル消費の削減
- G. aggregate — VRF 単位に切り替えるキーワードは per-vrf
- D. neighbors — ラベル割当は show ip bgp vpnv4 all labels
