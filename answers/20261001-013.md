## 解説

### 完成文: TACACS+ によるコマンド認可とアカウンティングの設定例

```
aaa new-model
!
tacacs server TAC1
 address ipv4 10.99.1.5
 key N0c-Tacacs
aaa group server tacacs+ TAC-SRV
 server name TAC1
ip tacacs source-interface Loopback0
!
aaa authentication login default group TAC-SRV local
aaa authorization exec default group TAC-SRV if-authenticated
aaa authorization commands 15 default group TAC-SRV local
［①］aaa authorization config-commands
aaa accounting exec default start-stop group TAC-SRV
aaa accounting commands 15 default start-stop group TAC-SRV
```

TACACS+ の価値はコマンド単位の制御にある。`aaa authorization commands 15` により、権限レベル 15 のユーザが打つコマンドは **［②］1 コマンドごとに** サーバに問い合わせて許可・拒否される。ただし既定では設定モードのコマンドは認可対象に含まれず、**［①］aaa authorization config-commands** を入れて初めてインターフェース配下などの設定コマンドも照会される。exec 認可の末尾に置いた if-authenticated は「認証に成功していれば許可」というメソッドで、サーバ無応答時に締め出されないための保険である。アカウンティングは start-stop にすると開始と終了の両方が記録され、コマンドのアカウンティングでは「誰がいつ何を打ったか」が残る。TACACS+ はこの照会と記録を **［③］TCP セッション** の上で行うので、サーバとの間に TCP 49 が通っている必要がある。なおコマンド認可はサーバが応答している限り厳密に効くため、サーバの障害時に備えて **［④］local** を末尾に置くのが定石である。

### 各空欄の要点

- ① = **F. aaa authorization config-commands** — 設定コマンドを認可対象に含めるコマンド
- ② = **C. 1 コマンドごとに** — commands 認可は打つたびに照会
- ③ = **G. TCP セッション** — TACACS+ は TCP 49
- ④ = **D. local** — 無応答時にローカル DB で認可
