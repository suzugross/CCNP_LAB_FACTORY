### VLAN 30 のスパニング ツリー

- ルート ブリッジ= SW05(ブリッジ ID(priority, MAC)が最小: priority 4096・001a.a17e.91fd)。
- SW01: ルート ポート= Gi0/1(コストが同じで、送信元のブリッジ ID が小さい)。候補 Gi0/1(対向 SW03 Gi0/0: 20000+20000=40000)、Gi0/2(対向 SW04 Gi0/0: 20000+20000=40000)、Gi0/0(対向 SW02 Gi0/0: 40000+20000=60000)。
- SW02: ルート ポート= Gi0/1(コストが同じで、送信元のブリッジ ID が小さい)。候補 Gi0/1(対向 SW03 Gi0/1: 20000+20000=40000)、Gi0/2(対向 SW04 Gi0/1: 20000+20000=40000)、Gi0/0(対向 SW01 Gi0/0: 40000+20000=60000)。
- SW03: ルート ポート= Gi0/3(ルート パス コストが最小)。候補 Gi0/3(対向 SW05 Gi0/0: 0+20000=20000)、Gi0/2(対向 SW04 Gi0/2: 20000+20000=40000)、Gi0/1(対向 SW02 Gi0/1: 40000+20000=60000)、Gi1/0(対向 SW06 Gi0/0: 40000+20000=60000)、Gi0/0(対向 SW01 Gi0/1: 40000+20000=60000)。
- SW04: ルート ポート= Gi0/3(ルート パス コストが最小)。候補 Gi0/3(対向 SW05 Gi0/1: 0+20000=20000)、Gi0/2(対向 SW03 Gi0/2: 20000+20000=40000)、Gi0/1(対向 SW02 Gi0/2: 40000+20000=60000)、Gi1/0(対向 SW06 Gi0/1: 40000+20000=60000)、Gi0/0(対向 SW01 Gi0/2: 40000+20000=60000)。
- SW06: ルート ポート= Gi0/0(コストが同じで、送信元のブリッジ ID が小さい)。候補 Gi0/0(対向 SW03 Gi1/0: 20000+20000=40000)、Gi0/1(対向 SW04 Gi1/0: 20000+20000=40000)。
- SW01 Gi0/0 は代替: このリンクの指定ポートは SW02 Gi0/0(ルート パス コスト 40000 対 40000・同点なのでブリッジ ID が小さい側)。

- SW02 Gi0/2 は代替: このリンクの指定ポートは SW04 Gi0/1(ルート パス コスト 20000 対 40000)。
- SW04 Gi0/2 は代替: このリンクの指定ポートは SW03 Gi0/2(ルート パス コスト 20000 対 20000・同点なのでブリッジ ID が小さい側)。
- SW06 Gi0/1 は代替: このリンクの指定ポートは SW04 Gi1/0(ルート パス コスト 20000 対 40000)。

往路= 送信元 VLAN の Active がルーティングし、宛先 VLAN へは**自分の SVI から**出す。復路= 宛先側 VLAN の Active が同じようにルーティングする。VLAN ごとに Active が違えば往路と復路は別の分配を通る(非対称)。フレームは各 VLAN のスパニング ツリーの木に沿って進むので、root と Active がずれていると分配間やコアを余計に回る。HSRP の選出= priority → 同値なら実 IP の大きい方(同時に起動した場合)。preempt が無ければ後から上がった側は priority が高くても Active を奪わない。preempt は priority が上回るときだけ働く(同値なら IP が大きくても奪わない)。

- 根拠: HSRP の選出・preempt・非対称経路・SVI の ACL の効き方は実機(IOSvL2)で確認済み(poc/fhrp/README.md)。
