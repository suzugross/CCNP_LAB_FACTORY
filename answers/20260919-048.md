## 解説

### 完成文: ラベルバインディング・配布モード・LDP ルータ ID

LDP がラベルを結び付ける単位は **［①］FEC(Forwarding Equivalence Class)** で、宛先プレフィックスのように転送処理が同じになるパケットの集合である。各 LSR はこの単位ごとに自分のローカルラベルを割り当て(ラベルバインディング)、既定の **［②］Downstream Unsolicited(DU)** モードでは相手からの要求を待たずに全ての LDP ピアへ広告する。要求されたときだけ広告するモードは **［③］Downstream on Demand(DoD)** である。LSR を識別する LDP ルータ ID は、明示指定がなければ up 状態のループバックインターフェースの中で最大の IP アドレス、それも無ければ物理インターフェースの最大 IP が選ばれる。このルータ ID は既定で LDP セッションのトランスポートアドレスにも使われるため、そのアドレスが IGP で到達可能でないとセッションが張れない。IOS では `mpls ldp router-id Loopback0 **［④］force**` のように固定するのが定石で、末尾のキーワードは既存セッションを張り直してでも直ちに適用させる意味を持つ。

### 各空欄の要点

- ① = **C. FEC(Forwarding Equivalence Class)** — バインディングの単位は FEC。LSP はラベル付き経路そのもの
- ② = **B. Downstream Unsolicited(DU)** — IOS の LDP 既定は要求なしで配る DU
- ③ = **H. Downstream on Demand(DoD)** — 要求時のみ配るのが DoD
- ④ = **A. force** — force はルータ ID 変更を即時適用(セッション再確立を伴う)
