## 解説

### 完成文: L2 のマルチキャスト: IGMP snooping・querier・filter・MLD

スイッチは既定ではマルチキャストフレームを VLAN 内に **［①］フラッディングする** が、IGMP snooping を使うと IGMP のメッセージを覗いて **［②］受信者のいるポート** にだけ転送する(Catalyst では既定で有効)。ルータが接続されたポートは **［③］mrouter ポート** として学習され、そこにはグループに関係なく転送される。ルータのいない VLAN では Query を送る機器が無いため、スイッチの IGMP snooping querier を有効にして Query を代行させる。特定のポートで参加できるグループを制限するには、`ip igmp profile` で範囲を定義し、インターフェイスに **［④］`ip igmp filter`** を適用する。IPv6 では IGMP の代わりに MLD を使い、MLDv1 は IGMPv2 に、MLDv2 は IGMPv3 に相当する。MLD のメッセージは **［⑤］ICMPv6** の一部として送られる。

### 各空欄の要点

- ① = **G. フラッディングする** — 宛先 MAC がマルチキャストなので MAC テーブルに載らない
- ② = **C. 受信者のいるポート** — 実測: `show ip igmp snooping groups` に参加したポートだけが載った
- ③ = **D. mrouter ポート** — 実測: PIM ルータの接続ポートが dynamic で学習された
- ④ = **H. `ip igmp filter`** — profile を参照してポートの参加を制限する(Cisco 文書。ioll2 には無い)
- ⑤ = **A. ICMPv6** — MLD は ICMPv6 のメッセージ
