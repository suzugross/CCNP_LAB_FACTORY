### 完成文: top-talkers(従来 NetFlow)と FNF の cache sort で上位フローを見る

```
ip flow-export destination 198.51.100.100 2055
ip flow-export version 5
!
interface Ethernet0/0
 ［①］ip flow ingress
!
ip flow-top-talkers
 ［②］top 5
 ［③］sort-by packets
!
RT02# ［④］show ip flow top-talkers
SrcIf   SrcIPaddress   DstIf   DstIPaddress   Pr SrcP DstP Bytes
Et0/0   192.168.7.30      Et0/1   192.168.9.40      06 C1A2 0050  921600
Et0/0   192.168.7.31      Et0/1   192.168.9.53      11 A3F0 0035  30720
2 of 5 top talkers shown. 2 flows processed.
```

従来の NetFlow で上位フローを見るには、まず IF に **［①］ip flow ingress** を付けて採取を有効にし、`ip flow-top-talkers` 配下で **［②］top** に表示件数(1〜200)、**［③］sort-by** に並べ替えの基準(bytes か packets)を書く。結果は **［④］show ip flow top-talkers** で見る。これは **［⑤］装置上のキャッシュをソートして表示するだけ** ので、コレクタへのエクスポートが動いていなくても使える。FNF で同じことをするには show flow monitor MON-WAN cache sort highest counter bytes のようにキャッシュをその場でソートし、末尾に件数の指定を付けて絞る。ただし並べ替えに使えるのはそのレコードに含まれるフィールドだけなので、バイト数で並べたければレコードに collect counter bytes が要る。
