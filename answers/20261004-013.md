## 解説

### 完成文: DMVPN を守る IPsec の連鎖(IKEv1/ISAKMP + IPsec プロファイル)

```
crypto isakmp policy 10
 encryption aes 256
 hash sha256
 authentication pre-share
 group 14
crypto isakmp key Wan#Key2026 address ［①］0.0.0.0
crypto isakmp keepalive 10 3
crypto ipsec transform-set TS-AES esp-aes 256 esp-sha256-hmac
 mode ［②］transport
crypto ipsec profile IPSEC-PROF
 set transform-set TS-AES
!
interface Tunnel0
 ［③］tunnel protection ipsec profile IPSEC-PROF
```

isakmp policy は **［④］IKE フェーズ 1(ISAKMP SA)の交渉条件** で、encryption・hash・authentication・group・lifetime を相手と一致させる。事前共有鍵の address を **［①］0.0.0.0** にしているのはスポーク間直接通信の相手 NBMA が事前に分からないためである。transform-set は IKE フェーズ 2(IPsec SA)で使う ESP のアルゴリズムとモードで、GRE 済みのトンネルなので **［②］transport** にする。IPsec プロファイルは transform-set(と pfs)を束ねる器で、**［③］tunnel protection** で Tunnel に貼ると Tunnel を通る全パケットが対象になる。crypto map 方式との違いは暗号化対象を ACL で列挙せず、物理 IF ではなく Tunnel IF に適用するである。`crypto isakmp keepalive` は **［⑤］DPD(相手の死活監視)の間隔と回数** である。

### 各空欄の要点
