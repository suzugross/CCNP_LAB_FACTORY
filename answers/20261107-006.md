## 解説

入口 PE はラベルを 2 枚積む。外側(先頭)は運ぶ層のラベルで、出口 PE のループバックへの道を表す。番号は**次の機器**が決めて LDP で配ったもので、入口 PE の表では出口 PE のループバックの行の Outgoing の列にある(Local の列は自分が隣に配った番号)。内側はサービスのラベルで、番号は**出口 PE** が決める(L3VPN と EVPN は BGP で広告し RR が変えずに反射する・LDP の疑似回線(VPWS・VPLS)は出口 PE が targeted LDP で直接渡す)。P は外側だけを見て付け替え、出口の 1 つ手前の P は外側を外して渡す(PHP。表では Pop Label / Pop)。出口 PE が explicit null を広告していれば、外側を外さずラベル 0 に付け替える(表では explicit-n)。出口 PE は内側の番号で、どの VRF の経路か・どの回線か・どのブリッジ ドメインかを決める。ラベルの番号は決めた機器の中でだけ意味を持つので、別の機器が同じ番号を別の用途に使っていてもよい。

- 外側: RT02 の表で XR01 のループバック 10.255.0.1 の行は、Local が 25・Outgoing が 22。RT02 が付けるのは次の RT01 が決めた 22。
- 内側: RT02 の `show ip bgp vpnv4 all labels` で 10.102.1.0/24 の Out label 24006(XR01 が決めて BGP で広告し、XR02 が反射した番号)。
- RT01 の表で 10.255.0.1 の行の Outgoing は explicit-n。XR01 が explicit null を広告しているので、RT01 は外側をラベル 0 に付け替えて渡す。XR01 は 0 を外し、内側の 24006 で 10.102.1.0/24[V] の行(Gi0/0/0/3 から CEB1 へ)を引く。
- 線の上の実測(CML のリンクの捕獲): RT02 から RT01 は `22 | 24006`、RT01 から XR01 は `0 | 24006`。

- 仕込み: 場面 `m_b_21`・区間 1
