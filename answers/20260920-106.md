## 解説

### 完成文: LDP-IGP 同期・LDP セッション保護・Autoconfig

LDP と IGP の足並みがそろわないと、リンク復旧直後などにブラックホール(パケット損失) が起きる。IGP の隣接が先に上がり、ラベル交換が終わる前にそのリンクへ転送が始まるためである。**［①］LDP-IGP 同期** はこれを防ぐ機能で、LDP が未確立のリンクに対して IGP が max-metric を広告して迂回させる。有効化は `router ospf` 配下の **［②］mpls ldp sync** で、対応する IGP は OSPF と IS-IS である。一方、リンク障害時にセッションそのものを維持するのが **［③］LDP セッション保護** で、直結リンク用の Link Hello 隣接に加えて Targeted Hello 隣接をあらかじめ張っておき、リンクが落ちても IP で到達できる限りセッションとラベルバインディングを保つ。復旧後の再学習が不要になるので収束が速い。バックアップ隣接の保持時間は既定で **［④］無期限(infinite)** である。さらに `mpls ldp autoconfig` は指定した IGP が走る全インターフェースで LDP を自動有効化する機能で、インターフェースごとの mpls ip 投入を省く。
