## 解説

### 完成文: アドミニストレーティブディスタンスの既定値

| 経路の出所 | AD |
|---|---|
| 直接接続 | **［①］0** |
| スタティック | 1 |
| eBGP | **［②］20** |
| EIGRP(内部) | **［③］90** |
| OSPF | 110 |
| IS-IS | 115 |
| RIP | **［④］120** |
| EIGRP(外部) | 170 |
| iBGP | 200 |
| 不明(使わない) | 255 |

AD は同じプレフィックスを複数の出所から学んだときに、どれを経路表に載せるかを決める信頼度で、**［⑤］小さい** 方が勝つ。同じプロトコル内の優劣はメトリックで決めるが、プロトコルをまたぐ比較はメトリックでは行えないので AD が要る。EIGRP は内部経路と外部(再配送)経路で値が違い、再配送ループを防ぐ意図で外部の方が **［⑥］大きい(信頼度が低い)**。BGP も eBGP と iBGP で値が違い、iBGP が大きいのは AS 内では IGP の経路を優先させたいためである。値はプロトコル配下の `distance` コマンドで変えられ、AD を最大値にした経路は「信頼しない」扱いで経路表に載らない。
