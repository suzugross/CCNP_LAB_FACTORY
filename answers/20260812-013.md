  filter=戻り経路を学習段で遮断(distribute-list) /

## 各選択肢の判定

- **A**: IGP 側の各ルータは当該プレフィックスを学習している(経路表に存在する)。広告そのものは成立している。
- **B**: (正解)
- **C**: 等コスト分散であれば宛先には到達する。示された traceroute は同一のホップ列を反復しており、分散ではなく周回である。
- **D**: `r>` の `>` はベストパス選出済みを示し、RIB-failure は選出後に RIB へ載せられなかったという表示。これは原因ではなく、原因(他プロトコルが RIB を占有していること)の結果である。
- **E**: RT01 の BGP テーブルに当該プレフィックスが存在する(広告は届いている)。
- **F**: 外部経路タイプは同一プロトコル内の優劣に影響するに過ぎず、iBGP と IGP 外部経路の比較は管理距離で決まる。

## 検証コマンドと期待される出力

  (是正前は `Known via "eigrp"`)。

## 教育核心

既定 AD の並び(eBGP 20 / EIGRP内 90 / OSPF 110 / EIGRP外 170 / **iBGP 200**)。
再配送リングでは出自が一周して「自分が注いだ経路」が外部経路として戻り、
iBGP より強い AD で勝ってしまう。切り分けの型は
「`show ip bgp` の r>(RIB-failure) × `show ip route <prefix>` の Known via 不一致」。
