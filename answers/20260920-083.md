## 解説

### 完成文: PHP と予約ラベル

ラベル値は 20 ビットで、0 から **［①］15** までは予約されている。出口 PE(egress LER)は自分に直結する FEC に対して、ラベル値 3 の Implicit Null を上流に通知するのが既定である。これを受け取った 1 つ手前のルータは、転送時に先頭ラベルを **［②］pop** してから送るので、出口 PE は 2 回の検索(ラベル→IP)をせずに済む。この動作を PHP(Penultimate Hop Popping) と呼ぶ。QoS 情報(TC/EXP)を出口まで保持したい場合は、代わりにラベル値 **［③］0** の **［④］Explicit Null** を通知させ、出口自身に剥がさせる。ラベル値 1 は Router Alert で、途中のルータが制御プレーンで検査すべきパケットであることを示す。

### 各空欄の要点

- ① = **C. 15** — 予約は 0〜15 の 16 個。16 以降が動的ラベル
- ② = **B. pop** — PHP では手前が剥がす(pop)
- ③ = **H. 0** — IPv4 Explicit Null は 0。3 は Implicit Null
- ④ = **G. Explicit Null** — ラベルを付けたまま出口まで届けさせるのは Explicit Null
