- **B**: (正解)

## 解説

同一 AS の拠点間では、CE が受信 AS_PATH に自身の AS を見つけて経路を捨てる(PE の advertised-routes には載るのに CE の PfxRcd が 0)。PE 側の as-override(CE の AS を PE の AS に置換= 受信 AS_PATH `65000 65000`)か、CE 側の allowas-in(自 AS を許容= `65000 65200`)で通る。どちらを採るかは「どちら側の構成を変えられるか」で決まる。
