## 解説

### 完成文: MPLS ルータが持つ 4 つの表

MPLS ルータは 4 つの表を使い分ける。IP ルーティングプロトコルの学習結果は RIB に入り、そこから転送用に最適化された **［①］FIB** が作られる。LDP で交換したラベルバインディングは、全ての隣接から受け取ったものをそのまま LIB に保持し、そのうち IP 経路表のネクストホップと一致する最良のものだけが転送用の LFIB に反映される。したがって全隣接のバインディングを一覧するには **［②］show mpls ldp bindings** を、実際の転送に使われるラベルと動作を見るには show mpls forwarding-table を使う。ラベルなしの IP パケットを受け取った入口 PE は IP 宛先で表を引いてラベルを **［③］push** し、ラベル付きパケットを受け取った P ルータは先頭ラベルで表を引いて **［④］swap** する。

### 各空欄の要点

- ① = **C. FIB** — IP 転送用は FIB。LFIB はラベル転送用
- ② = **H. show mpls ldp bindings** — bindings = LIB の内容
- ③ = **A. push** — 入口はラベルを付ける(push)
- ④ = **F. swap** — 途中は付け替え(swap)

### 語群の残り(どの空欄にも入らない)

- G. LIB — IP 転送用は FIB。LFIB はラベル転送用
- D. show mpls forwarding-table — bindings = LIB の内容
- B. pop — 入口はラベルを付ける(push)
- E. show mpls ldp neighbor — bindings = LIB の内容
