### 完成文: メソッドリストの読み方と「次のメソッドへ行く条件」

(この盤面の世界: **local → group の順(local 優先・local に無ければサーバ)** — 同じ kind でも世界が違えば正解が変わる)

```
aaa new-model
aaa authentication login default local group AAA-SRV
!
username local-admin privilege 15 secret 9 $9$xxxx    ! local だけに存在
! 認証サーバの台帳: ope-suzuki(サーバだけに存在)
!
line vty 0 15
 transport input ssh
 ! (login authentication 未指定)
```

aaa new-model を入れた瞬間に全回線が AAA のメソッドリストで認証されるので、投入前に別のセッションを開いたままにしておく。上の default のリストは **［①］名前付きリストを付けていない全回線** に効く。メソッドは左から順に試され、次へ進むのは前のメソッドが応答しない(タイムアウト/到達不能) ときだけで、**［②］拒否(Reject)した** 場合はそこで確定する(次へは行かない)。この盤面でサーバが正常に応答しているとき、local だけにいる local-admin は **［③］local で即座に入れる**。サーバだけにいる ope-suzuki は local に無いので次のサーバへ進み、入れる。サーバが 2 台とも無応答のとき、local-admin は待たされずに local で入れる。なお、回線に付けたリスト名が **［④］定義されていない** と、IOS は default と同じ動きをする(実測)。
