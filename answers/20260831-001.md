# 解答 20260831-001

## 正解

## 注入した故障

- 種別: `wrong_id` — redistribute の参照プロセス/AS が誤り(config は一見完備・無言で経路ゼロ)
- 対象: RT03 の router eigrp 596 への注入方向(OSPF 85 出自)
- 赤ニシン: RT01・RT02・RT03 に未適用の route-map/prefix-list/ACL と無害な適用行(passive-interface Lo0 等)を混入(実害なし)
- 適用基準(可変): seed metric=`100000 100 255 1 1500` / 付与方式=redistribute 文へ直接指定
- 生成: `gen_paper_mcq.py --seed 793689665`(sub-seed 4788942 / 展開パック PAPER-RD-4788942・撤収済)

## 各選択肢の判定

- **A**: route-map RM-BACKUP1 は定義されているだけで、どの redistribute にも適用されていない(実効なし)。
- **B**: 設定抜粋のとおり、当該境界の redistribute 文は存在する(欠落ではない)。
- **C**: 対向側 RT02 の経路表には RT05 の拠点網が外部経路として載っており、広告は行われている(逆方向は健全)。
- **D**: redistribute に route-map は適用されておらず、定義も存在しない。
- **E**: (正解)
- **F**: 経路表の経過タイマーが安定して進行しており、フラップの形跡がない。

## 検証コマンドと期待される出力

- `show ip protocols`(RT03): 対象プロセスの Redistributing 節に出自プロトコルが
  正しい ID・(EIGRP なら) metric 付きで載ること。
- `show ip route`(症状側 RT05): 対岸 Loopback 群が `D EX (external, AD 170)` として
  現れること。是正前は当該経路が不在(対比側 RT02 には最初からある)。
- 是正後に反映が遅い場合は境界ルータで `clear ip route *`。
