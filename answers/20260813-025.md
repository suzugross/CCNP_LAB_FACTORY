## 仕込んだ状態

- 種別: `riploop/seed_loop` — RIP⇄OSPF 二点相互再配送の「対策が効いていない」型
  (GEN-REDISTRO 盤面の紙面化・BL-116)
- 出題形式: cause
- 機構: 支社網 `10.19.0.0/24` 系は RT02 が RIP で広告し、両方の境界(RT04/RT01)が OSPF へ再配送する。対策(タグ・distance・常識的な seed metric)が無い素の二点相互再配送のため、(1)一方の境界が、他方が生成した O E2(AD 110)を RIP(120)より優先し【第1層=AD】、(2)それを seed metric 1 で RIP へ再注入するため、RT06 で RT02 方向のネイティブ [120/1] と再注入 [120/1] が**同値の等コスト**になる【第2層=seed metric】。分散の片割れが境界へ向かい、RT06→境界→OSPF→もう一方の境界→RT06 の定常周回になる。
- 正解法: (cause 形専用)是正の定石は、出自タグ両方向+seed metric 5+`distance ospf external 180` を**両方の境界**に入れる(GEN-REDISTRO の模範解と同一)。
- 生成: `gen_paper_mcq.py --shape riploop --seed 73283554`
  (sub-seed 1808939 / 展開パック PAPER-RD-1808939・撤収済)

## 各選択肢の判定

- **A**: 経路は広告されている。事象は広告の欠落ではなく、広告された経路の扱われ方にある。
- **B**: 両方の境界とも OSPF ドメインの経路を保持しており、隣接は確立している。
- **C**: RT06 はいずれの経路も RIP(AD 120)として学習しており、管理距離は同一。等価な負荷分散が周回の入口になっている。
- **D**: 経路表の経過時間は単調に進行しており、定常状態である。
- **E**: (正解)
- **F**: 分散された一方の経路は広告元へ向かっておらず、同一の区間を反復している。

## 教育核心

ring(AD 反転)・mploop(同AD・メトリック差)と違い、この形は**対策そのものは
構成に存在する**(あるいは存在した痕跡がある)。読み筋は、症状の型で層を
当てること — **周回(TTL 超過)**ならタグ/seed の層、**遠回り**なら選好(AD)の層、
**偏り**なら広告の抑止。そのうえで「対策が機能している証拠」(match tag の一致・
適用の範囲・残置物)を、config と `show route-map` / `show ip protocols` で
突き合わせる。二点相互再配送の対策は**両方の境界に対**で入って初めて完成する。
