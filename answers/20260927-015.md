## 解説

### 完成文: IGMP: v2 の参加と離脱・querier・v3

IGMPv2 のホストは、グループに参加するとき Membership Report を送り、離脱するときは **［①］224.0.0.2(全ルータ)** 宛てに Leave Group を送る。同じ LAN にルータが複数あると、Query を送る querier は **［②］IP アドレスが最小** のルータに決まる(PIM の DR の決め方とは逆)。Cisco IOS の既定では General Query を **［③］60** 秒ごとに送り、querier からの Query が 120 秒途絶えると他のルータが querier を引き継ぐ。Leave を受けた querier は Group-Specific Query を 1 秒間隔で **［④］2** 回送り、応答が無ければそのグループを消す。IGMPv3 では **［⑤］送信元を指定した参加(INCLUDE / EXCLUDE)** ができ、Report の宛先は **［⑥］224.0.0.22** である。SSM を使うにはこの IGMPv3 が必要になる。ルータのインターフェイスで `ip igmp join-group` を設定すると、ルータ自身がグループに参加し、グループ宛ての ping に応答する。
