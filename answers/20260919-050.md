## 解説

### 完成文: LDP と RSVP-TE の違い

LDP と RSVP-TE はどちらもトランスポートラベルを配るが、性格が違う。LDP は IGP の最短路に沿って全 FEC のラベルを自動で配る「敷き詰め型」で、設定は `mpls ip` を各インターフェースに入れるだけと簡単だが、経路を最短路以外に曲げることや帯域の予約はできない。RSVP-TE は **［①］トンネル(LSP)** ごとにヘッドエンドが経路を計算して張る「トンネル型」で、帯域予約・明示経路・優先度・**［②］Fast Reroute** による 50 ミリ秒級の保護が使える代わりに、トンネル数が増えるとヘッドエンドと途中ルータの **［③］ソフトステート(維持すべき状態)** が増える。ラベルの割当方向はどちらも **［④］下流から上流** で共通である。実務では、網全体に LDP を敷き、特定のトラフィックだけ RSVP-TE トンネルに載せる併用が多い。L3VPN の VPN ラベルは LDP でも RSVP-TE でもなく MP-BGP が配る点は変わらない。

### 各空欄の要点

- ① = **G. トンネル(LSP)** — RSVP-TE はトンネル単位で張る
- ② = **A. Fast Reroute** — 事前のバックアップトンネルによる局所保護は TE FRR
- ③ = **F. ソフトステート(維持すべき状態)** — RSVP は LSP ごとに状態をリフレッシュし続ける
- ④ = **B. 下流から上流** — LDP の DU も RSVP の RESV も下流がラベルを決めて上流へ渡す
