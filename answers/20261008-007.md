```
ip flow-export destination 198.51.100.100 2055

!

!

 ［②］top 10
```

従来の NetFlow で上位フローを見るには、まず IF に **［①］ip flow ingress** を付けて採取を有効にし、`ip flow-top-talkers` 配下で **［②］top** に表示件数(1〜200)、**［③］sort-by** に並べ替えの基準(bytes か packets)を書く。結果は show ip flow top-talkers で見る。これは **［④］装置上のキャッシュをソートして表示するだけ** ので、コレクタへのエクスポートが動いていなくても使える。FNF で同じことをするには show flow monitor MON-CORP cache sort highest counter bytes のようにキャッシュをその場でソートし、末尾に件数の指定を付けて絞る。ただし並べ替えに使えるのは **［⑤］そのレコードに含まれるフィールド** だけなので、バイト数で並べたければレコードに collect counter bytes が要る。
