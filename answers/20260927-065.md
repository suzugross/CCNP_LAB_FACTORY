- 往路: SW04 → SW02 → SW01 → SW03(VLAN 10 の木で SW04 → SW02、SW02 がルーティングして VLAN 30 の木で → SW03)
- 復路: SW03 → SW01 → SW02 → SW04(VLAN 30 の木で SW03 → SW01、SW01 がルーティングして VLAN 10 の木で → SW04)

- VLAN 30 の Active= **SW01**: 同時に起動したので priority が高い方。
- VLAN ごとに Active が違うので、往路は SW02・復路は SW01 を通る(非対称)。

### VLAN 10 のスパニング ツリー

- ルート ブリッジ= SW02(ブリッジ ID(priority, MAC)が最小: priority 24576・5c50.15ae.22ee)。
- SW01: ルート ポート= Gi0/0(コストと送信元のブリッジ ID が同じで、送信元のポート ID が小さい)。候補 Gi0/0(対向 SW02 Gi0/0: 0+4=4)、Gi0/1(対向 SW02 Gi0/1: 0+4=4)、Gi0/2(対向 SW03 Gi0/0: 4+4=8)、Gi0/3(対向 SW04 Gi0/0: 4+4=8)。
- SW03: ルート ポート= Gi0/1(ルート パス コストが最小)。候補 Gi0/1(対向 SW02 Gi0/2: 0+4=4)、Gi0/0(対向 SW01 Gi0/2: 4+4=8)。
- SW04: ルート ポート= Gi0/1(ルート パス コストが最小)。候補 Gi0/1(対向 SW02 Gi0/3: 0+4=4)、Gi0/0(対向 SW01 Gi0/3: 4+4=8)。
- SW01 Gi0/1 は代替: このリンクの指定ポートは SW02 Gi0/1(ルート パス コスト 0 対 4)。
- SW01 Gi0/2 は代替: このリンクの指定ポートは SW03 Gi0/0(ルート パス コスト 4 対 4・同点なのでブリッジ ID が小さい側)。
- SW04 Gi0/0 は代替: このリンクの指定ポートは SW01 Gi0/3(ルート パス コスト 4 対 4・同点なのでブリッジ ID が小さい側)。

### VLAN 30 のスパニング ツリー

- ルート ブリッジ= SW01(ブリッジ ID(priority, MAC)が最小: priority 8192・0023.04cc.15cc)。
- SW02: ルート ポート= Gi0/0(コストと送信元のブリッジ ID が同じで、送信元のポート ID が小さい)。候補 Gi0/0(対向 SW01 Gi0/0: 0+4=4)、Gi0/1(対向 SW01 Gi0/1: 0+4=4)、Gi0/3(対向 SW04 Gi0/1: 4+4=8)、Gi0/2(対向 SW03 Gi0/1: 4+4=8)。
- SW03: ルート ポート= Gi0/0(ルート パス コストが最小)。候補 Gi0/0(対向 SW01 Gi0/2: 0+4=4)、Gi0/1(対向 SW02 Gi0/2: 4+4=8)。
- SW04: ルート ポート= Gi0/0(ルート パス コストが最小)。候補 Gi0/0(対向 SW01 Gi0/3: 0+4=4)、Gi0/1(対向 SW02 Gi0/3: 4+4=8)。
- SW02 Gi0/1 は代替: このリンクの指定ポートは SW01 Gi0/1(ルート パス コスト 0 対 4)。
- SW03 Gi0/1 は代替: このリンクの指定ポートは SW02 Gi0/2(ルート パス コスト 4 対 4・同点なのでブリッジ ID が小さい側)。
- SW04 Gi0/1 は代替: このリンクの指定ポートは SW02 Gi0/3(ルート パス コスト 4 対 4・同点なのでブリッジ ID が小さい側)。

往路= 送信元 VLAN の Active がルーティングし、宛先 VLAN へは**自分の SVI から**出す。復路= 宛先側 VLAN の Active が同じようにルーティングする。VLAN ごとに Active が違えば往路と復路は別の分配を通る(非対称)。フレームは各 VLAN のスパニング ツリーの木に沿って進むので、root と Active がずれていると分配間やコアを余計に回る。HSRP の選出= priority → 同値なら実 IP の大きい方(同時に起動した場合)。preempt が無ければ後から上がった側は priority が高くても Active を奪わない。preempt は priority が上回るときだけ働く(同値なら IP が大きくても奪わない)。

- 根拠: HSRP の選出・preempt・非対称経路・SVI の ACL の効き方は実機(IOSvL2)で確認済み(poc/fhrp/README.md)。
