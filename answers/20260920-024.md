## 解説

### 完成文: NetFlow v5 / v9 / IPFIX の違いと従来 NetFlow の有効化

| 項目 | 従来の NetFlow(v5) | NetFlow v9 | IPFIX(v10) |
|---|---|---|---|
| レコードの形式 | **［①］固定フォーマット(フィールドを変えられない)** | テンプレートベース(フィールドを選べる) | テンプレートベース |
| IPv6 / MPLS などのフロー | 不可(IPv4 のみ) | 可 | 可 |
| 標準化 | Cisco 独自 | Cisco 独自(RFC 3954 で公開) | **［②］IETF 標準(RFC 7011)** |
| FNF の export-protocol | netflow-v5(v5 固定分のフィールドだけ) | netflow-v9(既定) | ipfix |
| 有効化のしかた | **［③］IF に ip flow ingress / egress** | flow monitor を IF に適用 | flow monitor を IF に適用 |

従来の NetFlow はフローの定義が固定で、キーは送信元/宛先 IP・送信元/宛先ポート・プロトコル・ToS・入力 IF の 7 項目である。v9 と IPFIX はレコードの構成を **［④］テンプレートで先に通知する** ため、コレクタはテンプレートを受け取ってからでないとデータレコードを解釈できない。従来 NetFlow のキャッシュは **［⑤］show ip cache flow** で、FNF のキャッシュは `show flow monitor <名> cache` で見る。従来 NetFlow のエクスポート先は `ip flow-export destination` と `ip flow-export version` で指定する。
