## 解説

### 完成文: 保護機構: PortFast・BPDU guard/filter・root guard・loop guard・UDLD・errdisable

端末が繋がるアクセスポートに PortFast を付けると listening/learning を飛ばして即 forwarding になる(グローバルに `spanning-tree portfast default` を書くとアクセスポート全部に効く)。そのポートにスイッチが繋がれて BPDU が届いた時に、ポートを err-disabled にして守るのが **［①］BPDU guard** である(グローバル既定は `spanning-tree portfast bpduguard default`)。一方 BPDU filter は BPDU を送受信しなくする機能で、グローバル既定ではエッジ扱いのポートに掛かり、BPDU を受信するとそのポートのエッジ扱いが外れて通常の STP に戻る。インタフェースで明示すると BPDU を完全に無視するのでループの危険がある。下流に置いたスイッチが root を奪うのを防ぐには、designated 側のポートに **［②］root guard** を掛ける。superior BPDU を受けるとそのポートは root-inconsistent(blocking 相当) になり、BPDU が止めば自動で戻る。逆に、片方向リンクで BPDU が届かなくなった blocking ポートが誤って forwarding に進むのを防ぐのが **［③］loop guard** で、root/alternate 側のポートに掛け、BPDU 途絶でポートを loop-inconsistent にする。同じ片方向リンク対策でも **［④］UDLD** は L2 のエコーで隣接の生死を確かめ、aggressive モードでは失敗時にポートを err-disabled にする。err-disabled からの自動復帰は **［⑤］`errdisable recovery cause bpduguard`(原因ごとに指定)** で有効にし、待ち時間の既定は **［⑥］300** 秒である。

### 各空欄の要点

- ① = **G. BPDU guard** — 受信した瞬間に err-disabled(遮断)
- ② = **D. root guard** — designated 側に掛ける(root port には掛けない)
- ③ = **H. loop guard** — root/alternate 側に掛ける。root guard と同一ポートには併用不可
- ④ = **F. UDLD** — normal= 通知のみ / aggressive= err-disabled
- ⑤ = **I. `errdisable recovery cause bpduguard`(原因ごとに指定)** — cause を指定しないと自動復帰しない
- ⑥ = **E. 300** — `errdisable recovery interval` の既定 300 秒
