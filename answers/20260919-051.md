## 解説

### 完成文: MPLS L3VPN の 3 本柱とラベルの形式

MPLS L3VPN は 3 つの技術の組み合わせで成り立つ。**［①］VRF** は PE 上で顧客ごとに経路表・転送表・所属インターフェースを分離する仕組みで、これ単体なら MPLS なしの軽量構成(いわゆる lite 構成)としても使える。MP-BGP は VPNv4 というアドレスファミリを追加して、RD 付きプレフィックス・RT・VPN ラベルをPE 間で運ぶ。MPLS ラベルスイッチングは IP ヘッダを見ずにラベルで転送する仕組みで、これのおかげで網の中心のルータが顧客経路を持たずに済む。ラベルは L2 ヘッダと **［②］L3(IP)** ヘッダの間に挿入される。ラベルスタックの 1 エントリは **［③］32** ビットで、20 ビットのラベル値・3 ビットの TC(旧 EXP)・1 ビットの S(Bottom of Stack)・8 ビットの TTL からなる。MPLS 網内の LSR が顧客経路を一切持たなくてよいのは、**［④］P ルータ** が転送に使うのがラベルだけだからである。

### 各空欄の要点

- ① = **F. VRF** — L3 の経路表を分離するのは VRF。VLAN は L2 の分離
- ② = **A. L3(IP)** — ラベルは L2 と L3 の間(いわゆる Layer 2.5)
- ③ = **H. 32** — 20+3+1+8 = 32 ビット。20 はラベル値だけの長さ
- ④ = **C. P ルータ** — PE は VRF に顧客経路を持つ。ラベルだけで動くのは P

- D. L1 — ラベルは L2 と L3 の間(いわゆる Layer 2.5)
