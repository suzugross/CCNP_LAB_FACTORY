## 解説

### 完成文: show spanning-tree vlan の読解: Root ID・Bridge ID・ポート役割

(この盤面の世界: **Gi0/1 が cost 4・Gi0/2 が cost 19(Gi0/1 が root port)** — 同じ kind でも世界が違えば正解が変わる)

```
SW2# show spanning-tree vlan 10

VLAN0010
  Spanning tree enabled protocol rstp
  Root ID    Priority    24586
             Address     5254.0012.0f01
             Cost        4
             Port        1 (GigabitEthernet0/1)
             Hello Time   2 sec  Max Age 20 sec  Forward Delay 15 sec

  Bridge ID  Priority    32778  (priority 32768 sys-id-ext 10)
             Address     0011.2233.bb02
             Hello Time   2 sec  Max Age 20 sec  Forward Delay 15 sec
             Aging Time  300 sec

Interface           Role Sts Cost      Prio.Nbr Type
------------------- ---- --- --------- -------- --------------------------------
Gi0/1               Root FWD 4         128.1    P2p
Gi0/2               Altn BLK 19        128.2    P2p
Gi0/3               Desg FWD 4         128.3    P2p Edge
```

この出力に「This bridge is the root」の行が無いので、SW2 は **［①］root ではない(root の情報を Root ID 欄に持つだけ)** である。Root ID の priority 24586 は **［②］root の priority 設定 24576 + VLAN 10(root primary の既定値)** を意味し、Bridge ID の 32778 は既定の 32768 に **［③］VLAN 番号 10(extended system ID)** を足した表示である。SW2 の root port は **［④］GigabitEthernet0/1** で、Gi0/1 と Gi0/2 の両方が root に届くが、**［⑤］root path cost が小さい(4 と 19 の比較)** ためにそちらが選ばれた。選ばれなかった方が Altn BLK なのは、root への別経路を持つが cost で負けた予備(discarding) だからである。Gi0/3 の Type 欄の Edge は PortFast 相当の端末向けポート(TC に数えない) を、P2p は全二重リンク(proposal/agreement で高速収束) を表す。

### 各空欄の要点

- ① = **C. root ではない(root の情報を Root ID 欄に持つだけ)** — root なら Root ID の下に This bridge is the root が出る
- ② = **E. root の priority 設定 24576 + VLAN 10(root primary の既定値)** — 表示= 設定値 + extended system ID(VLAN 番号)
- ③ = **H. VLAN 番号 10(extended system ID)** — sys-id-ext 10 の表示がそれ
- ④ = **G. GigabitEthernet0/1** — Role= Root の行。Root ID の Port 欄にも同じポートが出る
- ⑤ = **J. root path cost が小さい(4 と 19 の比較)** — root port 選択の第 1 基準は root path cost(本文で port 名を明かさないのは、③を出力から読ませるため)

### 語群の残り(どの空欄にも入らない)

- B. VLAN 10 で STP が無効 — root なら Root ID の下に This bridge is the root が出る
- F. 32768 − 8192 — 表示= 設定値 + extended system ID(VLAN 番号)
- A. インスタンス番号 10 — sys-id-ext 10 の表示がそれ
- I. GigabitEthernet0/2 — Role= Root の行。Root ID の Port 欄にも同じポートが出る
- D. Prio.Nbr の値が小さい — root port 選択の第 1 基準は root path cost(本文で port 名を明かさないのは、③を出力から読ませるため)
