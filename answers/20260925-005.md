## 解説

- ルート ブリッジ= SW3(ブリッジ ID(priority, MAC)が最小: priority 8192・a0cf.5b18.e955)。
- SW1: ルート ポート= Te1/1/1(ルート パス コストが最小)。候補 Te1/1/1(対向 SW2 Te1/1/1: 2000+2000=4000)、Te1/1/2(対向 SW4 Te1/1/2: 6000+2000=8000)、Gi1/0/3(対向 SW3 Gi1/0/3: 0+20000=20000)。
- SW2: ルート ポート= Te1/1/2(ルート パス コストが最小)。候補 Te1/1/2(対向 SW3 Te1/1/1: 0+2000=2000)、Te1/1/1(対向 SW1 Te1/1/1: 4000+2000=6000)。
- SW4: ルート ポート= Te1/1/2(ルート パス コストが最小)。候補 Te1/1/2(対向 SW1 Te1/1/2: 4000+2000=6000)、Gi1/0/1(対向 SW3 Gi1/0/2: 0+20000=20000)。
- SW1 Gi1/0/3 は代替: このリンクの指定ポートは SW3 Gi1/0/3(ルート パス コスト 0 対 4000)。
- SW4 Gi1/0/1 は代替: このリンクの指定ポートは SW3 Gi1/0/2(ルート パス コスト 0 対 6000)。

選出順= ルート ブリッジ(最小 BID)→ ルート ポート(最小ルート パス コスト→送信元 BID→送信元ポート ID)→ 各リンクの指定ポート(ルート パス コスト→BID→ポート ID が小さい端)→ 残りが代替(ブロッキング)。
