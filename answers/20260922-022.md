## 解説

### 完成文: root の配置とパス選択のチューニング(priority・cost・port-priority)

root の位置は運任せにせず priority で決める。`spanning-tree vlan 10 root primary` は priority を 24576 にする(現 root がそれより低ければ、現 root より priority を 1 段階下げた値)。`root secondary` は **［①］28672** に固定される。priority を直接書く場合は 4096 の倍数しか受け付けない(既定 32768)。ポートのコストは帯域から決まり、short 方式では 100 Mbps= **［②］19**・1 Gbps= **［③］4**・10 Gbps= 2 である。long 方式(`spanning-tree pathcost method long`)では 1 Gbps= **［④］20000** になる。root への経路を変えたいとき、自分のどのポートを root port にするかは `spanning-tree cost <値>`(インタフェース) で変える。一方、対向スイッチのどのポートを root port にするかを自分側で決めるには `spanning-tree port-priority <値>`(インタフェース) を使う(既定 128・**［⑤］16** 刻み・小さいほど優先。対向から見た送信元 port ID として効く)。hello・forward delay・max age を変えるときは **［⑥］root bridge(root で設定した値が配られる)** で設定する(BPDU に載って全体へ配られるため)。
